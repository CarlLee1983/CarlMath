## 給家長的話

<ParentNote />

## 情境開場

孩子在玩三角板。他手上有兩塊：一塊三個角是 $30^\circ$、$60^\circ$、$90^\circ$，一塊是 $45^\circ$、$45^\circ$、$90^\circ$。他把一塊三角板的三個角依序摸過去，問你：「三個角加起來，是不是都是一樣的？」

你記得好像有這麼一回事，可是說不出為什麼。更讓人好奇的是，家裡還有一塊很大的三角形野餐墊，邊長是三角板的好幾倍，三個角加起來，會不會比較大？

這個單元要回答的是：為什麼任何三角形的三個角加起來都是 180 度？

## 開始前

這個單元的先修是[角與角度](/units/angles/)。開始之前，先觀察孩子能不能做到下面幾件事：

- 知道角的大小是轉了多少，說得出直角是四分之一圈。
- 知道一條直線是半圈，是 $180^\circ$。
- 會用手撕紙，把一小塊角撕下來，不會因為撕得不整齊而放棄。

前兩件做得到，就可以開始。如果孩子還不確定半圈是多少度，先回去做「摺出一個直角」的活動，再把摺好的直角並排兩個，看看合起來是多少。

## 大人先懂

從動手開始。在紙上畫一個三角形，剪下來，把三個角分別撕下來。撕下來的角不必整齊，只要保留尖尖的頂點。接著畫一條直線，把三個角的頂點併在直線上的同一點，邊貼邊，不要重疊也不要留縫，你會看到它們剛好排滿直線的一側。

半圈 $180^\circ$ 的角叫**平角**（straight angle）。三個角拼成平角，用符號寫就是

$$
50^\circ + 60^\circ + 70^\circ = 180^\circ
$$

也就是說，只要知道兩個角，第三個角就是 180 度減去那兩個角。例如兩個角是 $50^\circ$ 和 $60^\circ$，第三個角是

$$
180^\circ - 50^\circ - 60^\circ = 70^\circ
$$

撕角是一種驗證。再換一種角度：沿著三角形走一圈。你站在三角形的一個頂點，順著邊走到下一個頂點，停下，原地轉到面向第三個頂點，再走過去，同樣轉身面向起點，走回起點，最後在起點轉回出發時的方向。每次都往同一邊轉，例如都往左。每個頂點都轉了一些，轉完三個角，你的身體回到最初的朝向，一共轉了一整圈 $360^\circ$。

<Figure caption="走一圈，三個轉角加起來是一整圈" note="虛線是順著剛走的邊繼續往前的方向，弧線是轉過的角，三個轉角 130°、120°、110° 加起來是 360°。每個轉角加上同一個頂點的內角，剛好是一條直線，也就是 180°。">
  <TurnAroundFigure
    title="沿三角形走一圈"
    desc="內角 50°、60°、70° 的三角形，從標著起點的左下角頂點出發，逆時針走一圈，邊中間的箭頭指出方向。在每個頂點，虛線延長剛走的邊，弧線標出轉到下一條邊的角度：起點轉 130°，右下角轉 120°，上方頂點轉 110°，加起來是 360°。"
  />
</Figure>

每個頂點的轉角和內角，合起來剛好是一條直線，所以轉角是 $180^\circ$ 減去內角。三個轉角加起來是 $360^\circ$，用三個內角表示就是

$$
3 \times 180^\circ - (\text{三個內角的和}) = 360^\circ
$$

所以三個內角的和是 $540^\circ - 360^\circ = 180^\circ$。兩種做法看到的是同一件事。

不過這裡要說清楚：撕、拼、量、走，都只是**驗證**，不是**證明**。我們只試了手上的幾個三角形，而且撕得有一點歪、量角器有誤差，拼起來「看起來」是直線，不等於「一定」是直線。世界上的三角形有無限多種，證明要說明不管三角形長什麼樣子都成立。真正的證明要用到平行線的性質，本站目前沒有另外寫這個證明。「走一圈」的說法也是直覺：回到最初的朝向，只能說明轉了整圈的整數倍，為什麼剛好是一圈，本身還需要理由。

這個結論在[相似三角形](/units/similar-triangles/)單元還會再用到：只要兩個三角形有兩組對應的角相等，因為內角和都是 $180^\circ$，第三組角就自動相等。

自學者延伸：把四邊形沿一條對角線切成兩個三角形，四個角加起來是兩個三角形的內角和，$2 \times 180^\circ = 360^\circ$。五邊形可以切成 3 個三角形，內角和是 $3 \times 180^\circ = 540^\circ$。一般地，凸 n 邊形（沒有凹進去的角）可以切成 $n - 2$ 個三角形，內角和是 $(n-2) \times 180^\circ$。另外，三角形內角和是 $180^\circ$ 只在平面上成立：在球面上畫三角形，例如從北極往下到赤道的兩條經線，再加一段赤道，內角和會大於 $180^\circ$。「走一圈」的直覺也一樣：在球面上走三角形，三個轉角是 $180^\circ$ 減去內角，加起來會小於 $360^\circ$。所以這個結論並不是「顯然」的，它背後藏著平面是平的這個前提。

## 常見迷思

**迷思一：三角形越大，內角和越大**。孩子覺得大的東西「什麼都比較多」，看到大的三角形，就以為它的三個角加起來也比較大。

<Misconception>

大的三角形比小的三角形大很多，所以大三角形三個角加起來比較大。

---

大的三角形把邊放大了，可是角沒有變。下圖兩個三角形，三個角都是 $50^\circ$、$60^\circ$、$70^\circ$，內角和都是 $180^\circ$。

</Misconception>

診斷題：「一塊很大的三角形空地，有兩個角是 $90^\circ$ 和 $30^\circ$。另一張很小的三角形紙片，也有兩個角是 $90^\circ$ 和 $30^\circ$。兩個三角形的第三個角各是多少度？」

<Answer>
都是 $60^\circ$，$180^\circ - 90^\circ - 30^\circ = 60^\circ$。孩子若說空地的第三個角比較大，是把「大」想成角也大了。請他想：「把紙片用影印機放大，三個角會變嗎？」也可以用兩個大小不同的三角板疊起來比角。
</Answer>

**迷思二：量出來不是 180，就是這個三角形特別**。孩子用量角器量三個角，加起來得到 178 或 183，就以為這個三角形是例外。其實是量角器的刻度和筆線的粗細，讓每一次量都差一兩度。

<Misconception>

我量出三個角是 $58^\circ$、$61^\circ$、$63^\circ$，加起來是 $182^\circ$，所以這個三角形的內角和不是 $180^\circ$。

---

量出來差一兩度很常見，每個角各差一點，加起來就差幾度。這個三角形的內角和仍是 $180^\circ$，量出來的 $182^\circ$ 是量角的誤差，這也是為什麼量只能當驗證。

</Misconception>

診斷題：「小華量一個三角形，三個角是 $88^\circ$、$47^\circ$、$43^\circ$。這個三角形的內角和是多少度？量出來的和有沒有問題？」

<Answer>
量出來的和是 $88^\circ + 47^\circ + 43^\circ = 178^\circ$，比 $180^\circ$ 少 2 度，是量角的誤差，這個三角形的內角和仍是 $180^\circ$。答「這個三角形比較特別」的孩子把一次量的結果當成事實。請他把三個角各量兩次，看每一次的結果是不是都一樣。
</Answer>

## 親子活動

兩個活動不必一天做完，第一個活動需要先印好[方格紙](/print/grid-paper/)。

<Activity title="撕角拼成一直線" minutes="10–15">

### 目的

親手把三角形的三個角撕下來，拼成一直線，並且換不同的三角形重複，看見結果每次都一樣。

### 材料

[方格紙](/print/grid-paper/)、尺、鉛筆、剪刀。拼角的紙：另一張白紙。

### 步驟

1. 在方格紙上用尺畫三個不同的三角形：一個三個角都比直角小的、一個有一個直角的（兩條邊沿著格線畫）、一個有一個角比直角大的。越不一樣越好。剪下來。
2. 拿其中一個三角形，在三個角分別畫一道、兩道、三道弧線做記號。
3. 把三個角撕下來。不用撕得整齊，保留尖尖的頂點就好。
4. 在白紙上畫一條直線，選一個點，把三個角的頂點併在這個點上，邊貼邊，不要重疊也不要留縫。
5. 問孩子：三個角有沒有剛好沿著直線排滿？這條直線是半圈，是幾度？
6. 用另外兩個三角形再做一次。

### 家長引導語

三個角拼起來，是什麼形狀？這條直線是幾度？換一個三角形，結果還一樣嗎？你覺得為什麼三個不同的三角形，結果都一樣？

### 卡關時

拼起來有一點縫或有一點重疊：撕的邊本來就不會很直，差一點點是正常的。請他撕大一點，頂點留好，重點是看有沒有「差很多」。孩子只在第一個三角形成功就想停：請他再換一個，問：「三個三角形長得不一樣，這次呢？」

### 回饋語範例

你每次都用不一樣的三角形再試一次，所以知道不是只有一個三角形才這樣。

</Activity>

<Activity title="用腳走三角形" minutes="10">

### 目的

用身體走一圈，感覺沿著三角形走一圈、每個角轉一些，三次轉身加起來剛好是一整圈。

### 材料

三個杯子或三隻鞋子，客廳或院子約 3 公尺寬的空地。

### 步驟

1. 把三個杯子放在地上，彼此相距約 3 步，圍成一個三角形。
2. 孩子站在第一個杯子旁，面向第二個杯子，直直走過去。繞的方向要讓每次轉身都轉向同一邊，例如都往左轉。
3. 到了第二個杯子，站在原地往左轉，轉到面向第三個杯子就停，再走過去。
4. 到了第三個杯子，同樣往左轉，轉到面向第一個杯子就停，走回起點。
5. 回到起點後，一樣往左轉，轉到最開始面向的方向，也就是面向第二個杯子。問孩子：「你從出發到現在，一共轉了幾圈？」
6. 把一個杯子移遠，換成不同形狀的三角形，再走一次。

### 家長引導語

你在哪一個杯子轉得最多？走完三個角，你一共轉了幾圈？換一個三角形，轉的角度有變嗎？一共轉幾圈有沒有變？

### 卡關時

孩子轉身時不知道轉多少：請他伸出手臂，先指著剛走的那一段的方向，再讓手臂跟著身體轉到下一段的方向就停。孩子覺得每個杯子都轉了一圈：請他把三次轉身想成一次完整的轉動，問：「你最後面向的方向，和剛出發時一樣嗎？中間有沒有多轉一整圈？」

### 回饋語範例

你每到一個杯子才轉身，所以數得出每個角各轉了多少。

</Activity>

<Answer>
$180^\circ - 50^\circ - 60^\circ = 70^\circ$。答 $110^\circ$ 的孩子只把已知的兩個角加起來，還沒有從 $180^\circ$ 減掉；請他先說出三個角加起來是多少，再算。
</Answer>

2. 一個直角三角形，其中一個銳角是 $35^\circ$，另一個銳角是幾度？

<Answer>
$180^\circ - 90^\circ - 35^\circ = 55^\circ$。孩子答 $145^\circ$，是只減了直角，忘了減已知的 $35^\circ$；請他先把直角和 $35^\circ$ 加起來，看看用掉多少度。
</Answer>

3. 等邊三角形的三個角一樣大，每個角是幾度？

<Answer>
$180^\circ \div 3 = 60^\circ$。孩子答 $90^\circ$，可能是用 $180^\circ \div 2$，只想到「一半」，忘了有三個角要平分；請他用三塊一樣的紙角，拼拼看三個角能不能拼成一直線。
</Answer>

4. 下圖，等腰三角形的頂角是 $80^\circ$，兩個底角一樣大，各是幾度？

<Figure caption="兩條腰一樣長，兩個底角一樣大" note="兩條短斜線表示這兩條邊一樣長；一樣長的兩條邊對面的角也一樣大。">
  <Shape
    title="等腰三角形"
    desc="頂點 A、B、C 的等腰三角形，A 在上方，A 的角是 80°；A 到 B 與 A 到 C 兩條邊長度相等，各有一條短斜線；B 與 C 的角都未知，標著問號。"

      {
        vertices: [[0, 3.0642], [-2.5711, 0], [2.5711, 0]],
        names: ["A", "B", "C"],
        sides: [{ side: 0, equal: 1 }, { side: 2, equal: 1 }],
        angles: [{ at: 0, degrees: 80 }, { at: 1, degrees: "?" }, { at: 2, degrees: "?" }],
      },
    ]}
  />

<Answer>
$(180^\circ - 80^\circ) \div 2 = 50^\circ$，兩個底角各是 $50^\circ$。孩子答 $100^\circ$，是只算了兩個底角加起來的和，忘了要平分成兩個一樣大的角；請他問自己：「$100^\circ$ 是一個角，還是兩個角加起來？」
</Answer>

5. 小明量一個三角形的三個角，得到 $62^\circ$、$58^\circ$、$63^\circ$。他的三個角加起來是多少？你覺得這個三角形真正的內角和是多少？

<Answer>
量出來的和是 $62^\circ + 58^\circ + 63^\circ = 183^\circ$，比 $180^\circ$ 多 3 度，是量角的誤差，真正的內角和是 $180^\circ$。孩子答「這個三角形比較特別」，請他把三個角各量兩次，看看每一次是否都有一點不同。
</Answer>

6. 沿一個三角形走一圈，在兩個頂點分別轉了 $100^\circ$ 和 $110^\circ$。在第三個頂點轉了幾度？那個頂點的內角是幾度？

<Answer>
一圈是 $360^\circ$，第三個轉角是 $360^\circ - 100^\circ - 110^\circ = 150^\circ$。轉角加內角是 $180^\circ$，所以第三個頂點的內角是 $180^\circ - 150^\circ = 30^\circ$。答 $150^\circ$ 就停下來的孩子，只回答了第一問，請他問自己：「轉角和內角是同一個角嗎？」
</Answer>

7. 把一個凸四邊形（沒有凹進去的角）沿一條對角線切成兩個三角形，四邊形的四個角加起來是多少度？

<Answer>
兩個三角形的內角和各是 $180^\circ$，四邊形的四個角剛好就是這六個角，所以是 $2 \times 180^\circ = 360^\circ$。孩子答 $180^\circ$ 或 $270^\circ$，請他在紙上畫一個四邊形，沿對角線剪開，數一數每個三角形有幾個角，再回頭看這六個角是怎麼拼成四個角的。
</Answer>

## 隔天再問

隔天找一個空檔，不給提示地問下面三題，答錯也不必當場糾正，記下來，下次活動多練那一部分。

1. 「三角形的三個角加起來是幾度？用撕的方法怎麼看出來？」

<Answer label="看提示">
$180^\circ$。把三個角撕下來，頂點併在一起，剛好排成一直線，直線是半圈。孩子說不出，下次再做一次「撕角拼成一直線」。
</Answer>

2. 「一個三角形有兩個角是 $30^\circ$ 和 $90^\circ$，第三個角是幾度？」

<Answer label="看提示">
$180^\circ - 30^\circ - 90^\circ = 60^\circ$。孩子答 $120^\circ$，請他再說一次三角形三個角加起來是多少。
</Answer>

3. 「為什麼說撕和量出來的結果還不算證明？」

<Answer label="看提示">
因為只試了幾個三角形，而且撕和量都有誤差；證明要說明不管什麼三角形都成立。孩子說不出也沒關係，請他說說「撕了三個不同的三角形，是不是已經試過所有三角形了」。
</Answer>
