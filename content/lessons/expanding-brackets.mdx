## 情境開場

三個朋友到飲料店，每個人都點同一款飲料，外加一份 2 元的小餅乾。飲料的價錢你沒看清楚，反正每個人要付的錢一樣。結帳時你想先估一下總共多少，旁邊的朋友說：「三杯飲料的錢，再加餅乾 2 元就好啦。」

你覺得不對：餅乾不是每個人都有一份嗎？可是如果要把「每個人付的錢，乘以 3 個人」寫成一個式子，括號外面的 3 到底要乘到哪裡？只乘飲料，還是連餅乾也乘？

這個單元要回答的核心問題是：括號外的數乘進去時，為什麼每一項都要乘到？

## 先修回顧

這個單元的先修是[化簡式子：同類項](/units/algebraic-expressions/)。下面三題不計時、不計分，卡住的話回去看那個單元再回來。

1. 化簡 $6x + 3x$。

<Answer>
$9x$。兩項都是 $x$ 乘上一個數，係數相加：$6 + 3 = 9$。
</Answer>

2. 化簡 $5a + 4 + 2a - 1$。

<Answer>
$7a + 3$。$a$ 的項 $5a$ 與 $2a$ 係數相加得 7，常數項 $4 - 1 = 3$。
</Answer>

3. $4x + 3$ 可以合併成 $7x$ 嗎？

<Answer>
不可以。$4x$ 與 3 不是同類項，沒有公共的因數，$4x + 3$ 已經是最簡。把 $x$ 換成 10 就看得出來：$43$ 和 $70$ 不一樣。
</Answer>

## 直覺

用 $x$ 代表那款飲料的價錢，$x$ 是一個數，不是一杯飲料。每個人要付 $x + 2$ 元（飲料加餅乾），3 個人的總價是 $3 \times (x + 2)$ 元。和 $3x$ 一樣，數字接括號時乘號可以省略，寫成 $3(x + 2)$，意思就是 $3 \times (x + 2)$。

### 圖解：縱邊 3 的長方形

畫一個長方形，縱邊是 3（3 個人），橫邊是 $x + 2$：先畫 $x$ 那一段，再接上 2 那一段。整個長方形的面積就是 $3(x + 2)$。從 $x$ 和 2 的交界切開，變成左右兩塊，兩塊的縱邊都是 3。

<Figure caption="每一塊都乘到縱邊 3" note="左塊是飲料的部分，右塊是餅乾的部分。切成兩塊以後，兩塊的面積加起來，還是整個長方形。">
  <AreaModel title="3(x + 2)" desc="一個長方形，縱邊是 3，橫邊拆成 x 和 2 兩段，字母 x 的長度只是示意，不按比例。左格面積是 3x，右格面積是 6。" cols={["x", 2]} rows={[3]} areas={[["3x", null]]} />
</Figure>

左塊的面積是 $3 \times x = 3x$，右塊的面積是 $3 \times 2 = 6$，整個長方形是兩塊相加：

$$
3(x + 2) = 3 \times x + 3 \times 2 = 3x + 6
$$

這個式子讀作「3 乘以 x 加 2 的和，等於 3x 加 6」。把括號拿掉，變成沒有括號的式子，叫做去括號。

這張圖和[交換、結合與分配律](/units/arithmetic-properties/)那一篇 $(10 + 3) \times 4$ 的面積圖是同一個形狀，只是其中一段從 10 換成了 $x$：分配律從數字一路走到了字母。括號外面的數放在前面或後面都可以，這是乘法的交換律。

情境、圖和符號三者是一一對應的：3 個人是縱邊的 3，飲料的價錢是橫邊的 $x$，餅乾的 2 元是橫邊的 2；左塊的面積 $3x$ 是三杯飲料的錢，右塊的面積 6 是三份餅乾的錢；兩塊相加，就是式子 $3x + 6$。朋友說的「三杯飲料再加 2 元」少算了兩份餅乾，對應到圖上，就是右塊只算了 1 份的 2，沒有算 3 份的 6。

這張圖畫的是長度都是正的情況。括號裡有減號，或括號前面是負號的時候，沒有「負的長度」可以畫，要靠規則推出來，下一段就是在做這件事。

## 推理

### 為什麼每一項都要乘到

看圖就知道：括號外的 3 是整個長方形的縱邊，橫邊不管切成幾塊，每一塊都有這條縱邊，所以每一塊的面積都要乘上 3。只乘 $x$ 那一塊，右塊就只算了一份餅乾的錢，可是三個人各有一份。

用數字檢查最清楚：把 $x$ 換成 5，$3 \times (5 + 2) = 21$。去括號後的 $3x + 6$ 是 $3 \times 5 + 6 = 21$，相同；如果只乘第一項，$3x + 2 = 17$，少了 4。

### 括號裡有減號：$3(x - 2)$

減去一個數，等於加上它的相反數，所以 $x - 2 = x + (-2)$，括號裡其實是兩項：$x$ 與 $-2$。分配律對任何數都成立，包括負數（負負為何得正那一篇就是靠它推出來的），所以

$$
3(x - 2) = 3\bigl(x + (-2)\bigr) = 3 \times x + 3 \times (-2) = 3x + (-6) = 3x - 6
$$

最後一步又用了一次「加上一個負數就是減去它」。用 $x = 5$ 檢查：$3 \times (5 - 2) = 9$，$3 \times 5 - 6 = 9$，相同。可見括號外的數乘到每一項，連 $-2$ 前面的負號也跟著那一項走。

### 括號前面是負號：$-(a + b)$

$-(a + b)$ 是 $a + b$ 的相反數。任何數乘以 $-1$，都會得到它的相反數（見[負負為何得正](/units/integer-mul-div/)），所以 $a + b$ 的相反數 $-(a + b)$ 就是 $(-1) \times (a + b)$，是括號外乘上 $-1$。再用分配律：

$$
-(a + b) = (-1)(a + b) = (-1)a + (-1)b = -a + (-b) = -a - b
$$

結果是兩項的符號都變了，不是只改第一項。

這個結果也可以用相反數的定義驗證：一個數的相反數，和它相加等於 0。$(a + b) + (-a - b) = a + b - a - b = 0$，所以 $-a - b$ 確實是 $a + b$ 的相反數。如果寫成 $-a + b$，加起來是 $(a + b) + (-a + b) = 2b$，不是 0（除非 $b = 0$），所以 $-a + b$ 不是 $a + b$ 的相反數。

括號裡有減號的情況也一樣：$-(a - b) = (-1)\bigl(a + (-b)\bigr) = -a + b$。第一項變號，$-b$ 也變號成 $+b$。

括號前面如果是減號接在別的項後面，例如 $10 - (3 + 4)$，減去一個數等於加上它的相反數，所以是 $10 + \bigl(-(3 + 4)\bigr) = 10 - 3 - 4 = 3$。直接算括號也是 $10 - 7 = 3$，相同；寫成 $10 - 3 + 4$ 會得到 11，錯了。

### 括號外是負數，以及去括號之後合併

括號外是負數也一樣，每一項都乘：$-2(x - 3) = (-2)x + (-2) \times (-3) = -2x + 6$。其中 $(-2) \times (-3) = 6$，所以最後一項是 $+6$。

去括號之後，通常還要把同類項合併：$2(x + 3) + 3x = 2x + 6 + 3x = 5x + 6$。去括號和合併同類項是兩個不同的動作，先去括號，再合併。

順序不能顛倒：括號還在的時候，括號裡的項和括號外的項不能直接合併。例如 $2(x + 3) + 3x$ 裡，$2(x + 3)$ 還沒有拆開，不能看到 $x$ 和 $3x$ 就加起來。每次去完括號，都要把括號外的數乘到每一項、符號跟著走，之後才輪到合併。

## 範例

下面的範例從完整示範開始，逐步把步驟留給你。每個範例最後都回頭檢查一次：把 $x$ 換成一個不是 0、也不是 1 的數，看去括號前後算出來是不是一樣。

### 範例一：長方形的面積（完整範例）

長方形的寬是 4 公分，長是 $(x + 5)$ 公分，面積是 $4(x + 5)$ 平方公分。去括號。

第一步，$4(x + 5) = 4 \times x + 4 \times 5$。

為什麼這步成立？

<Answer>
括號外的 4 要乘到括號裡的每一項。把長方形從 $x$ 和 5 的交界切成兩塊，兩塊的縱邊都是 4，面積各是 $4 \times x$ 和 $4 \times 5$。見「推理」段第一節。
</Answer>

第二步，$4 \times x + 4 \times 5 = 4x + 20$。

回頭檢查：把 $x$ 換成 2，$4 \times (2 + 5) = 28$，$4 \times 2 + 20 = 28$，相同。

### 範例二：括號裡有減號（範例與練習配對）

先看示範：$5(a - 3)$。$a - 3 = a + (-3)$，所以 $5(a - 3) = 5a + 5 \times (-3) = 5a + (-15) = 5a - 15$。回頭檢查：把 $a$ 換成 4，$5 \times (4 - 3) = 5$，$5 \times 4 - 15 = 5$。

換你：$2(m - 7)$。

<Answer>
$2(m - 7) = 2m + 2 \times (-7) = 2m - 14$。回頭檢查：把 $m$ 換成 10，$2 \times (10 - 7) = 6$，$2 \times 10 - 14 = 6$，相同。$-7$ 前面的負號跟著它一起被乘，所以減號還在。
</Answer>

### 範例三：括號前面是負號（留空最後一步）

去括號：$-(x + 6)$。

第一步，$-(x + 6) = (-1)(x + 6)$。

為什麼這步成立？

<Answer>
任何數乘以 $-1$ 都得到它的相反數，括號前面的負號就是取整個括號的相反數，所以相當於把整個括號乘上 $-1$。見「推理」段第三節。
</Answer>

最後一步留給你：用分配律把 $-1$ 乘進去，並回頭檢查。

<Answer>
$(-1)x + (-1) \times 6 = -x - 6$。回頭檢查：把 $x$ 換成 2，$-(2 + 6) = -8$，$-2 - 6 = -8$，相同。兩項的符號都變了，不是只有第一項。
</Answer>

### 範例四：兩個零用錢的差（留空最後兩步）

$x$ 是某個大於 4 的數（元）。甲的零用錢是 $2(x + 3)$ 元，乙的零用錢是 $(x - 4)$ 元，甲比乙多多少元？

第一步，多的部分是甲減乙：$2(x + 3) - (x - 4) = 2x + 6 - x + 4$。

為什麼這步成立？

<Answer>
$2(x + 3)$ 的 2 乘到兩項，得到 $2x + 6$。減去 $(x - 4)$ 是取它的相反數再加，括號裡每一項都變號：$-(x - 4) = -x + 4$，$-4$ 變成 $+4$。見「推理」段第一、三節。
</Answer>

最後兩步留給你：合併同類項，再用 $x = 5$ 回頭檢查。

<Answer>
$2x - x = x$，$6 + 4 = 10$，所以甲比乙多 $x + 10$ 元。回頭檢查：$x = 5$ 時，甲是 $2 \times 8 = 16$ 元，乙是 1 元，差 15 元；$5 + 10 = 15$，相同。
</Answer>

### 範例五：兩個括號一起處理（獨立解題）

化簡 $3(x + 2) - 2(x - 5)$。想想看有哪些做法，先自己試，再看下面兩種解法。

<Answer>
解法一，分別去括號再合併：$3(x + 2) = 3x + 6$；$-2(x - 5) = (-2)x + (-2) \times (-5) = -2x + 10$。合併：$3x + 6 - 2x + 10 = x + 16$。

解法二，先把每個減號都改成加上一項，再逐項乘：$3(x + 2) + (-2)\bigl(x + (-5)\bigr) = 3x + 6 + (-2x) + 10 = x + 16$。

比較：解法一比較短；解法二每一步的符號都寫出來，括號前面是負的數時，不容易把 $-5$ 的負號弄丟。兩種做法的答案相同，不確定符號的時候選解法二。

回頭檢查：把 $x$ 換成 4，原式 $3 \times 6 - 2 \times (-1) = 18 + 2 = 20$，$4 + 16 = 20$，相同。
</Answer>

## 常見迷思

**迷思一：只乘到第一項**。括號外的數只乘了括號裡的第一個，第二個原封不動。

<Misconception>

$3(x + 2) = 3x + 2$，括號外的 3 乘了 $x$，2 不用乘。

---

括號外的 3 要乘括號裡的每一項：$3(x + 2) = 3x + 6$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它漏乘了 2。用面積圖看：縱邊是 3，橫邊切成 $x$ 和 2 兩塊，右塊的面積是 $3 \times 2 = 6$，不是 2。檢查：$x = 5$ 時，$3 \times (5 + 2) = 21$，但 $3 \times 5 + 2 = 17$。
</Answer>

診斷題：去括號，$5(a + 4)$。

<Answer>
$5a + 20$。答 $5a + 4$ 的，是只乘了第一項。檢查：$a = 2$ 時，$5 \times 6 = 30$，$5 \times 2 + 20 = 30$。
</Answer>

**迷思二：去負號括號時只改第一項的符號**。看到括號前面是負號，只把括號裡第一項變號。

<Misconception>

$-(a + b) = -a + b$，負號只影響第一項。

---

括號前面的負號是乘以 $-1$，括號裡每一項都變號：$-(a + b) = -a - b$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它漏掉了第二項。$-(a + b)$ 是 $(-1)(a + b)$，$-1$ 要乘到 $a$ 和 $b$ 兩項。檢查：$a = 3$、$b = 4$ 時，$-(3 + 4) = -7$，$-3 + 4 = 1$，不一樣；$-3 - 4 = -7$ 才對。
</Answer>

診斷題：去括號，$8 - (2x - 3)$。

<Answer>
$11 - 2x$。括號前面是負號，$2x$ 與 $-3$ 都變號：$8 - 2x + 3 = 11 - 2x$。答 $5 - 2x$ 的，是只改了第一項，$-3$ 沒變號。檢查：$x = 1$ 時，$8 - (2 - 3) = 9$，$11 - 2 = 9$。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。卡住時，先問：括號外的數有沒有乘到每一項，負號有沒有跟著走？

1. 去括號，$2(x + 4)$。

<Answer>
$2x + 8$。
</Answer>

2. 去括號，$6(a - 1)$。

<Answer>
$6a - 6$。$-1$ 也要乘 6，變成 $-6$。
</Answer>

3. 化簡 $3x + 5 + 2x$。

<Answer>
$5x + 5$。$3x$ 與 $2x$ 是同類項，5 是常數項，不能併進去。答 $10x$ 的，是把 5 也當成了係數。
</Answer>

4. 去括號，$-(x + 9)$。

<Answer>
$-x - 9$。兩項都變號。
</Answer>

5. 用分配律心算 $7 \times 103$。

<Answer>
721。$7 \times (100 + 3) = 7 \times 100 + 7 \times 3 = 700 + 21 = 721$。
</Answer>

6. 去括號，$-(2a - 5)$。

<Answer>
$-2a + 5$。$2a$ 變成 $-2a$，$-5$ 變成 $+5$。
</Answer>

7. 去括號，$-3(x - 4)$。

<Answer>
$-3x + 12$。$-3$ 乘 $x$ 得 $-3x$，$-3$ 乘 $-4$ 得 $+12$。回頭檢查：$x = 2$ 時，$-3 \times (2 - 4) = 6$，$-3 \times 2 + 12 = 6$。
</Answer>

8. 算 $(-3) \times (-5) + 2 \times (-4)$。

<Answer>
7。$(-3) \times (-5) = 15$，$2 \times (-4) = -8$，$15 + (-8) = 7$。
</Answer>

9. 去括號並化簡，$7 - (x - 2)$。

<Answer>
$9 - x$。$7 - x + 2 = 9 - x$。回頭檢查：$x = 3$ 時，$7 - (3 - 2) = 6$，$9 - 3 = 6$。
</Answer>

10. 甲店買 3 件，每件 $x$ 元，再折扣 5 元，付 $(3x - 5)$ 元；乙店買 2 件，每件 $(x + 1)$ 元，付 $2(x + 1)$ 元。$x$ 是小於 7 的單價（元），乙比甲貴多少元？

<Answer>
$7 - x$ 元。乙減甲：$2(x + 1) - (3x - 5) = 2x + 2 - 3x + 5 = 7 - x$。回頭檢查：$x = 4$ 時，乙是 10 元，甲是 7 元，差 3 元；$7 - 4 = 3$。
</Answer>

## 提取題

不看前面的內容，憑記憶回答。

1. 為什麼 $3(x + 2)$ 去括號是 $3x + 6$，不是 $3x + 2$？

<Answer>
把 $3(x + 2)$ 看成縱邊 3、橫邊 $x + 2$ 的長方形，切成 $x$ 和 2 兩塊，兩塊的縱邊都是 3，面積是 $3x$ 和 $3 \times 2 = 6$。括號外的數要乘到括號裡的每一項。
</Answer>

2. $-(a + b)$ 去括號等於什麼？為什麼不是 $-a + b$？

<Answer>
$-a - b$。前面的負號是乘以 $-1$，用分配律乘到 $a$ 和 $b$ 兩項。$-a + b$ 加上 $a + b$ 是 $2b$，不是 0，所以它不是 $a + b$ 的相反數。
</Answer>

3. 用「減去一個數等於加上它的相反數」，說明 $3(x - 2)$ 為什麼是 $3x - 6$。

<Answer>
$x - 2 = x + (-2)$，括號裡是 $x$ 與 $-2$ 兩項。分配律：$3x + 3 \times (-2) = 3x + (-6) = 3x - 6$。
</Answer>

4. 去括號並化簡，$5 - (x - 1)$。

<Answer>
$6 - x$。括號前面是負號，$x$ 與 $-1$ 都變號：$5 - x + 1 = 6 - x$。
</Answer>
