## 情境開場

社團要採買筆記本，這一趟先買 3 本。賣場老闆說單價這週還在調整，報價單明天才會到，可是會計今天就要你把預算式交過去，式子裡先留著單價的位置，等報價到了再填。

除了筆記本，這一趟還要付一筆固定 2 元的袋子錢。你把預算寫好，旁邊的同學瞄了一眼說：「3 加 2 是 5，那不就是 5 本筆記本的錢嗎？」聽起來好像有道理，可是你直覺哪裡怪怪的，又說不出來。過兩天人數變多，社團又追加了 2 本，這時候筆記本的錢又該怎麼算？

筆記本的錢好像可以併成一筆，袋子錢卻好像不行，差別在哪裡？這個單元要回答的核心問題是：含有字母的式子怎麼合併得更簡單？

## 先修回顧

這個單元的先修是[用字母代表數](/units/variables/)和[負負為何得正](/units/integer-mul-div/)。下面三題不計時、不計分，卡住的話回去看那兩個單元再回來。

1. 每支筆 $x$ 元，買 4 支要多少元？

<Answer>
$4x$ 元。$4x$ 就是 $4 \times x$，數字寫在字母前面，乘號省略。答 $x + 4$ 的，是把「4 支」當成加 4。
</Answer>

2. $(-3) \times (-4)$ 是多少？

<Answer>
12。負數乘負數是正數。答 −12 的，是看到負號就把答案寫成負的。
</Answer>

3. $3 + (-5)$ 是多少？

<Answer>
$-2$。加上 −5 就是往左走 5 格，從 3 往左走 3 格到 0，再走 2 格到 −2。
</Answer>

## 直覺

先把情境裡還不知道的單價用 $x$ 代替，$x$ 代表的是「這本筆記本的單價」這個數。報價出來以前，我們不知道它是多少，但它一定是某一個確定的數。

這一趟買 3 本，要付 $3 \times x$ 元，寫成 $3x$ 元（$3x$ 就是 $3 \times x$，數字在前，乘號省略），再加袋子錢 2 元，這一趟的預算是 $3x + 2$ 元。過兩天追加的 2 本要付 $2x$ 元，兩趟的筆記本錢加起來，是 $3x + 2x$ 元。先來看後面這個。

### 圖解：兩塊縱邊相同的長方形

長方形的面積是橫邊乘以縱邊。把縱邊畫成 $x$，橫邊畫成 3，面積就是 $3 \times x = 3x$；再畫一塊縱邊也是 $x$、橫邊是 2 的長方形，面積是 $2x$。兩塊的縱邊一樣，可以直接並排。

</Figure>

並排以後，這是一個縱邊 $x$、橫邊 $3 + 2$ 的大長方形，它的面積是 $(3 + 2) \times x$，也就是 $(3 + 2)x$。大長方形的面積就是兩小塊面積的和，所以

$$
3x + 2x = (3 + 2)x = 5x
$$

這個式子讀作「3x 加 2x 等於 3 加 2 的和乘以 x，等於 5x」。意思是：兩項都有同一個 $x$，就可以把前面的數加起來，$x$ 只寫一次。

### 符號：項、係數、常數項與同類項

現在把這些用語整理一下，後面都會用到。代數式裡用加號隔開的每一部分叫做項（term）。減號視為加上一個負的項，所以 $3x - 2$ 的項是 $3x$ 與 $-2$。

- 項裡和字母相乘的那個數叫做係數（coefficient）。$3x$ 的係數是 3，$-5x$ 的係數是 $-5$。
- 係數是 1 或 −1 的時候，那個 1 省略不寫：$x$ 就是 $1x$，係數是 1；$-x$ 的係數是 $-1$。
- 不含字母的項叫做常數項（constant term），例如 $3x + 2$ 裡的 2。
- 字母部分完全相同的項叫做同類項（like terms），例如 $3x$ 與 $-5x$，或 $x$ 與 $4x$。只有同類項才能合併。

回到採買的預算：兩趟的筆記本錢 $3x + 2x$ 是同類項，可以合併成 $5x$；但這一趟的預算 $3x + 2$ 裡，$3x$ 和袋子錢 2 不是同類項，所以同學說的「5 本的錢」並不成立。為什麼不是，下一段會推出來。

## 推理

### 為什麼 $3x + 2x$ 可以合併

合併同類項靠的是分配律。數字的版本在前面學過，是 $(10 + 3) \times 4 = 10 \times 4 + 3 \times 4$（見[交換、結合與分配律](/units/arithmetic-properties/)），現在把 4 換成 $x$：

$$
(3 + 2) \times x = 3 \times x + 2 \times x
$$

分配律說的是任何三個數都成立，字母 $x$ 代表的就是一個數，所以不管 $x$ 是 10、0.5 還是 $-4$，這個式子都成立。合併同類項，就是把這條分配律從右邊讀回左邊：兩項都有 $x$ 這個公共的因數，把 $x$ 提出來，剩下的係數 3 和 2 相加。

用 $x = 10$ 驗證：$3 \times 10 + 2 \times 10 = 50$，$5 \times 10 = 50$。

### 為什麼只有同類項可以合併

再看 $3x + 2$。2 可以看成 $2 \times 1$，所以 $3x + 2 = 3 \times x + 2 \times 1$。兩項各自乘的另一個數，一個是 $x$，一個是 1，不一樣，沒有公共的因數可以提出來。用面積看，就是兩塊長方形的縱邊一個是 $x$、一個是 1，並排以後邊不齊，拼不成一個大長方形。

用 $x = 10$ 試試：$3x + 2 = 32$，但 $5x = 50$。兩邊不一樣，所以 $3x + 2$ 不等於 $5x$。同樣的道理，$3x + 2y$ 也不能合併：$x$ 和 $y$ 是兩個可以不一樣的數。

判斷是不是同類項，只看字母部分，不看係數：$3x$ 和 $-x$ 是同類項，因為字母部分都是 $x$；$4x$ 和 $4y$ 不是同類項，雖然係數一樣，字母不同；常數項彼此永遠是同類項，例如 $3 + 5$ 可以直接算成 8。

### 減法與負的係數

$5x - 2x$ 呢？減去一個數等於加上它的相反數，所以 $5x - 2x = 5x + (-2)x$，再用分配律：

$$
5x - 2x = 5x + (-2)x = \bigl(5 + (-2)\bigr)x = 3x
$$

係數相加的時候，每個係數連同前面的符號一起算。$3x - 5x$ 就是 $\bigl(3 + (-5)\bigr)x = -2x$，係數可以變成負的。

### 一次整理很多項

加法有交換律，所以式子裡的項可以換位置，但每一項要連同它前面的符號一起搬。例如 $4x + 3 - x$ 的項是 $4x$、3、$-x$，把同類項放在一起，變成 $4x - x + 3$。放在一起以後，各組同類項分別合併，就是把係數相加：$4x - x$ 的係數是 $4 + (-1) = 3$。

## 範例

下面的範例從完整示範開始，逐步把步驟留給你。每個範例最後都回頭檢查一次：把 $x$ 換成一個不是 0、也不是 1 的數，看看合併前後算出來是不是一樣。

### 範例一：兩項合併（完整範例）

化簡 $5x + 3x$。

第一步，$5x + 3x = (5 + 3)x$。

為什麼這步成立？

<Answer>
$5x$ 和 $3x$ 都是 $x$ 乘上一個數，$x$ 是公共的因數。分配律 $(5 + 3)x = 5x + 3x$ 從右邊讀回左邊，就是把 $x$ 提出來、係數相加。見「推理」段。
</Answer>

第二步，$(5 + 3)x = 8x$。

回頭檢查：把 $x$ 換成 2，$5 \times 2 + 3 \times 2 = 16$，$8 \times 2 = 16$，相同。

### 範例二：減去同類項（範例與練習配對）

先看示範：$7a - 3a$。減去 $3a$ 就是加上 $-3a$，所以 $7a - 3a = \bigl(7 + (-3)\bigr)a = 4a$。回頭檢查：把 $a$ 換成 5，$7 \times 5 - 3 \times 5 = 20$，$4 \times 5 = 20$。

換你：$2m - 5m$。

<Answer>
$2m - 5m = \bigl(2 + (-5)\bigr)m = -3m$。回頭檢查：把 $m$ 換成 4，$2 \times 4 - 5 \times 4 = -12$，$-3 \times 4 = -12$，相同。係數 $2 + (-5)$ 是負的，所以結果的係數也是負的。
</Answer>

### 範例三：同類項與常數項一起（留空最後一步）

化簡 $4x + 3 + 2x - 1$。

第一步，把同類項放在一起：$4x + 3 + 2x - 1 = 4x + 2x + 3 - 1$。

為什麼這步成立？

<Answer>
加法有交換律，項可以換位置。$-1$ 這一項的減號是它的一部分，搬動時要連同符號一起走，所以 $3$ 和 $-1$ 留在後面時，寫成 $3 - 1$。見「推理」段最後一節。
</Answer>

最後一步留給你：把 $4x + 2x$ 與 $3 - 1$ 分別合併，寫出最後的式子，並回頭檢查。

<Answer>
$4x + 2x = 6x$，$3 - 1 = 2$，所以結果是 $6x + 2$。$6x$ 和 2 不是同類項，到這裡就是最簡。回頭檢查：把 $x$ 換成 5，原式 $4 \times 5 + 3 + 2 \times 5 - 1 = 32$，$6 \times 5 + 2 = 32$，相同。
</Answer>

### 範例四：三角形的周長（留空最後兩步）

三角形三邊的長度分別是 $4a$ 公分、$(2a + 3)$ 公分、$(a - 1)$ 公分，周長是多少？

第一步，周長是三邊相加：$4a + (2a + 3) + (a - 1) = 4a + 2a + 3 + a - 1$。

為什麼這步成立？

<Answer>
加上一個和，等於把和裡的每一項一項一項加上去（加法的結合律）。括號前面是加號，括號裡每一項的符號都不變，所以括號可以直接拿掉。括號前面是減號，或前面有數字相乘的時候就不一樣了，下一個單元會講。
</Answer>

最後兩步留給你：把同類項放在一起並合併，再用 $a = 3$ 回頭檢查。

<Answer>
$4a + 2a + a + 3 - 1$，$a$ 的係數是 $4 + 2 + 1 = 7$（最後那個 $a$ 的係數是 1），常數項是 $3 - 1 = 2$，周長是 $7a + 2$ 公分。回頭檢查：$a = 3$ 時三邊是 12、9、2 公分，加起來 23；$7 \times 3 + 2 = 23$，相同。
</Answer>

### 範例五：負的係數與常數項（獨立解題）

化簡 $3x - 7 + 5 - 8x$。想想看有哪些做法，先自己試，再看下面兩種解法。

<Answer>
解法一，重排再合併：$3x - 7 + 5 - 8x = 3x - 8x - 7 + 5 = \bigl(3 + (-8)\bigr)x + (-7 + 5) = -5x - 2$。

解法二，直接看係數：$x$ 的項有 $3x$ 和 $-8x$，係數 3 與 −8 相加得 −5；常數項有 −7 與 5，相加得 −2。結果同樣是 $-5x - 2$。

比較：解法一每一步都寫出來，不容易漏掉符號；解法二比較快，但要留意 $-8x$ 的係數是 −8，不是 8。兩種做法都先把同類項分好組。

回頭檢查：把 $x$ 換成 2，原式 $6 - 7 + 5 - 16 = -12$，$-5 \times 2 - 2 = -12$，相同。
</Answer>

## 常見迷思

**迷思一：$3x + 2 = 5x$**。看到 3 和 2 兩個數字，就想把它們加起來。

<Misconception>

$3x + 2 = 5x$，因為 3 加 2 是 5。

---

$3x$ 和 2 不是同類項，不能合併，$3x + 2$ 已經是最簡的寫法。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它把常數項 2 當成了 $x$ 的係數。$3x$ 是 $3 \times x$，2 是 $2 \times 1$，兩項沒有公共的因數，分配律用不上。檢查方法：把 $x$ 換成 10，$3x + 2 = 32$，$5x = 50$，不一樣。只有 $x = 1$ 時兩邊碰巧都是 5，所以代入檢查時不要只用 1，要換成 2 或 10。
</Answer>

診斷題：化簡 $6y + 4$。

<Answer>
不能再化簡，答案就是 $6y + 4$。答 $10y$ 的，是把 4 也當成了 $y$ 的係數。檢查：$y = 2$ 時，$6 \times 2 + 4 = 16$，但 $10 \times 2 = 20$。
</Answer>

**迷思二：$x + 4x = 4x$**。字母前面沒有數字，就以為它不用算。

<Misconception>

$x + 4x = 4x$，因為 $x$ 前面沒有數字，所以不用管它。

---

$x$ 的係數是 1，只是省略沒寫：$x + 4x = 1x + 4x = (1 + 4)x = 5x$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它漏掉了第一項。$x$ 其實是 $1 \times x$，係數 1 省略不寫，但算的時候要算進去。檢查：$x = 2$ 時，$2 + 8 = 10$，$4x = 8$ 差了 2，$5x = 10$ 才對。
</Answer>

診斷題：化簡 $7m - m$。

<Answer>
$6m$。減去 $m$ 就是減去 $1m$，係數是 $7 + (-1) = 6$。答 $7m$ 的，是以為 $m$ 沒有係數、不用減。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。卡住時，先問：這兩項的字母部分一不一樣？

1. 化簡 $6x + 4x$。

<Answer>
$10x$。$(6 + 4)x = 10x$。
</Answer>

2. 化簡 $9a - 5a$。

<Answer>
$4a$。$9a - 5a = \bigl(9 + (-5)\bigr)a = 4a$。
</Answer>

3. 算 $(-3) \times (-7)$。

<Answer>
21。負數乘負數是正數，$3 \times 7 = 21$。
</Answer>

4. 化簡 $2m + 5 + 3m$。

<Answer>
$5m + 5$。把 $2m$ 和 $3m$ 放在一起合併成 $5m$，5 是常數項，不能併進去。答 $10m$ 的，是把 5 也當成係數。
</Answer>

5. 寫出 $5x - 3 + x$ 的所有項、每個含字母的項的係數，以及常數項。

<Answer>
三個項：$5x$、$-3$、$x$。$5x$ 的係數是 5，$x$ 的係數是 1，常數項是 $-3$。
</Answer>

6. 心算 $25 \times 13 \times 4$。

<Answer>
1300。先算 $25 \times 4 = 100$，再算 $100 \times 13 = 1300$。乘法可以交換，所以先湊出整百。
</Answer>

7. 化簡 $8t - 3 - 11t + 7$。

<Answer>
$-3t + 4$。$t$ 的係數 $8 + (-11) = -3$，常數項 $-3 + 7 = 4$。回頭檢查：$t = 2$ 時，原式 $16 - 3 - 22 + 7 = -2$，$-3 \times 2 + 4 = -2$。
</Answer>

8. 下面哪些可以合併成一項？(a) $5x + 2x$；(b) $5x + 2$；(c) $5x + 2y$；(d) $5x - 5x$。

<Answer>
(a) 和 (d)。(a) 是 $7x$；(d) 的係數是 $5 + (-5) = 0$，結果是 0。(b) 的 2 是常數項，(c) 的 $x$ 與 $y$ 是不同的字母，都不是同類項，不能合併。
</Answer>

9. 算 $-3 + 8 - (-2)$。

<Answer>
7。減去 −2 等於加上 2：$-3 + 8 = 5$，$5 + 2 = 7$。
</Answer>

10. 小莉週一存了 $(2x + 5)$ 元，週二存了 $(x - 3)$ 元，週三存了 $3x$ 元，三天一共存了多少元？

<Answer>
$6x + 2$ 元。三筆相加，括號前面是加號，直接拿掉：$2x + 5 + x - 3 + 3x$。$x$ 的係數 $2 + 1 + 3 = 6$，常數項 $5 - 3 = 2$。回頭檢查：$x = 4$ 時，三筆是 13、1、12 元，一共 26；$6 \times 4 + 2 = 26$。
</Answer>

## 提取題

不看前面的內容，憑記憶回答。

1. 為什麼 $3x + 2x$ 可以合併成 $5x$？用一句話說明依據的是什麼。

<Answer>
因為兩項都有公共的因數 $x$，分配律 $(3 + 2)x = 3x + 2x$ 反過來用，就是把 $x$ 提出來、係數相加。也可以說是兩塊縱邊相同的長方形，並排以後縱邊不變，橫邊接在一起。
</Answer>

2. 什麼是同類項？$3x - 7 + 2x$ 裡，哪些是同類項，常數項是哪一個？

<Answer>
字母部分完全相同的項叫同類項。$3x$ 與 $2x$ 是同類項，常數項是 $-7$。
</Answer>

3. 有人說 $3x + 2 = 5x$，你要怎麼用一個數字讓他看到哪裡不對？

<Answer>
把 $x$ 換成 10：$3x + 2 = 32$，$5x = 50$，不一樣。（不要只用 $x = 1$，那時兩邊碰巧相同。）原因是 $3x$ 和 2 沒有公共的因數，不是同類項。
</Answer>

4. 化簡 $4a + 9 - a - 3$。

<Answer>
$3a + 6$。$a$ 的係數 $4 + (-1) = 3$，常數項 $9 - 3 = 6$。
</Answer>
