## 情境開場

週末你打算去合歡山，出發前查了天氣：山下 12 度，山頂清晨「零下 3 度」。同一個週末，朋友傳來潛水的照片，說他潛到海面下 12 公尺。晚上你打開信用卡的 App，畫面上用紅字寫著「目前欠款 300 元」。

三件事講的其實是同一種情況：零下 3 度比 0 度還冷，海面下比海平面還低，欠款比身上一毛錢都沒有還要糟。它們都是「比零還少」。

可是你學過的數，都是從 0 開始往右一格一格數上去。零下 3 度、海面下 12 公尺、欠款 300 元，這些比零還少的東西，要放在數線的哪裡？零下 3 度和零下 1 度，哪一個比較冷？這個單元要回答的核心問題是：比零還少是什麼意思，數線怎麼往左延伸？

## 先修回顧

這個單元的先修是[數線：數字排成一條線](/units/number-line/)。下面三題不計時、不計分，卡住的話，回去看那個單元再回來。

1. 在每格是 1 的數線上，從 3 走到 8 要走幾格？8 在 3 的哪一邊？

<Answer>
走 5 格，8 在 3 的右邊。數線上兩點之間隔了幾格，距離就是幾。
</Answer>

2. 6 和 9 哪一個比較大？在數線上，誰比較靠右？

<Answer>
9 比較大，9 也比較靠右。數線上越右邊的數越大，$6 < 9$。
</Answer>

3. 數線上的刻度為什麼一定要等距？

<Answer>
因為每一格代表走一步，每一步一樣長。間隔有寬有窄，同樣是一步，卻走得不一樣遠，位置就不能代表步數了。
</Answer>

## 直覺

### 三個「比零還少」的情境

氣溫、海拔和帳戶餘額有一個共同的樣子：都有一個零點，往一邊是多，往另一邊是少。

- 氣溫：0 度是水結冰的溫度，比它低 3 度，叫做零下 3 度。
- 海拔：海平面是 0 公尺，海面下 12 公尺，就是比海平面低 12 公尺。
- 帳戶餘額：0 元是一毛錢都沒有，欠款 300 元，比 0 元還少 300 元。

「比零還少」就是從零點出發，往「少」的那個方向走了幾格。

### 數線往左延伸

以前的數線，0 在最左邊，右邊是越來越大的數。現在把數線往左延伸，刻度仍然等距，0 左邊的第 1 格寫 $-1$，第 2 格寫 $-2$，依此類推。$-1$ 讀作「負一」，意思是在 0 的左邊 1 格。

0 右邊的數叫做正數（positive number），0 左邊的數叫做負數（negative number），0 既不是正數也不是負數。正數通常不寫正號，只有要對照正負的時候才寫，例如 $+3$ 讀作「正三」，$-3$ 讀作「負三」。零下 3 度寫成 $-3$ 度，海面下 12 公尺寫成 $-12$ 公尺，欠款 300 元寫成餘額 $-300$ 元。

### 比大小看左右

數線上的左右，決定誰大誰小：右邊的比左邊的大。比較 $-5$ 和 $-2$，先把它們放到數線上。

<Figure caption="兩個點，哪一個在右邊" note="弧線的方向對應「變大」：從 −5 往右走到 −2，數變大了。">
  <NumberLine title="−5 和 −2" desc="負六到 2 的數線，每一格是 1。負五和負二各有一個點，負五在負二的左邊；從負五往右畫一道弧線跳到負二，弧線上標著往右變大。" from={-6} to={2} points={[{ at: -5 }, { at: -2 }]} jumps={[{ from: -5, to: -2, label: "往右變大" }]} />

$-5$ 在 $-2$ 的左邊，所以 $-5 < -2$，讀作「負五小於負二」。這和氣溫一致：零下 5 度比零下 2 度冷，冷的數比較小。

### 負分數與負小數

兩個整數之間還有分數和小數，0 的左邊也一樣。下面兩張圖，點的位置都在兩個整數的正中間。

$-\frac{1}{2}$ 讀作「負二分之一」，在 $-1$ 和 0 的正中間。$-1\frac{1}{2}$ 就是 $-1.5$，在 $-2$ 和 $-1$ 的正中間。

### 整數的意思變了

前面的單元說「整數」，指的是 0 和正整數。從這個單元起，整數（integer）包含負整數：

$$
\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots
$$

也就是說，以前說的整數是現在整數的一部分，新加進來的是 0 左邊的那些點。

## 推理

### 為什麼數線會往左延伸

數線往右走一格是多 1，往左走一格是少 1。從 3 往左走：2、1、0，每走一格少 1。這個規律沒有理由到 0 就停下來，再往左走一格，就是比 0 少 1，也就是 $-1$。負數就是讓「少」這件事永遠有位置放：欠款、零下、海面下，都是走過了 0 以後的位置。

### 為什麼比大小看左右，不看數字的大小

數線上的規則只有一條：右邊的數比左邊的數大。正數時，離 0 越遠就越大，只是這條規則的結果。到了 0 的左邊，離 0 越遠，位置反而越靠左，所以越小。

$-5$ 離 0 有 5 格，$-2$ 離 0 有 2 格，$-5$ 離得比較遠，所以它在更左邊，$-5 < -2$。簡單說：負數比 0 小，比任何正數都小；兩個負數相比，離 0 越遠的越小。

### 為什麼 0 的兩邊是對稱的

3 和 $-3$ 離 0 一樣遠，都是 3 格，只是方向相反。像這樣在數線上對稱於 0 的兩個數，叫做互為相反數（opposite number），例如 $+3$ 與 $-3$。它們加起來是 0。0 的相反數是 0。

## 範例

下面的範例從完整示範開始，逐步把步驟留給你。每個範例最後都回頭檢查一次。

### 範例一：氣溫比大小（完整範例）

比較 $-7$ 度和 $-3$ 度，哪個數比較大？

第一步，在數線上標出位置：$-7$ 在 0 左邊 7 格，$-3$ 在 0 左邊 3 格。

第二步，$-7$ 在 $-3$ 的左邊，所以 $-7 < -3$，$-3$ 比較大。

為什麼這步成立？

<Answer>
數線的規則是右邊的數比左邊的大。$-7$ 離 0 比較遠，但它在更左邊，所以反而小。看位置，不是看 7 比 3 大。
</Answer>

回頭檢查：零下 7 度比零下 3 度冷，冷的數比較小，$-7 < -3$。

### 範例二：帳戶餘額（範例與練習配對）

先看示範：小宇的餘額是 $-150$ 元，小安的是 $-80$ 元，誰的餘額比較多？$-150$ 在 $-80$ 的左邊，所以 $-150 < -80$，小安的餘額比較多。回頭檢查：欠 150 元比欠 80 元欠得多，餘額當然比較少。

換你：兩天的最低氣溫分別是 $-2$ 度和 $-9$ 度，哪一天比較冷？哪一個數比較小？

<Answer>
$-9$ 度那一天比較冷，$-9 < -2$，因為 $-9$ 在 $-2$ 的左邊。回頭檢查：零下 9 度比零下 2 度冷。
</Answer>

### 範例三：排順序（留空最後一步）

把 $-3$、2、$-1.5$、0、$-\frac{1}{2}$ 由小到大排列。

第一步，分成兩堆：負數是 $-3$、$-1.5$、$-\frac{1}{2}$，其他是 0 和 2。負數都比 0 小，也比 2 小。

為什麼這步成立？

<Answer>
負數都在 0 的左邊，0 和正數都在 0 或它的右邊。數線上右邊的數比左邊的大，所以任何負數都比 0 和正數小。
</Answer>

第二步，三個負數離 0 的格數：$-3$ 是 3 格，$-1.5$ 是 1.5 格，$-\frac{1}{2}$ 是 0.5 格。最後一步留給你：把五個數由小到大排好，並回頭檢查。

<Answer>
離 0 越遠的負數越小：$-3 < -1.5 < -\frac{1}{2} < 0 < 2$。回頭檢查：把五個數放到數線上，由左到右剛好是這個順序。
</Answer>

### 範例四：海拔高低（留空最後兩步）

甲在海面下 35 公尺（$-35$），乙在海面下 12 公尺（$-12$），丙在海拔 8 公尺。要由低到高排列，並指出甲和乙誰比較接近海平面。

第一步，甲和乙是負數，在 0 的左邊，丙在 0 的右邊，所以丙最高。

最後兩步留給你：排好甲和乙的順序，完成由低到高的排列；再說出甲和乙誰離海平面比較近，並回頭檢查。

<Answer>
$-35 < -12 < 8$，由低到高是甲、乙、丙。甲和乙之中，乙離海平面比較近，只差 12 公尺，甲差 35 公尺，看的是離 0 的格數。回頭檢查：甲在海面下 35 公尺，比乙深，所以更低。
</Answer>

### 範例五：正中間的數（獨立解題）

數線上有一個點，在 $-3$ 和 $-2$ 的正中間，它是多少？它比 $-2$ 大還是小？先自己試，再看答案。

<Answer>
從 $-3$ 往右半格是 $-2.5$，也可以寫成 $-2\frac{1}{2}$。它在 $-2$ 的左邊，所以比 $-2$ 小，$-2.5 < -2$。回頭檢查：它離 $-3$ 和 $-2$ 都是 0.5 格；零下 2.5 度比零下 2 度冷。
</Answer>

## 常見迷思

**迷思一：$-5$ 比 $-2$ 大**。因為 5 比 2 大，就以為 $-5$ 比 $-2$ 大。

<Misconception>

5 比 2 大，所以 $-5$ 比 $-2$ 大。

---

$-5$ 在 $-2$ 的左邊，所以 $-5 < -2$。零下 5 度比零下 2 度冷。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它只看了數字部分，沒看負號。負號把數放到了 0 的左邊，離 0 越遠，位置越靠左，數反而越小。比大小要看數線上的位置。
</Answer>

診斷題：$-8$ 和 $-3$ 哪個比較大？$-\frac{1}{2}$ 和 $-\frac{1}{3}$ 哪個比較大？

<Answer>
$-3$ 比較大；$-\frac{1}{3}$ 比較大。$\frac{1}{2}$ 比 $\frac{1}{3}$ 大，所以 $-\frac{1}{2}$ 離 0 比較遠，位置更靠左。答 $-8$ 和 $-\frac{1}{2}$ 的，是只比了數字部分。
</Answer>

**迷思二：0 是正數**。因為 0 比所有負數都大，就把 0 歸到正數那一邊。

<Misconception>

0 比所有負數都大，所以 0 是正數。

---

0 是正數和負數的分界，既不是正數也不是負數。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它從「0 比負數大」跳到「0 是正數」。正數的定義是比 0 大的數，0 不比自己大，所以不是正數；0 也不比自己小，所以不是負數。
</Answer>

診斷題：下面哪些是負數？$-3$、0、$-\frac{1}{2}$、0.2、$-0.5$。

<Answer>
$-3$、$-\frac{1}{2}$、$-0.5$ 是負數，也就是在 0 左邊的點。0 和 0.2 不是：0 是分界，0.2 在 0 的右邊。漏掉分數或小數的，是以為負號只配整數；把 0 算進去的，是持有迷思的人。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。卡住時，先把數放到數線上看左右。

1. 用負數表示：零下 6 度、海面下 20 公尺、帳戶欠款 350 元（寫成餘額）。

<Answer>
$-6$ 度、$-20$ 公尺、$-350$ 元。「零下」「海面下」「欠」都是比零點少的方向。
</Answer>

2. $-4$ 和 $-9$ 哪個比較大？

<Answer>
$-4$。它在 $-9$ 的右邊。答 $-9$ 的，是只看 9 比 4 大。
</Answer>

3. $\frac{3}{4}$ 和 $\frac{2}{3}$ 哪個比較大？

<Answer>
$\frac{3}{4}$。通分成十二分之幾：$\frac{9}{12}$ 比 $\frac{8}{12}$ 大。
</Answer>

4. 把 2、$-5$、0、$-1$、$-3$ 由小到大排列。

<Answer>
$-5 < -3 < -1 < 0 < 2$。放到數線上，由左到右就是由小到大。
</Answer>

5. 每顆蘋果 $a$ 元，$a$ 是 12 時，$4a$ 是多少元？

<Answer>
$4 \times 12 = 48$ 元。$a$ 是一個數，$4a$ 是 $4 \times a$，不是 4 顆蘋果，也不是 412。
</Answer>

6. $-2.5$ 和 $-2.25$ 哪個比較大？

<Answer>
$-2.25$。2.25 離 0 比 2.5 近，所以 $-2.25$ 在 $-2.5$ 的右邊。
</Answer>

7. 寫出 6、$-4$、0 的相反數。

<Answer>
$-6$、4、0。0 的相反數是它自己，因為 $0 + 0 = 0$。
</Answer>

8. 在每格是 $\frac{1}{4}$ 的數線上，$\frac{7}{4}$ 在 1 的哪一邊？把它寫成帶分數。

<Answer>
在 1 的右邊，$\frac{7}{4} = 1\frac{3}{4}$。從 0 走 7 個 $\frac{1}{4}$，走過 1 以後還要再走 3 個。
</Answer>

9. 數線上介於 $-3.5$ 與 2 之間（不含兩端）的整數有哪些？

<Answer>
$-3$、$-2$、$-1$、0、1。2 是右端，不算；$-3.5$ 在 $-4$ 和 $-3$ 之間，所以 $-3$ 算，$-4$ 不算。整數包含負整數和 0。
</Answer>
