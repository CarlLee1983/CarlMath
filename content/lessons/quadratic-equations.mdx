## 情境開場

社團要在校園一角圍出一塊長方形的菜圃。長比寬多 3 公尺，土地只剩 40 平方公尺，要剛好用完。你拿著捲尺站在空地上，想知道寬要量幾公尺。

你試著猜：寬 4 公尺，長就是 7 公尺，面積 28，太小；寬 6 公尺，長 9 公尺，面積 54，太大；寬 5 公尺，長 8 公尺，面積 40，剛好。猜中了，可是你心裡有兩個疑問：這是唯一的答案嗎？如果數字不這麼漂亮，還能一直猜下去嗎？

數學裡有一個關於「0」的小性質，能讓這類問題不必靠猜。這個單元要回答的核心問題是：「乘積為零」為什麼能幫我們解方程式？

## 先修回顧

這個單元的先修是[因式分解](/units/factoring/)和[平方根與根式](/units/square-roots/)。下面三題不計時、不計分，卡住的話回去看那兩個單元再回來。

1. 因式分解 $x^2 + 7x + 12$。

<Answer>
$(x + 3)(x + 4)$。乘起來是 12、加起來是 7 的兩個數是 3 和 4。展開檢查：$x^2 + 4x + 3x + 12 = x^2 + 7x + 12$。
</Answer>

2. 9 的平方根有哪些？$\sqrt{16}$ 是多少？

<Answer>
9 的平方根是 3 與 $-3$，因為 $3^2 = 9$，$(-3)^2 = 9$。$\sqrt{16} = 4$，$\sqrt{\ }$ 只指正的那個平方根。答 $\pm 4$ 的，是把「16 的平方根」和「$\sqrt{16}$」混在一起。
</Answer>

3. 展開 $(x - 2)(x - 3)$。

<Answer>
$x^2 - 5x + 6$。$(x - 2)(x - 3) = x^2 - 3x - 2x + 6$，中間兩項合併是 $-5x$。
</Answer>

如果你已經能說出為什麼 $(x - 2)(x - 3) = 0$ 時 $x$ 只能是 2 或 3，也會解 $x^2 = 9$，可以直接跳到練習：

## 直覺

菜圃的問題，用 $x$ 代表寬（單位是公尺），長是 $x + 3$ 公尺，面積是 40 平方公尺，列出來是

$$
x(x + 3) = 40
$$

含有未知數的等式叫方程式，讓它成立的未知數的值叫做解。這一條的未知數最高是 $x$ 的 2 次方（展開以後出現 $x^2$），只有一個未知數，所以叫做一元二次方程式（quadratic equation）。展開並讓右邊變成 0，可以寫成 $x^2 + 3x - 40 = 0$。一般的寫法是 $ax^2 + bx + c = 0$，其中 $a$ 不是 0；如果 $a$ 是 0，$x^2$ 那一項就消失了，剩下的就是一次方程式。猜出來的 $x = 5$ 能不能算數，要看它能不能讓等式成立；而有沒有別的解，只靠猜是沒辦法確定的，這也是這個單元想補上的缺口。

### 零是特別的

先看兩個數相乘等於 12：$3 \times 4$、$2 \times 6$、$(-1) \times (-12)$ 都可以，知道積是 12，幾乎問不出什麼。但如果兩個數相乘等於 0，情況就不一樣：

$$
a \times b = 0
$$

想想看，$a$ 和 $b$ 要怎麼配才行？只要 $a$ 是 0，不管 $b$ 是多少都成立；只要 $b$ 是 0，不管 $a$ 是多少也成立；兩個都不是 0 的話，例如 $2 \times 3 = 6$、$(-4) \times 5 = -20$，乘起來都不是 0。所以乘積是 0 的時候，至少有一個因數是 0。

### 用到方程式上

把這個性質用在 $(x - 2)(x - 3) = 0$。兩個因式 $x - 2$ 與 $x - 3$ 相乘等於 0，所以 $x - 2 = 0$ 或 $x - 3 = 0$，也就是 $x = 2$ 或 $x = 3$。用數字試試看：$x = 0$ 時 $(0 - 2)(0 - 3) = 6$，$x = 4$ 時 $(4 - 2)(4 - 3) = 2$，都不是 0，只有 2 和 3 能讓其中一個因式變成 0。

  <NumberLine title="兩個解" desc="0 到 5 的數線，每一格是 1。2 有一個點，3 有一個點，這兩個點是方程式的兩個解。" from={0} to={5} points={[{ at: 2 }, { at: 3 }]} />
</Figure>

情境、圖和符號三者是一一對應的：因式 $x - 2$ 為 0 的位置，是數線上 2 的點；因式 $x - 3$ 為 0 的位置，是數線上 3 的點；方程式 $(x - 2)(x - 3) = 0$ 的解，寫成 $x = 2$ 或 $x = 3$，讀作「x 等於 2，或 x 等於 3」。「或」的意思是兩個至少成立一個，這個方程式就有這兩個解。

## 推理

### 為什麼乘積為零，至少有一個因數是零

證明只要兩行。設 $a \times b = 0$。如果 $a$ 不是 0，就可以把兩邊同除以 $a$，得到 $b = 0 \div a = 0$。所以 $a$ 不是 0 的話，$b$ 一定是 0；換句話說，不是 $a = 0$，就是 $b = 0$。

這個性質只對 0 成立。例如 $a \times b = 12$，$a$ 不是 0，除以 $a$ 以後 $b = 12 \div a$，$b$ 並沒有被固定住。所以只有右邊是 0 的時候，才能把乘積拆開。

### 用因式分解解方程式

照這個性質，解二次方程式有固定的做法：先把右邊整理成 0，左邊因式分解，再讓每個因式等於 0。回到菜圃的 $x^2 + 3x - 40 = 0$：

$$
\begin{aligned}
x^2 + 3x - 40 &= 0 \\
(x + 8)(x - 5) &= 0 && \quad\text{（因式分解：乘起來是 }-40\text{、加起來是 3）}
\end{aligned}
$$

乘積為零，至少一個因數為零，所以 $x + 8 = 0$ 或 $x - 5 = 0$，也就是 $x = -8$ 或 $x = 5$。兩個解都要代回原式驗算：$x = 5$ 時 $5 \times 8 = 40$，成立；$x = -8$ 時 $(-8) \times (-5) = 40$，也成立。可是寬不可能是負的，所以菜圃的寬是 5 公尺。方程式的解是否符合題目的條件，要另外檢查。

二次方程式最多有兩個解，因為分解後最多有兩個因式，每個因式只讓一個 $x$ 的值等於 0。一元二次方程式的解，有的書也稱為根（root）；本站一律寫「解」。

### 為什麼右邊一定要先是 0

$(x - 2)(x - 3) = 6$ 不能寫成 $x - 2 = 6$ 或 $x - 3 = 6$。乘積是 6 的兩個數有很多組，例如 $2 \times 3$、$1 \times 6$、$(-1) \times (-6)$，沒有哪個因數被固定住。要先展開並整理成右邊是 0，才能分解。

### 用平方根解 $x^2 = k$

有一類二次方程式，左邊只有 $x^2$，不需要分解。$x^2 = 9$ 是問：什麼數平方等於 9？這正是 9 的平方根（見[平方根與根式](/units/square-roots/)），有兩個：3 與 $-3$，所以 $x = 3$ 或 $x = -3$。合寫成 $x = \pm 3$，讀作「x 等於正負 3」。

這和因式分解的結果一致：$x^2 - 9 = 0$ 分解成 $(x + 3)(x - 3) = 0$，也得到 $x = -3$ 或 $x = 3$。

$k$ 是正數的時候，$x^2 = k$ 的解是 $x = \sqrt{k}$ 或 $x = -\sqrt{k}$。不是完全平方數的時候就保留 √ 的寫法，例如 $x^2 = 7$ 的解是 $x = \pm\sqrt{7}$，$\sqrt{7} \approx 2.646$。$k = 0$ 時只有 $x = 0$。$k$ 是負數時，沒有任何實數平方以後是負的，所以這類方程式在實數裡沒有解。

括號平方也一樣：$(x - 1)^2 = 16$，把 $x - 1$ 當成一個整體，$x - 1 = 4$ 或 $x - 1 = -4$，所以 $x = 5$ 或 $x = -3$。

### 兩個解與重根

兩個解的寫法要固定：用「或」連起來，寫成 $x = 2$ 或 $x = 3$，不要寫成 $x = 2, 3$。因為這兩個值不是同時成立，而是任選一個代入，等式都成立。驗算的時候，也要把兩個值分別代回原式，各驗一次。

最後看兩個解相同的情形。$x^2 - 4x + 4 = 0$ 分解是 $(x - 2)(x - 2) = 0$，兩個因式一樣，所以只有一個值 $x = 2$。這種情形寫成「$x = 2$（重根）」，表示兩個解重疊在一起，只寫一次。

## 範例

下面的範例從完整示範開始，逐步把步驟留給你。每個範例最後都把解代回原式驗算，二次方程式的兩個解都要驗。

### 範例一：因式分解解法（完整範例）

解 $x^2 - 5x + 6 = 0$。

$$
\begin{aligned}
x^2 - 5x + 6 &= 0 \\
(x - 2)(x - 3) &= 0 && \quad\text{（乘起來是 6、加起來是 }-5\text{）}
\end{aligned}
$$

乘積為零，至少一個因數為零，所以 $x - 2 = 0$ 或 $x - 3 = 0$，也就是 $x = 2$ 或 $x = 3$。

為什麼這步成立？

<Answer>
右邊是 0，兩個因式相乘等於 0，所以其中一個一定是 0；如果右邊不是 0，就不能這樣拆。見「推理」段第一、三節。
</Answer>

驗算：$x = 2$ 時，$4 - 10 + 6 = 0$，成立；$x = 3$ 時，$9 - 15 + 6 = 0$，成立。

### 範例二：開平方（範例與練習配對）

先看示範：$x^2 = 25$。25 的平方根是 5 與 $-5$，所以 $x = 5$ 或 $x = -5$。驗算：$5^2 = 25$，$(-5)^2 = 25$。

換你：$2x^2 = 18$。

<Answer>
$2x^2 = 18$，兩邊同除以 2，得 $x^2 = 9$，所以 $x = 3$ 或 $x = -3$。驗算：$2 \times 3^2 = 18$，$2 \times (-3)^2 = 18$，兩個都成立。
</Answer>

### 範例三：右邊不是 0（留空最後一步）

解 $x^2 + 2x = 15$。

$$
\begin{aligned}
x^2 + 2x &= 15 \\
x^2 + 2x - 15 &= 0 && \quad\text{（兩邊同減 15）} \\
(x + 5)(x - 3) &= 0 && \quad\text{（乘起來是 }-15\text{、加起來是 2）}
\end{aligned}
$$

為什麼要先讓右邊變成 0？

<Answer>
因為只有乘積是 0 的時候，才能說其中一個因式是 0。兩邊同減 15，是兩邊做同樣的事，等式仍然成立。見「推理」段第三節。
</Answer>

最後一步留給你：讓每個因式等於 0，寫出兩個解，並驗算。

<Answer>
$x + 5 = 0$ 或 $x - 3 = 0$，所以 $x = -5$ 或 $x = 3$。驗算：$x = -5$ 時，$25 - 10 = 15$；$x = 3$ 時，$9 + 6 = 15$，兩個都成立。
</Answer>

### 範例四：花圃的寬（留空最後兩步）

長方形花圃的長比寬多 2 公尺，面積是 24 平方公尺，求寬。

第一步，設寬為 $x$ 公尺，則長是 $(x + 2)$ 公尺。列式 $x(x + 2) = 24$，展開整理（兩邊同減 24）得 $x^2 + 2x - 24 = 0$。

為什麼這步成立？

<Answer>
長方形的面積是長乘以寬，所以 $x(x + 2) = 24$。把括號展開得到 $x^2 + 2x = 24$，兩邊同減 24 讓右邊變成 0。見「推理」段第二、三節。
</Answer>

最後兩步留給你：分解並求出 $x$，驗算並用一句話回答原題。

<Answer>
$(x + 6)(x - 4) = 0$（乘起來是 $-24$、加起來是 2），所以 $x = -6$ 或 $x = 4$。驗算：$x = 4$ 時，長是 6，$4 \times 6 = 24$；$x = -6$ 時，$(-6) \times (-4) = 24$，也滿足方程式，可是寬不可能是負的，捨去。所以花圃的寬是 4 公尺（長 6 公尺）。
</Answer>

### 範例五：重根（獨立解題）

解 $x^2 - 6x + 9 = 0$。想想看有哪些做法，先自己試，再看下面兩種解法。

<Answer>
解法一，因式分解：乘起來是 9、加起來是 $-6$ 的兩個數是 $-3$ 與 $-3$，$(x - 3)(x - 3) = 0$，所以 $x = 3$（重根）。

解法二，看出完全平方：$x^2 - 6x + 9 = (x - 3)^2$，所以 $(x - 3)^2 = 0$，開平方得 $x - 3 = 0$，$x = 3$（重根）。

比較：解法二看出 $9$ 是 $3$ 的平方、$6$ 是 $2 \times 3$ 時最快；看不出來時，解法一的做法一定可行。兩種做法得到同一個解。

驗算：$x = 3$ 時，$9 - 18 + 9 = 0$，成立。
</Answer>

## 常見迷思

**迷思一：兩邊同除以 $x$**。看到兩邊都有 $x$，就想約掉一個。

<Misconception>

$x^2 = 3x$，兩邊同除以 $x$，得 $x = 3$。

---

$x^2 = 3x$ 先整理成 $x^2 - 3x = 0$，再分解 $x(x - 3) = 0$，所以 $x = 0$ 或 $x = 3$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
$x = 0$ 也是這個方程式的解：$0^2 = 0 = 3 \times 0$。兩邊同除以 $x$ 的時候，默默假設了 $x$ 不是 0；除數不能是 0，所以 $x = 0$ 這個解就被丟掉了。正確做法是移到一邊分解，不要除。驗算：$x = 0$ 時，$0 = 0$；$x = 3$ 時，$9 = 9$，兩個都成立。
</Answer>

診斷題：解 $5x^2 = 10x$。

<Answer>
$x = 0$ 或 $x = 2$。整理成 $5x^2 - 10x = 0$，提公因式 $5x(x - 2) = 0$，所以 $x = 0$ 或 $x = 2$。答 $x = 2$ 的，是兩邊同除了 $x$。驗算：$x = 0$ 時，$0 = 0$；$x = 2$ 時，$5 \times 4 = 20$，$10 \times 2 = 20$。
</Answer>

**迷思二：右邊不是 0 也拆開**。看到兩個因式相乘，就讓每一個因式等於右邊的數。

<Misconception>

$(x - 1)(x - 2) = 6$，所以 $x - 1 = 6$ 或 $x - 2 = 6$。

---

先展開整理成 $x^2 - 3x - 4 = 0$，分解成 $(x - 4)(x + 1) = 0$，所以 $x = 4$ 或 $x = -1$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
「乘積為零」只在乘積是 0 的時候才能拆。乘積是 6 的兩個數有很多組，不能說其中一個就是 6。檢查：由 $x - 1 = 6$ 得 $x = 7$，代入 $(7 - 1)(7 - 2) = 30$，不是 6。正確的兩個解：$x = 4$ 時 $3 \times 2 = 6$；$x = -1$ 時 $(-2) \times (-3) = 6$，都成立。
</Answer>

診斷題：解 $(x + 2)(x - 3) = 14$。

<Answer>
$x = 5$ 或 $x = -4$。展開整理：$x^2 - x - 6 = 14$，兩邊同減 14 得 $x^2 - x - 20 = 0$，分解 $(x - 5)(x + 4) = 0$。答 $x = 12$ 或 $x = 17$ 的，是讓每個因式等於 14。驗算：$x = 5$ 時，$7 \times 2 = 14$；$x = -4$ 時，$(-2) \times (-7) = 14$，都成立。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。卡住時，先問：右邊是 0 嗎？左邊分解得了嗎？

1. 解 $(x - 4)(x + 1) = 0$。

<Answer>
$x = 4$ 或 $x = -1$。讓每個因式等於 0。驗算：$x = 4$ 時，$0 \times 5 = 0$；$x = -1$ 時，$(-5) \times 0 = 0$。
</Answer>

2. 因式分解 $x^2 + 8x + 15$。

<Answer>
$(x + 3)(x + 5)$。乘起來是 15、加起來是 8。檢查：$x^2 + 5x + 3x + 15 = x^2 + 8x + 15$。
</Answer>

3. 解 $x^2 - 10x + 25 = 0$。

<Answer>
$x = 5$（重根）。$(x - 5)^2 = 0$。驗算：$25 - 50 + 25 = 0$。
</Answer>

4. 解 $3x^2 = 27$。

<Answer>
$x = 3$ 或 $x = -3$。兩邊同除以 3 得 $x^2 = 9$。驗算：$3 \times 9 = 27$，$3 \times (-3)^2 = 27$。
</Answer>

5. $\sqrt{25}$ 是多少？25 的平方根有哪些？

<Answer>
$\sqrt{25} = 5$；25 的平方根是 5 與 $-5$。$\sqrt{\ }$ 只指正的那個。
</Answer>

6. 解 $x^2 + 2x = 24$。

<Answer>
$x = -6$ 或 $x = 4$。整理成 $x^2 + 2x - 24 = 0$，分解 $(x + 6)(x - 4) = 0$。驗算：$x = -6$ 時，$36 - 12 = 24$；$x = 4$ 時，$16 + 8 = 24$。
</Answer>

7. 解 $3x^2 = 12x$。

<Answer>
$x = 0$ 或 $x = 4$。整理成 $3x^2 - 12x = 0$，$3x(x - 4) = 0$。驗算：$x = 0$ 時，$0 = 0$；$x = 4$ 時，$3 \times 16 = 48$，$12 \times 4 = 48$。
</Answer>

8. 因式分解 $2x^2 + 5x + 3$。

<Answer>
$(2x + 3)(x + 1)$。$a \times c = 6$，加起來是 5 的是 2 和 3。檢查：展開 $2x^2 + 2x + 3x + 3 = 2x^2 + 5x + 3$。
</Answer>

9. 解 $(x - 2)^2 = 25$。

<Answer>
$x = 7$ 或 $x = -3$。$x - 2 = 5$ 或 $x - 2 = -5$。驗算：$x = 7$ 時，$5^2 = 25$；$x = -3$ 時，$(-5)^2 = 25$。
</Answer>

10. 兩個連續正整數的乘積是 56，這兩個數是多少？

<Answer>
7 與 8。設較小的數為 $n$，另一個是 $n + 1$，列式 $n(n + 1) = 56$，整理成 $n^2 + n - 56 = 0$，分解 $(n + 8)(n - 7) = 0$，所以 $n = -8$ 或 $n = 7$。題目要正整數，捨去 $-8$。驗算：$7 \times 8 = 56$。
</Answer>

## 提取題

不看前面的內容，憑記憶回答。

1. 為什麼 $(x - 2)(x - 3) = 0$ 可以推出 $x = 2$ 或 $x = 3$，但 $(x - 2)(x - 3) = 6$ 不行？

<Answer>
兩個數相乘等於 0 時，如果其中一個不是 0，另一個除下去就一定是 0，所以至少有一個是 0。乘積是 6 的話，兩個因數可以有很多種配法，沒有哪一個被固定，所以要先整理成右邊是 0。
</Answer>

2. 解 $x^2 = 3x$，並說明為什麼不能兩邊同除以 $x$。

<Answer>
$x = 0$ 或 $x = 3$。同除以 $x$ 默默假設 $x$ 不是 0，會漏掉 $x = 0$。正確做法：$x^2 - 3x = 0$，$x(x - 3) = 0$。
</Answer>

3. $x^2 = 9$ 的解怎麼寫？

<Answer>
$x = 3$ 或 $x = -3$，也可以合寫成 $x = \pm 3$。9 有兩個平方根。
</Answer>

4. 什麼時候要在解後面寫「（重根）」？舉一個例子。

<Answer>
兩個因式相同、兩個解重疊的時候，只寫一次並註明重根。例如 $x^2 - 6x + 9 = (x - 3)^2 = 0$，解是 $x = 3$（重根）。
</Answer>
