## 情境開場

潛水員在海面下 3 公尺的地方檢查設備，一隻海鷗停在海面上 5 公尺高的燈桿頂端。你問朋友：「他們兩個離多遠？」朋友想了想：「5 減 3，應該是 2 公尺。」另一個朋友搖頭：「拉一條繩子從潛水員到海鷗，繩子要 8 公尺長。」

繩子的長度不分方向，從潛水員量到海鷗，和從海鷗量到潛水員，都是同一條繩子，不可能一邊是 8 公尺、另一邊是負八公尺。可是算式的減法有先後：用海鷗的高度減去潛水員的高度，和用潛水員的高度減去海鷗的高度，結果一正一負。

要讓算式也算出「不分方向的長度」，需要一個專門的記號。這個單元要回答的核心問題是：為什麼 |a−b| 剛好是數線上兩點的距離？

## 先修回顧

這個單元的先修是[負數：比零還少](/units/negative-numbers/)和[用字母代表數](/units/variables/)。下面三題不計時、不計分，卡住就回去補一下。

1. 在數線上，$-5$ 和 $-2$ 哪一個比較大？

<Answer>
$-2$ 比較大。數線上越右邊的數越大，$-2$ 在 $-5$ 的右邊。答 $-5$ 的，是看到 5 比 2 大，忘了負數是往 0 的左邊延伸。
</Answer>

2. $-4$ 在 0 的哪一邊？它和 0 之間隔了幾格？

<Answer>
在 0 的左邊，隔了 4 格。負數都在 0 的左邊，數字部分告訴你離 0 幾格。
</Answer>

3. $a$ 代表 6，$b$ 代表 4，$a - b$ 是多少？

<Answer>
2。字母代表一個數，把 6 和 4 換進去，$6 - 4 = 2$。
</Answer>

## 直覺

我們沿用潛水員和海鷗的情境，依序看情境、圖和符號。先把海面當成 0，海面上是正、海面下是負：潛水員在 $-3$，海鷗在 5。

### 一個數離 0 多遠

先問比較簡單的問題：一個數離 0 有多遠？如果潛水員在海面下 4 公尺，他在數線上就是 $-4$，從 $-4$ 到 0 隔了 4 格。

<Figure caption="括號只量長度，不管這個數在 0 的哪一邊">
  <NumberLine title="−4 離 0 多遠" desc="負五到 5 的數線，每一格是 1。負四有一個點，從負四到 0 的下方有括號，標著負四的絕對值等於 4，表示跨過 4 格。" from={-5} to={5} points={[{ at: -4 }]} spans={[{ from: -4, to: 0, label: "|−4| = 4" }]} />
</Figure>

一個數在數線上到 0 的距離，叫做這個數的絕對值（absolute value）。$a$ 的絕對值寫成 $|a|$，讀作「a 的絕對值」。所以 $|-4| = 4$，讀作「負四的絕對值等於 4」。同樣地，$|4| = 4$（4 和 $-4$ 離 0 一樣遠），$|0| = 0$。距離不會是負的，所以絕對值一定不是負數。

把三種說法對起來：情境說「潛水員離海面 4 公尺」，圖說「括號從點量到 0，跨過 4 格」，符號說 $|-4| = 4$。三句話講的是同一件事，差別只在寫法。從這裡也看得出來，絕對值只關心「離 0 多遠」，不關心在 0 的哪一邊，所以 $-4$ 和 4 的絕對值相同。

### 兩個點相距多遠

回到最初的問題。潛水員在 $-3$，海鷗在 5，括號從 $-3$ 量到 5，跨過 8 格。

<Figure caption="注意括號跨過了 0：左邊一段 3 格，右邊一段 5 格" note="情境裡的 8 公尺、括號跨過的 8 格、算式的結果 8，說的是同一件事。">
  <NumberLine title="潛水員與海鷗" desc="負五到 5 的數線，每一格是 1。負三和 5 各有一個點，負三是潛水員，5 是海鷗；兩點下方有括號，跨過 8 格，標著 5 減負三的絕對值等於 8。" from={-5} to={5} points={[{ at: -3 }, { at: 5 }]} spans={[{ from: -3, to: 5, label: "|5 − (−3)| = 8" }]} />
</Figure>

用算式表示：海鷗的高度減去潛水員的高度，

$$
5 - (-3) = 5 + 3 = 8
$$

這裡用到[負數加減](/units/integer-add-sub/)學過的結論：減去 $-3$ 等於加上 3。反過來，潛水員的高度減去海鷗的高度是 $-3 - 5 = -8$。距離是 8，不是 $-8$，所以把差取絕對值。

兩個點 $a$ 和 $b$ 的距離寫成 $|a - b|$，讀作「a 減 b 的絕對值」。取 $a = 5$、$b = -3$，就得到 $|5 - (-3)| = 8$；把兩個點對調，$|-3 - 5| = |-8| = 8$，結果一樣。

## 推理

### 為什麼負數的絕對值是 $-a$

$a$ 在數線上有三種位置。$a$ 在 0 的右邊（正數）時，它到 0 的距離就是 $a$ 自己。$a$ 就是 0 時，距離是 0。$a$ 在 0 的左邊（負數）時，要從 $a$ 往右走到 0，走的格數是 $0 - a$，也就是 $-a$。例如 $a = -4$，$-a = -(-4) = 4$，正好是剛才量出的 4 格。

$$
|a| = \begin{cases} a, & a \ge 0 \\ -a, & a < 0 \end{cases}
$$

這個式子的意思是：$a$ 不小於 0 時，$|a|$ 就是 $a$；$a$ 小於 0 時，$|a|$ 是 $-a$。這裡的 $-a$ 是「$a$ 的相反數」，不是「一個負數」：$a$ 是 $-4$ 時，$-a$ 是 4，是正數。

換句話說，遇到絕對值，第一個問題永遠是「裡面這個數在 0 的哪一邊」。在右邊就原樣留下，在左邊就換成它的相反數。兩種情形得到的都是正數或 0，也就是一段不分方向的長度。

這也說明為什麼絕對值不能靠「擦掉負號」。$a$ 是字母時，你看不出它是正還是負，$-a$ 前面那個負號也不一定代表負的。要判斷怎麼處理，只能看 $a$ 在 0 的哪一邊。

### 為什麼 $|a - b|$ 是兩點的距離

假設 $b$ 在 $a$ 的右邊。從 $a$ 往右走 $d$ 格會到 $b$，意思是 $b$ 比 $a$ 多 $d$，所以 $d = b - a$，這時 $b - a$ 是正數，剛好是距離。如果 $b$ 在 $a$ 的左邊，把兩點的角色對調，距離是 $a - b$，而 $b - a$ 是它的相反數，是負數。

兩種情形，距離都是 $b - a$ 與 $a - b$ 之中不是負數的那一個。挑出不是負數的那一個，正是絕對值做的事，所以 $|a - b|$ 與 $|b - a|$ 是同一個數，就是兩點的距離。兩點重合（$a = b$）時，差是 0，距離也是 0，一樣成立。

$|a|$ 其實是特例：$b$ 取 0，$|a - 0| = |a|$，就是 $a$ 到 0 的距離。所以「到 0 的距離」和「兩點的距離」不是兩個概念，而是同一個概念：前者只是把其中一個點固定在 0。

回到開場的問題，朋友算出 2 公尺，是因為把潛水員的 $-3$ 當成了 3，兩個點被擺到 0 的同一側。海鷗和潛水員在 0 的兩側，兩段距離要相加，這件事用 $|a - b|$ 會自動處理好。

## 範例

下面的範例從完整示範開始，逐步把步驟留給你。每個範例最後都回頭檢查一次。檢查的方法都一樣：回到數線上，數一數兩點之間隔了幾格。這個做法不需要記任何公式，算式有沒有寫對，用數線一看就知道。

### 範例一：數線上兩點的距離（完整範例）

求數線上 $-6$ 與 2 的距離。

第一步，一個點減另一個點，再取絕對值：$|2 - (-6)|$。

為什麼這步成立？

<Answer>
從 $-6$ 走到 2 是往右走，走的格數就是 2 比 $-6$ 多多少，也就是 $2 - (-6)$。取絕對值，是因為不管誰減誰，我們要的都是不分方向的長度（見「推理」）。
</Answer>

第二步，減去 $-6$ 等於加上 6：$|2 - (-6)| = |2 + 6| = |8| = 8$。

回頭檢查：數線上從 $-6$ 走到 0 是 6 格，再從 0 走到 2 是 2 格，$6 + 2 = 8$。對調兩點，$|-6 - 2| = |-8| = 8$，結果一樣。

### 範例二：潛水員和海鷗再算一次（範例與練習配對）

先看示範：$|-3 - 5|$。先算裡面，$-3 - 5 = -3 + (-5) = -8$，再取絕對值，$|-8| = 8$。回頭檢查：這就是潛水員和海鷗的距離，和圖上括號跨過的 8 格相同。

換你：$|-2 - 7|$。

<Answer>
$-2 - 7 = -2 + (-7) = -9$，$|-9| = 9$。回頭檢查：$-2$ 到 0 是 2 格，0 到 7 是 7 格，$2 + 7 = 9$。
</Answer>

### 範例三：字母的絕對值（留空最後一步）

已知 $a = -5$，求 $|a|$、$-a$ 和 $|-a|$。

第一步，$|a| = |-5| = 5$。

第二步，$-a = -(-5) = 5$。

為什麼這步成立？

<Answer>
$-a$ 的意思是「$a$ 的相反數」，不是「一個負數」。$a$ 是 $-5$，它的相反數是 5，兩個數在數線上對稱於 0。$a$ 是負數時 $-a$ 是正數，所以前面才說 $|a| = -a$。
</Answer>

最後一步留給你：算出 $|-a|$，並回頭檢查。

<Answer>
$|-a| = |5| = 5$。回頭檢查：$a$ 和 $-a$ 對稱於 0，離 0 一樣遠，所以 $|-a| = |a| = 5$，兩邊一致。
</Answer>

### 範例四：氣溫差幾度（留空最後兩步）

昨天的氣溫是 $-3$ 度，今天是 $-8$ 度。兩天的氣溫差幾度（不管升或降）？

第一步，把兩個氣溫看成數線上的兩個點，距離是 $|-8 - (-3)|$。

為什麼這步成立？

<Answer>
氣溫也是數線上的點，差幾度就是兩點的距離，所以用 $|a - b|$。兩個數都是負數也一樣，取絕對值就保證結果不是負數，不必先判斷誰比較低。
</Answer>

最後兩步留給你：把減去 $-3$ 改成加上 3，算出結果，並回頭檢查。

<Answer>
$-8 - (-3) = -8 + 3 = -5$，$|-5| = 5$，差 5 度。回頭檢查：數線上從 $-3$ 往左數 5 格，剛好是 $-8$。
</Answer>

### 範例五：捷運站的高度（獨立解題）

捷運月台在地面下 8 公尺，連通的天橋在地面上 4 公尺，兩者的垂直距離是多少？想想看有哪些算法，先自己試，再看下面的解法。

<Answer>
解法一，用公式：把地面當成 0，月台是 $-8$，天橋是 4，$|4 - (-8)| = |4 + 8| = 12$。

解法二，用數線：從 $-8$ 走到 0 是 8 格，從 0 走到 4 是 4 格，$8 + 4 = 12$。

解法三，對調兩點：$|-8 - 4| = |-12| = 12$，結果一樣。

比較：兩點在 0 的兩側時，兩段距離相加，$|-8| + |4| = 12$。兩點在 0 的同一側時（例如上一題的 $-3$ 和 $-8$），改成相減，$|-8| - |-3| = 5$。到底該相加還是相減，要先判斷兩點在不在 0 的兩側；解法一用 $|a - b|$ 不必判斷，兩種情形都對。

回頭檢查：地下 8 公尺加上地上 4 公尺是 12 公尺，合理。
</Answer>

## 常見迷思

**迷思一：絕對值就是把負號拿掉**。因為 $|-4| = 4$，看起來像是「擦掉負號」，於是把這個做法用在所有的式子上。

<Misconception>

絕對值就是把負號拿掉：$|-x| = x$，$|-3 + 5| = 3 + 5 = 8$。

---

絕對值是到 0 的距離，要先算出裡面的數，再看它離 0 多遠：$|-3 + 5| = |2| = 2$。$x$ 是 $-2$ 時，$-x$ 是 2，$|-x| = |2| = 2$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
$|-3 + 5|$ 不能只拿掉 3 前面的負號，裡面要先算成 2，再看 2 到 0 的距離。$|-x| = x$ 更站不住：$x$ 是 $-2$ 時，右邊是 $-2$，絕對值卻不可能是負數。字母看不出正負，「擦掉負號」根本無從做起；「看它離 0 多遠」則永遠做得到。
</Answer>

診斷題：$x$ 是 $-2$ 時，$|x|$ 和 $|-x|$ 各是多少？

<Answer>
都是 2。$|x| = |-2| = 2$；$-x = 2$，$|-x| = |2| = 2$。答 $|-x| = -2$ 的，是把負號拿掉，以為得到 $x$。
</Answer>

**迷思二：算出來的差是負的，距離就是負的**。潛水員的故事裡，用 $-3 - 5$ 得到 $-8$，就以為距離是 $-8$。

<Misconception>

$-3$ 和 5 的距離是 $-3 - 5 = -8$，所以距離是 $-8$。

---

$-8$ 只表示用 $-3$ 減 5 的結果，距離是長度，不會是負的：$|-3 - 5| = 8$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
距離是繩子的長度，沒有方向，也不可能是負的。$-3 - 5$ 這個差有方向：負號只說明 $-3$ 比 5 小。要的是不分方向的長度，所以取絕對值。
</Answer>

診斷題：下面哪些式子的值可以當作 $-2$ 與 $-9$ 的距離？(a) $-2 - (-9)$；(b) $-9 - (-2)$；(c) $|-2 - (-9)|$；(d) $|-9 - (-2)|$。

<Answer>
(a)、(c)、(d)，三個都是 7。(b) 是 $-9 + 2 = -7$，不是距離。(a) 只是剛好把大的減小的，運氣好才是正數；(c)、(d) 取了絕對值，不必先判斷誰大。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。卡住時，先想想這個數或這兩個點在數線上的位置。

1. 計算 $|-9|$、$|9|$ 和 $|0|$。

<Answer>
9、9、0。$-9$ 和 9 離 0 一樣遠，0 離 0 的距離是 0。
</Answer>

2. 把 $-7$、4、$-1$、0 由小到大排列。

<Answer>
$-7 < -1 < 0 < 4$。越往右越大：$-7$ 在最左邊，其次是 $-1$，然後是 0，最右邊是 4。
</Answer>

3. 數線上 $-5$ 與 3 相距幾格？

<Answer>
8 格。$|3 - (-5)| = |3 + 5| = 8$。回頭檢查：$-5$ 到 0 是 5 格，0 到 3 是 3 格，$5 + 3 = 8$。
</Answer>

4. 計算 $|2 - 11|$。

<Answer>
9。先算裡面，$2 - 11 = -9$，再取絕對值，$|-9| = 9$。回頭檢查：2 和 11 在數線上相距 9 格。
</Answer>

5. $x$ 是 $-6$，求 $|x|$、$-x$ 和 $|-x|$。

<Answer>
6、6、6。$|x| = |-6| = 6$；$-x = 6$；$|-x| = |6| = 6$。答 $-x$ 是 $-6$ 的，是以為 $-x$ 一定是負數。
</Answer>

6. 計算 $-4 - (-10)$。

<Answer>
6。減去 $-10$ 等於加上 10，$-4 + 10 = 6$。答 $-14$ 的，是把減去負數當成再往左走。
</Answer>

7. 氣溫從 $-3$ 度降到 $-10$ 度，溫度下降了幾度？

<Answer>
7 度。$|-10 - (-3)| = |-7| = 7$。回頭檢查：數線上從 $-3$ 往左數 7 格是 $-10$。
</Answer>

8. 一個便當 $x$ 元，買 3 個再加 10 元外送費，一共多少元？$x$ 是 90 時是多少元？

<Answer>
$3x + 10$ 元，其中 $3x$ 就是 $3 \times x$。$x = 90$ 時，$3 \times 90 + 10 = 280$ 元。
</Answer>

9. $a$ 是什麼數時 $|a| = a$？什麼數時 $|a| = -a$？

<Answer>
$a \ge 0$ 時 $|a| = a$，$a \le 0$ 時 $|a| = -a$。$a$ 是 0 時兩個都對，因為 $-0 = 0$。這就是「推理」那個分成兩種情形的式子。
</Answer>

## 提取題

不看前面的內容，憑記憶回答。

1. $|a|$ 是什麼意思？它可以是負數嗎？

<Answer>
$|a|$ 是 $a$ 在數線上到 0 的距離。距離不會是負的，所以絕對值一定不是負數。
</Answer>

2. $a$ 是負數時，$|a|$ 等於什麼？為什麼不能說「把負號拿掉」？

<Answer>
$|a| = -a$，也就是 $a$ 的相反數。$-a$ 的負號不是「負的」，而是「相反數」；$a$ 是字母時看不出正負，沒有負號可以拿掉。
</Answer>

3. 數線上兩點 $a$、$b$ 的距離怎麼寫？為什麼要取絕對值？

<Answer>
寫成 $|a - b|$。差 $a - b$ 可能是負數，而距離是不分方向的長度，取絕對值就得到不是負數的那一個。
</Answer>

4. 計算 $|-3 + 5|$。

<Answer>
2。先算 $-3 + 5 = 2$，再取絕對值，$|2| = 2$。
</Answer>
