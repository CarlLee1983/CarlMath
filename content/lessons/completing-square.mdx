## 情境開場

學校想在一塊正方形的花圃旁邊鋪步道：花圃的右邊鋪一條寬 3 公尺的步道，花圃的下邊也鋪一條寬 3 公尺的步道，兩條步道交會的右下角那一小塊先留空，不鋪。花圃加上兩條步道，一共佔地 16 平方公尺。

工務組只拿到這個總面積，想知道花圃的邊長。你把圖畫出來，發現這個圖形像一個大正方形被咬掉了右下角。如果把缺的那一角補上，圖形就會變得很整齊。

補上的那一塊要多大？補了以後，原本的問題要怎麼跟著改？這個單元要回答的核心問題是：不能因式分解的二次方程式要怎麼解？

## 先修回顧

這個單元的先修是[一元二次方程式](/units/quadratic-equations/)。下面三題不計時、不計分，卡住的話回去看那個單元再回來。

1. 解 $(x - 1)(x + 4) = 0$。

<Answer>
$x = 1$ 或 $x = -4$。乘積為零，至少一個因數為零。驗算：$x = 1$ 時，$0 \times 5 = 0$；$x = -4$ 時，$(-5) \times 0 = 0$。
</Answer>

2. 解 $x^2 = 7$。

<Answer>
$x = \sqrt{7}$ 或 $x = -\sqrt{7}$，合寫成 $x = \pm\sqrt{7}$。7 有兩個平方根，互為相反數。驗算：$(\sqrt{7})^2 = 7$，$(-\sqrt{7})^2 = 7$。
</Answer>

3. 解 $(x + 3)^2 = 25$。

<Answer>
$x = 2$ 或 $x = -8$。$x + 3 = 5$ 或 $x + 3 = -5$。驗算：$x = 2$ 時，$5^2 = 25$；$x = -8$ 時，$(-5)^2 = 25$。
</Answer>

## 直覺

用 $x$ 代表花圃的邊長（單位是公尺）。花圃是邊長 $x$ 的正方形，面積 $x^2$；右邊的步道寬 3、長 $x$，面積 $3x$；下邊的步道也是 $3x$。三塊的面積合計是 $x^2 + 6x$，列成方程式就是

$$
x^2 + 6x = 16
$$

### 圖解：補上缺的一角

把花圃、右邊步道、下邊步道排成一個大正方形，缺的就是右下角那一格。

<Figure caption="三塊實線格是 x² + 6x，虛線框的右下角是缺的一格" note="缺的一格是 3 乘 3，面積是 9。把它補上，整個圖形就是邊長 x 加 3 的正方形。">
  <AreaModel title="缺了一角的正方形" desc="一個正方形，橫邊和縱邊都拆成 x 和 3 兩段，字母 x 的長度只是示意，不按比例。左上格面積是 x²，右上格面積是 3x，左下格面積是 3x。右下角是缺的一格，用虛線框表示，面積是 9。" cols={["x", 3]} rows={["x", 3]} areas={[["x²", "3x"], ["3x", null]]} missing={[1, 1]} />
</Figure>

補上缺的 9，大正方形的邊長是 $x + 3$，面積是 $(x + 3)^2$：

$$
x^2 + 6x + 9 = (x + 3)^2
$$

這個式子讀作「x 的平方加 6x 加 9，等於 x 加 3 的平方」。這個把缺角補成完整正方形的做法，叫做配方法（completing the square）。補上的 9 不是亂選的：兩條步道各寬 3，3 剛好是 6 的一半，缺的那一格邊長 3，面積 $3^2 = 9$。

情境、圖和符號三者是一一對應的：花圃加步道是三塊實線格；右下角的虛線框是缺的 $3^2 = 9$；補上以後的大正方形，邊長就是式子裡的 $x + 3$。

## 推理

### 配方法的步驟

配方，就是把 $x^2 + bx$ 補成 $x + \frac{b}{2}$ 的平方。補的數是 $b$ 的一半的平方，用展開檢查：

$$
\left(x + \frac{b}{2}\right)^2 = x^2 + 2 \times \frac{b}{2} \times x + \left(\frac{b}{2}\right)^2 = x^2 + bx + \left(\frac{b}{2}\right)^2
$$

所以 $x^2 + bx$ 還差 $\left(\frac{b}{2}\right)^2$ 就是完全平方。$b = 6$ 的時候，$\left(\frac{6}{2}\right)^2 = 9$，和圖上缺的那一格一樣。

為什麼是「一半」的平方？因為 $bx$ 是兩條長條，一條放在正方形右邊，一條放在下面，每一條的寬是 $b$ 的一半。兩條長條交會的角落是一個邊長 $\frac{b}{2}$ 的小正方形，它的面積就是 $\left(\frac{b}{2}\right)^2$。一次項係數是多少，補的數就跟著變，每次都是一半的平方，不需要去背某個固定的數。

用配方法解方程式，步驟是：

1. 兩邊做同樣的事，讓左邊只剩 $x^2$ 和 $x$ 的項，常數項移到右邊。
2. 如果 $x^2$ 前面不是 1，兩邊同除以它。
3. 兩邊同加一次項係數一半的平方。
4. 左邊寫成完全平方，右邊算出一個數。
5. 開平方，記得有正負兩個。
6. 解出 $x$，把兩個解都代回原式驗算。

第 3 步一定要兩邊都加。方程式是一架平衡的天平，只在一邊加東西，兩邊就不相等了。

### 對一般式配方，推出公式解

任何一元二次方程式都可以寫成 $ax^2 + bx + c = 0$，其中 $a$ 不是 0。用上面的步驟，對這個式子配方一次：

$$
\begin{aligned}
ax^2 + bx + c &= 0 \\
x^2 + \frac{b}{a}x + \frac{c}{a} &= 0 && \quad\text{（兩邊同除以 a）} \\
x^2 + \frac{b}{a}x &= -\frac{c}{a} && \quad\text{（兩邊同減 c/a）} \\
x^2 + \frac{b}{a}x + \frac{b^2}{4a^2} &= \frac{b^2}{4a^2} - \frac{c}{a} && \quad\text{（一次項係數 b/a 的一半是 b/2a，兩邊同加它的平方）} \\
\left(x + \frac{b}{2a}\right)^2 &= \frac{b^2 - 4ac}{4a^2} && \quad\text{（左邊配成平方，右邊通分）}
\end{aligned}
$$

最後一行右邊通分的理由：$\frac{c}{a} = \frac{4ac}{4a^2}$，所以 $\frac{b^2}{4a^2} - \frac{4ac}{4a^2} = \frac{b^2 - 4ac}{4a^2}$。接著開平方：

$$
x + \frac{b}{2a} = \pm\frac{\sqrt{b^2 - 4ac}}{2a}
$$

這裡右邊的分母 $4a^2$ 開平方是 $2a$（取絕對值也沒關係，因為前面已經有 $\pm$）。兩邊同減 $\frac{b}{2a}$，就得到

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

這個式子叫公式解，讀作「x 等於負 b 加減根號 b 平方減 4ac，再除以 2a」。它不是需要死背的魔法，而是把配方法對一般式做了一次，結果記下來。以後遇到具體的 $a$、$b$、$c$，代進去就好，不必每次重新配方。

用 $x^2 + 6x - 16 = 0$ 檢查：$a = 1$、$b = 6$、$c = -16$，$b^2 - 4ac = 36 + 64 = 100$，$x = \frac{-6 \pm 10}{2}$，得 $x = 2$ 或 $x = -8$，和開頭的花圃算出來一樣。

### $b^2 - 4ac$ 決定有幾個解

公式解裡，$\sqrt{\ }$ 底下的 $b^2 - 4ac$ 決定結果，分三種情形：

- **大於 0**：$\sqrt{b^2 - 4ac}$ 是一個正數，前面的 $\pm$ 給出兩個不同的值，所以有兩個解。
- **等於 0**：$\sqrt{0} = 0$，加減 0 都一樣，只有一個值 $x = \frac{-b}{2a}$，也就是重根。
- **小於 0**：從 $\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}$ 來看，右邊的分母 $4a^2$ 是正數，右邊會是負數；可是任何實數的平方都不會是負的，所以沒有實數滿足這個式子，方程式在實數裡沒有解。這裡的「實數」就是數線上所有的數。

### 怎麼選方法

先看有沒有公因式、能不能因式分解（乘起來、加起來找得到整數）。分解得了，通常最快。分解不了，用配方法或公式解都行：配方法的好處是每一步都看得見圖，公式解的好處是代進去就算，不容易漏步驟。兩種做法本來就是同一件事，所以同一個方程式用哪一種解，答案都相同；選哪一種，看你當下比較不容易出錯。如果係數有分數或負數，代公式時每一個負數都要記得加括號，再仔細算一次 $b^2 - 4ac$，這一步最容易出錯。

## 範例

下面的範例從完整示範開始，逐步把步驟留給你。每個範例最後都把解代回原式驗算，二次方程式的兩個解都要驗。

### 範例一：花圃的邊長（完整範例）

花圃加兩條步道的面積是 16 平方公尺，求花圃的邊長。

第一步，設花圃的邊長為 $x$ 公尺，列式 $x^2 + 6x = 16$。

第二步，配方：

$$
\begin{aligned}
x^2 + 6x &= 16 \\
x^2 + 6x + 9 &= 16 + 9 && \quad\text{（兩邊同加 9）} \\
(x + 3)^2 &= 25 && \quad\text{（左邊是完全平方）}
\end{aligned}
$$

為什麼這步成立？

<Answer>
$6$ 的一半是 3，$3^2 = 9$，就是圖上缺的那一格。補上它，左邊變成邊長 $x + 3$ 的正方形的面積；方程式是平衡的，所以右邊也要加 9。見「直覺」段與「推理」段第一節。
</Answer>

第三步，開平方：$x + 3 = 5$ 或 $x + 3 = -5$，所以 $x = 2$ 或 $x = -8$。

第四步，驗算並回答：$x = 2$ 時，$4 + 12 = 16$，成立；$x = -8$ 時，$64 - 48 = 16$，也成立。可是邊長不可能是負的，捨去。所以花圃的邊長是 2 公尺。

### 範例二：解不是整數（範例與練習配對）

先看示範：解 $x^2 + 4x - 1 = 0$。

$$
\begin{aligned}
x^2 + 4x - 1 &= 0 \\
x^2 + 4x &= 1 && \quad\text{（兩邊同加 1）} \\
x^2 + 4x + 4 &= 1 + 4 && \quad\text{（4 的一半是 2，2 的平方是 4，所以兩邊同加 4）} \\
(x + 2)^2 &= 5 && \quad\text{（左邊是完全平方）}
\end{aligned}
$$

開平方：$x + 2 = \sqrt{5}$ 或 $x + 2 = -\sqrt{5}$，所以 $x = -2 + \sqrt{5}$ 或 $x = -2 - \sqrt{5}$，也可以合寫成 $x = -2 \pm \sqrt{5}$。$\sqrt{5} \approx 2.236$，所以 $x \approx 0.236$ 或 $x \approx -4.236$。

驗算：$x = -2 + \sqrt{5}$ 時，$x^2 = 4 - 4\sqrt{5} + 5 = 9 - 4\sqrt{5}$，$4x = -8 + 4\sqrt{5}$，$x^2 + 4x - 1 = 9 - 8 - 1 = 0$。$x = -2 - \sqrt{5}$ 時，$x^2 = 9 + 4\sqrt{5}$，$4x = -8 - 4\sqrt{5}$，$x^2 + 4x - 1 = 0$。兩個都成立。

換你：解 $x^2 + 2x - 5 = 0$。

<Answer>
$x^2 + 2x = 5$（兩邊同加 5），2 的一半是 1，兩邊同加 $1^2 = 1$：$x^2 + 2x + 1 = 6$，$(x + 1)^2 = 6$，所以 $x = -1 + \sqrt{6}$ 或 $x = -1 - \sqrt{6}$，合寫成 $x = -1 \pm \sqrt{6}$，約 1.449 或 $-3.449$。驗算：$x = -1 + \sqrt{6}$ 時，$x^2 = 7 - 2\sqrt{6}$，$2x = -2 + 2\sqrt{6}$，加起來 $x^2 + 2x = 5$；$x = -1 - \sqrt{6}$ 時，$x^2 = 7 + 2\sqrt{6}$，$2x = -2 - 2\sqrt{6}$，$x^2 + 2x = 5$，兩個都成立。
</Answer>

### 範例三：$b^2 - 4ac$ 大於 0（留空最後一步）

用公式解，解 $3x^2 + 5x - 2 = 0$。

第一步，$a = 3$、$b = 5$、$c = -2$，$b^2 - 4ac = 5^2 - 4 \times 3 \times (-2) = 25 + 24 = 49$。

為什麼這步成立？

<Answer>
$c = -2$ 是負數，所以 $4ac = 4 \times 3 \times (-2) = -24$，減去 $-24$ 等於加上 24。如果沒有把負號算進去，會得到 $25 - 24 = 1$，是錯的。見「推理」段第二節。
</Answer>

第二步，代入公式：$x = \dfrac{-5 \pm \sqrt{49}}{2 \times 3} = \dfrac{-5 \pm 7}{6}$。

最後一步留給你：算出兩個解，並驗算。

<Answer>
$x = \frac{-5 + 7}{6} = \frac{1}{3}$ 或 $x = \frac{-5 - 7}{6} = -2$。$b^2 - 4ac = 49$ 大於 0，所以有兩個不同的解。驗算：$x = \frac{1}{3}$ 時，$3 \times \frac{1}{9} + \frac{5}{3} - 2 = \frac{1}{3} + \frac{5}{3} - 2 = 0$；$x = -2$ 時，$12 - 10 - 2 = 0$，兩個都成立。
</Answer>

### 範例四：$b^2 - 4ac$ 等於 0（留空最後兩步）

用公式解，解 $4x^2 - 12x + 9 = 0$。

第一步，$a = 4$、$b = -12$、$c = 9$，代入公式：$x = \dfrac{-(-12) \pm \sqrt{(-12)^2 - 4 \times 4 \times 9}}{2 \times 4}$。

為什麼這步成立？

<Answer>
公式裡的 $-b$ 是 $b$ 的相反數。$b = -12$ 的相反數是 12，所以寫成 $-(-12)$；負數放進平方和括號時也要加括號，$(-12)^2 = 144$，不是 $-144$。見「推理」段第二節。
</Answer>

最後兩步留給你：算出 $b^2 - 4ac$ 和 $x$，並驗算。

<Answer>
$(-12)^2 = 144$，$4 \times 4 \times 9 = 144$，$b^2 - 4ac = 144 - 144 = 0$，所以 $x = \frac{12 \pm 0}{8} = \frac{3}{2}$，寫成 $x = \frac{3}{2}$（重根）。驗算：$4 \times \frac{9}{4} - 12 \times \frac{3}{2} + 9 = 9 - 18 + 9 = 0$，成立。
</Answer>

### 範例五：$b^2 - 4ac$ 小於 0（獨立解題）

解 $x^2 + 2x + 5 = 0$。想想看有哪些做法，先自己試，再看下面兩種解法。

<Answer>
解法一，公式解：$a = 1$、$b = 2$、$c = 5$，$b^2 - 4ac = 4 - 20 = -16$，小於 0，$\sqrt{-16}$ 在實數裡不存在，所以這個方程式在實數裡沒有解。

解法二，配方法：$x^2 + 2x = -5$，兩邊同加 $1^2 = 1$，$(x + 1)^2 = -4$。平方不可能是負的，沒有實數滿足這個式子，所以沒有解。

比較：公式解只要算一個數 $b^2 - 4ac$，小於 0 就能立刻下結論；配方法能看見為什麼，是因為平方不能是負的。兩種做法的答案相同。

驗算：沒有解可以代入，改檢查左邊永遠不是 0。$x^2 + 2x + 5 = (x + 1)^2 + 4$，而平方不小於 0，所以左邊至少是 4，永遠不會等於 0。
</Answer>

## 常見迷思

**迷思一：配方時只在一邊加**。補上缺的那一格，卻只改了左邊。

<Misconception>

$x^2 + 6x = 16$，左邊加 9：$x^2 + 6x + 9 = 16$，所以 $(x + 3)^2 = 16$，$x + 3 = \pm 4$，$x = 1$ 或 $x = -7$。

---

兩邊都加 9：$x^2 + 6x + 9 = 16 + 9$，所以 $(x + 3)^2 = 25$，$x + 3 = \pm 5$，$x = 2$ 或 $x = -8$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
只在左邊加 9，等號兩邊就不相等了，等於換了一個不同的方程式。檢查：錯誤的解 $x = 1$ 代回原式，$1 + 6 = 7$，不是 16。正確的解 $x = 2$ 時，$4 + 12 = 16$，成立。
</Answer>

診斷題：用配方法解 $x^2 + 4x = 5$。

<Answer>
$x = 1$ 或 $x = -5$。兩邊同加 4：$x^2 + 4x + 4 = 9$，$(x + 2)^2 = 9$，$x + 2 = \pm 3$。答 $x = -2 \pm \sqrt{5}$ 的，是只在左邊加了 4。驗算：$x = 1$ 時，$1 + 4 = 5$；$x = -5$ 時，$25 - 20 = 5$，兩個都成立。
</Answer>

**迷思二：$b$ 是負數時，$-b$ 也是負數**。看到公式裡的 $-b$，就直接把 $b$ 的符號抄過來。

<Misconception>

$2x^2 - 3x - 5 = 0$ 的 $b = -3$，所以公式裡的 $-b = -3$。

---

$-b$ 是 $b$ 的相反數。$b = -3$ 時，$-b = -(-3) = 3$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
公式裡的 $-b$ 是「$b$ 的相反數」，不是「負的 $b$」。$b$ 本身是負數時，它的相反數是正數。用一個簡單的方程式檢查：$x^2 - 5x + 6 = 0$ 的 $b = -5$，解是 2 和 3，公式 $\frac{5 \pm 1}{2}$ 才對，$\frac{-5 \pm 1}{2}$ 會得到 $-2$ 與 $-3$，代回去不成立。
</Answer>

診斷題：用公式解，解 $2x^2 - 3x - 5 = 0$。

<Answer>
$x = \frac{5}{2}$ 或 $x = -1$。$a = 2$、$b = -3$、$c = -5$，$b^2 - 4ac = 9 + 40 = 49$，$x = \frac{-(-3) \pm 7}{4} = \frac{3 \pm 7}{4}$。答 $x = 1$ 或 $x = -\frac{5}{2}$ 的，是把 $-b$ 當成 $-3$。驗算：$x = \frac{5}{2}$ 時，$2 \times \frac{25}{4} - \frac{15}{2} - 5 = \frac{25}{2} - \frac{15}{2} - 5 = 0$；$x = -1$ 時，$2 + 3 - 5 = 0$，兩個都成立。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。卡住時，先問：能因式分解嗎？配方要補的數，兩邊都加了嗎？

1. 用配方法解 $x^2 + 6x + 5 = 0$。

<Answer>
$x = -1$ 或 $x = -5$。$x^2 + 6x = -5$，兩邊同加 9，$(x + 3)^2 = 4$，$x + 3 = \pm 2$。驗算：$x = -1$ 時，$1 - 6 + 5 = 0$；$x = -5$ 時，$25 - 30 + 5 = 0$。
</Answer>

2. 解 $4x^2 = 8x$。

<Answer>
$x = 0$ 或 $x = 2$。整理成 $4x^2 - 8x = 0$，$4x(x - 2) = 0$。不能兩邊同除以 $x$，會漏掉 $x = 0$。驗算：$x = 0$ 時，$0 = 0$；$x = 2$ 時，$16 = 16$。
</Answer>

3. 用配方法解 $x^2 - 8x + 3 = 0$。

<Answer>
$x = 4 + \sqrt{13}$ 或 $x = 4 - \sqrt{13}$，合寫成 $x = 4 \pm \sqrt{13}$。$x^2 - 8x = -3$，8 的一半是 4，兩邊同加 16，$(x - 4)^2 = 13$。驗算：$x = 4 + \sqrt{13}$ 時，$x^2 = 29 + 8\sqrt{13}$，$-8x = -32 - 8\sqrt{13}$，加 3 後 $29 - 32 + 3 = 0$；$x = 4 - \sqrt{13}$ 時，$x^2 = 29 - 8\sqrt{13}$，$-8x = -32 + 8\sqrt{13}$，同樣是 0。
</Answer>

4. 因式分解 $x^2 + x - 12$。

<Answer>
$(x + 4)(x - 3)$。乘起來是 $-12$、加起來是 1：4 與 $-3$。檢查：$x^2 - 3x + 4x - 12 = x^2 + x - 12$。
</Answer>

5. 用公式解，解 $2x^2 + 5x - 3 = 0$。

<Answer>
$x = \frac{1}{2}$ 或 $x = -3$。$b^2 - 4ac = 25 + 24 = 49$，$x = \frac{-5 \pm 7}{4}$。驗算：$x = \frac{1}{2}$ 時，$2 \times \frac{1}{4} + \frac{5}{2} - 3 = 0$；$x = -3$ 時，$18 - 15 - 3 = 0$。
</Answer>

6. 只算 $b^2 - 4ac$，說明 $x^2 - 4x + 5 = 0$ 在實數裡有沒有解。

<Answer>
沒有。$a = 1$、$b = -4$、$c = 5$，$b^2 - 4ac = 16 - 20 = -4$，小於 0。檢查：$x^2 - 4x + 5 = (x - 2)^2 + 1$，至少是 1，不會等於 0。
</Answer>

7. 用公式解，解 $x^2 - 3x - 1 = 0$。

<Answer>
$x = \frac{3 + \sqrt{13}}{2}$ 或 $x = \frac{3 - \sqrt{13}}{2}$，合寫成 $x = \frac{3 \pm \sqrt{13}}{2}$。$b^2 - 4ac = 9 + 4 = 13$。驗算：$x = \frac{3 + \sqrt{13}}{2}$ 時，$x^2 = \frac{22 + 6\sqrt{13}}{4}$，$3x + 1 = \frac{11 + 3\sqrt{13}}{2} = \frac{22 + 6\sqrt{13}}{4}$，所以 $x^2 = 3x + 1$；另一個同理。
</Answer>

8. 解 $(x - 3)^2 = 7$。

<Answer>
$x = 3 + \sqrt{7}$ 或 $x = 3 - \sqrt{7}$，合寫成 $x = 3 \pm \sqrt{7}$。$x - 3 = \pm\sqrt{7}$。驗算：$(\pm\sqrt{7})^2 = 7$。
</Answer>

9. 用公式解，解 $4x^2 - 4x + 1 = 0$。

<Answer>
$x = \frac{1}{2}$（重根）。$b^2 - 4ac = 16 - 16 = 0$，$x = \frac{4}{8}$。驗算：$4 \times \frac{1}{4} - 2 + 1 = 0$。
</Answer>

10. 長方形的長比寬多 1 公分，面積是 3 平方公分，寬約是多少公分？（取到小數第三位）

<Answer>
設寬為 $x$ 公分，長是 $(x + 1)$ 公分，列式 $x(x + 1) = 3$，整理成 $x^2 + x - 3 = 0$。$b^2 - 4ac = 1 + 12 = 13$，$x = \frac{-1 \pm \sqrt{13}}{2}$。$\sqrt{13} \approx 3.606$，所以 $x \approx 1.303$ 或 $x \approx -2.303$。寬不可能是負的，捨去。驗算：$x \approx 1.303$ 時，長約 2.303，$1.303 \times 2.303 \approx 3.001$，接近 3。所以寬約 1.303 公分。
</Answer>

1. 用面積圖說明：為什麼 $x^2 + 6x$ 要補上 9 才能變成完全平方？

<Answer>
$x^2 + 6x$ 是一個邊長 $x$ 的正方形，加上兩條寬 3 的步道 $3x$ 與 $3x$，右下角缺了 $3 \times 3 = 9$ 的一格。補上它，才是邊長 $x + 3$ 的大正方形。
</Answer>

2. 配方時補上一個數，為什麼兩邊都要加？

<Answer>
方程式像一架平衡的天平，兩邊做同樣的事，等式才仍然成立。只加一邊，就換成了另一個方程式，解也就變了。
</Answer>

3. 公式解 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ 裡，$b^2 - 4ac$ 大於、等於、小於 0 時，各有幾個解？

<Answer>
大於 0 有兩個不同的解；等於 0 有一個解（重根）；小於 0 在實數裡沒有解，因為實數的平方不會是負的。
</Answer>

4. 用公式解，解 $x^2 - x - 1 = 0$。

<Answer>
$x = \frac{1 + \sqrt{5}}{2}$ 或 $x = \frac{1 - \sqrt{5}}{2}$。$a = 1$、$b = -1$、$c = -1$，$b^2 - 4ac = 1 + 4 = 5$，$-b = 1$。
</Answer>
