## 情境開場

社區活動中心要重鋪一間長方形教室的地板。採購單上寫著：邊長還沒決定的大方磚 1 塊、細長的長條磚 5 條、邊長 1 公尺的小方磚 6 塊。每一條長條磚的一邊和大方磚一樣長，另一邊是 1 公尺。三種磚剛好拼成一整塊長方形，不留縫，也不剩。

工人拿著採購單問你：這個長方形的長和寬各是多少？採購單只列出磚的數量，沒有寫怎麼擺。

平常的算法是已經知道長和寬，去算一共需要多少磚。這次剛好反過來：已經知道有哪些磚，要找出長和寬。這個單元要回答的核心問題是：怎麼把一個多項式拆回幾個因式相乘？

## 先修回顧

這個單元的先修是[乘法公式](/units/polynomial-multiplication/)和[最大公因數與最小公倍數](/units/gcd-lcm/)。下面三題不計時、不計分，卡住的話回去看那兩個單元再回來。

1. 12 和 18 的最大公因數是多少？

<Answer>
6。$12 = 2 \times 2 \times 3$，$18 = 2 \times 3 \times 3$，兩邊共有的質因數是 $2 \times 3$，乘起來是 6。
</Answer>

2. 去括號，$3(x + 4)$。

<Answer>
$3x + 12$。括號外的 3 要乘到括號裡的每一項。
</Answer>

3. 展開 $(x + 3)^2$。

<Answer>
$x^2 + 6x + 9$。和的平方是 $a^2 + 2ab + b^2$，這裡 $a = x$、$b = 3$，中間那項是 $2 \times 3 \times x = 6x$。答 $x^2 + 9$ 的，是漏掉了中間那兩塊 $3x$。
</Answer>

## 直覺

用 $x$ 代表大方磚的邊長（單位是公尺），$x$ 是一個數，不是一塊磚。大方磚是邊長 $x$ 的正方形，面積是 $x \times x$，寫成 $x^2$（讀作「x 的平方」）。一條長條磚的面積是 $x \times 1 = x$，一塊小方磚的面積是 $1 \times 1 = 1$。採購單上全部的磚加起來，面積是

$$
x^2 + 5x + 6
$$

### 圖解：把磚拼回長方形

大方磚放在左上角。5 條長條磚分成兩堆：3 條接在大方磚的右邊，2 條接在大方磚的下面。右下角剩下的空位，寬 3、高 2，剛好放進 6 塊小方磚。

  <AreaModel title="拼回長方形" desc="一個長方形，橫邊拆成 x 和 3 兩段，縱邊拆成 x 和 2 兩段，字母 x 的長度只是示意，不按比例。左上格面積是 x²，右上格面積是 3x，左下格面積是 2x，右下格面積是 6。" cols={["x", 3]} rows={["x", 2]} areas={[["x²", "3x"], ["2x", null]]} />

拼好的長方形，橫邊是 $x + 3$，縱邊是 $x + 2$，面積是這兩邊相乘：

$$
x^2 + 5x + 6 = (x + 2)(x + 3)
$$

這個式子讀作「x 的平方加 5x 加 6，等於 x 加 2 乘以 x 加 3」。把一個多項式改寫成幾個多項式相乘，叫做因式分解（factorization）；相乘的每一個多項式叫做因式（factor）。所以 $x + 2$ 與 $x + 3$ 都是 $x^2 + 5x + 6$ 的因式。因式分解的結果一定是「相乘」：$x(x + 5) + 6$ 的最後還有一個加號，不算分解完。

情境、圖和符號三者是一一對應的：大方磚是左上格的 $x^2$，5 條長條磚分成右上格的 $3x$ 與左下格的 $2x$，6 塊小方磚是右下格的 6；整個長方形的長與寬，就是式子裡的兩個因式。工人要的答案，是長 $x + 3$ 公尺、寬 $x + 2$ 公尺。

## 推理

### 先看有沒有公因式

乘法展開是 $3(x + 4) = 3x + 12$，把括號外的數乘進每一項（見[去括號與分配律](/units/expanding-brackets/)）。因式分解是倒過來走：$3x + 12$ 兩項都有因數 3，把 3 提到括號外面，

$$
3x + 12 = 3(x + 4)
$$

每一項共有的因數叫公因式。提的時候要提「最大」的：係數取各項係數的最大公因數（見[最大公因數與最小公倍數](/units/gcd-lcm/)），字母取每一項都有的部分。$6x^2 + 9x$ 的係數是 6 和 9，最大公因數是 3；$x^2 = x \times x$ 和 $x$ 都有一個 $x$。所以公因式是 $3x$：

$$
6x^2 + 9x = 3x(2x + 3)
$$

提完以後，括號裡的項數會和原來一樣多，而且括號裡的各項不再有共同的因數。展開檢查：$3x \times 2x = 6x^2$，$3x \times 3 = 9x$，回到原式。

有公因式就先提出來，因為括號裡剩下的式子比較簡單，後面的步驟會輕鬆許多。

### 為什麼要找「乘起來、加起來」的兩個數

沒有公因式的 $x^2 + 5x + 6$ 要靠面積圖。如果長方形的兩邊是 $x + p$ 與 $x + q$，把它切成四塊：一塊 $x^2$、兩條長條 $px$ 與 $qx$、右下角 $p \times q$。用分配律寫出來是

$$
(x + p)(x + q) = x(x + q) + p(x + q) = x^2 + qx + px + pq = x^2 + (p + q)x + pq
$$

每一步的理由：先把第一個括號裡的 $x$ 與 $p$ 各自乘進 $(x + q)$，再把四項展開，最後把含 $x$ 的兩項 $qx + px$ 合併成 $(p + q)x$。

比較兩邊，要把 $x^2 + bx + c$ 拼回長方形，就要找到兩個數 $p$、$q$，讓 $p \times q = c$（右下角剛好是常數項）、$p + q = b$（兩種長條合起來剛好是 $b$ 條）。回到採購單，$b = 5$、$c = 6$：6 的因數對有 $1 \times 6$ 與 $2 \times 3$，加起來分別是 7 和 5，只有 2 和 3 滿足，所以是 $(x + 2)(x + 3)$。

面積圖畫不出負的邊長，但上面用分配律推出的式子對任何數都成立，所以 $p$、$q$ 可以是負數。符號可以這樣判斷：

- $c$ 是正數，$p$ 與 $q$ 同號；$b$ 是正數就同為正，$b$ 是負數就同為負。例如 $x^2 - 5x + 6 = (x - 2)(x - 3)$，因為 $(-2) \times (-3) = 6$，$(-2) + (-3) = -5$。
- $c$ 是負數，$p$ 與 $q$ 一正一負，絕對值大的那個和 $b$ 同號。

### 首項係數不是 1 的時候

遇到 $3x^2 + 10x + 8$，$x^2$ 前面不是 1。假設它等於 $(mx + p)(nx + q)$，展開是

$$
(mx + p)(nx + q) = mnx^2 + (mq + np)x + pq
$$

中間兩項的係數 $mq$ 與 $np$ 相加要等於 $b$，相乘是 $mq \times np = (mn) \times (pq) = ac$，也就是首項係數乘以常數項。所以要找兩個數，乘起來是 $a \times c$，加起來是 $b$。$3x^2 + 10x + 8$ 的 $a \times c = 24$、$b = 10$，24 的因數對中 $4 + 6 = 10$，把 $10x$ 拆成 $4x + 6x$，再分組提公因式：

$$
3x^2 + 4x + 6x + 8 = x(3x + 4) + 2(3x + 4) = (3x + 4)(x + 2)
$$

第二個等號用了兩次提公因式，兩組都出現 $3x + 4$，所以它可以再提一次。展開檢查：$3x^2 + 6x + 4x + 8 = 3x^2 + 10x + 8$。

### 十字交乘法：同一件事的速記

上面「乘起來是 $ac$、加起來是 $b$」的找法，課本上常寫成十字交乘法。把首項係數 3 拆成 $3 \times 1$ 寫在左邊，把常數項 8 拆成 $4 \times 2$ 寫在右邊，兩條斜線上的數相乘再相加：

$$
\begin{array}{ccc}
3x & & +4 \\
 & \times & \\
x & & +2
\end{array}
$$

左邊一行相乘得 $3x^2$，右邊一行相乘得 8，斜著乘再相加是 $3x \times 2 + 4 \times x = 6x + 4x = 10x$，剛好是中間那一項，所以分解成 $(3x + 4)(x + 2)$。斜著相乘的那兩項，就是面積圖上不在對角線的那兩塊長條。十字交乘法不是另一條規則，只是把「試拆、檢查中間項」的過程排成一個方便心算的版面；一旦試不出來，回到面積圖或「乘起來、加起來」的找法就好。

## 範例

下面的範例從完整示範開始，逐步把步驟留給你。每個範例最後都回頭檢查一次：把分解的結果展開，看是不是回到原式。

### 範例一：花圃的面積（完整範例）

長方形花圃的面積是 $(x^2 + 7x + 12)$ 平方公尺，求花圃的長與寬（用 $x$ 表示）。

第一步，沒有公因式，所以找兩個數，乘起來是 12、加起來是 7。12 的因數對：$1 \times 12$（和 13）、$2 \times 6$（和 8）、$3 \times 4$（和 7）。取 3 和 4。

為什麼這步成立？

<Answer>
$(x + p)(x + q) = x^2 + (p + q)x + pq$，要讓它等於 $x^2 + 7x + 12$，就要 $pq = 12$、$p + q = 7$。見「推理」段第二節。
</Answer>

第二步，$x^2 + 7x + 12 = (x + 3)(x + 4)$，花圃的寬是 $x + 3$ 公尺，長是 $x + 4$ 公尺。

回頭檢查：展開 $(x + 3)(x + 4) = x^2 + 4x + 3x + 12 = x^2 + 7x + 12$，回到原式。

### 範例二：提公因式（範例與練習配對）

先看示範：$4a + 8$。4 與 8 的最大公因數是 4，所以 $4a + 8 = 4(a + 2)$。回頭檢查：$4 \times a + 4 \times 2 = 4a + 8$。

換你：$10m^2 - 15m$。

<Answer>
10 與 15 的最大公因數是 5，$m^2$ 與 $m$ 都有 $m$，公因式是 $5m$：$10m^2 - 15m = 5m(2m - 3)$。回頭檢查：$5m \times 2m = 10m^2$，$5m \times (-3) = -15m$，相同。
</Answer>

### 範例三：常數項是負數（留空最後一步）

因式分解 $x^2 - 2x - 15$。

第一步，常數項 $-15$ 是負數，所以 $p$、$q$ 一正一負。乘起來是 $-15$ 的整數對有 $1$ 與 $-15$、$-1$ 與 $15$、$3$ 與 $-5$、$-3$ 與 $5$，加起來分別是 $-14$、$14$、$-2$、$2$。

為什麼這步成立？

<Answer>
乘積為負，表示兩個數一正一負；因為 $(x + p)(x + q)$ 的常數項是 $pq$，所以要列出乘積是 $-15$ 的整數對，再找加起來是 $b = -2$ 的那一對。見「推理」段第二節。
</Answer>

最後一步留給你：選出加起來是 $-2$ 的那一對，寫出分解的結果，並展開檢查。

<Answer>
選 3 與 $-5$，$x^2 - 2x - 15 = (x + 3)(x - 5)$。回頭檢查：$(x + 3)(x - 5) = x^2 - 5x + 3x - 15 = x^2 - 2x - 15$，相同。
</Answer>

### 範例四：先提公因式再分解（留空最後兩步）

廣告板的面積是 $(2x^2 + 10x + 12)$ 平方公分，把這個式子因式分解。

第一步，三項都有因數 2，先提出來：$2x^2 + 10x + 12 = 2(x^2 + 5x + 6)$。

為什麼這步成立？

<Answer>
提公因式是分配律倒過來用：$2 \times x^2 + 2 \times 5x + 2 \times 6 = 2 \times (x^2 + 5x + 6)$。先提出來，括號裡的係數變小，後面找兩個數會容易許多。見「推理」段第一節。
</Answer>

最後兩步留給你：把括號裡的式子再分解，寫出完整的結果，並檢查。

<Answer>
括號裡是開頭拼回長方形的那一題，$x^2 + 5x + 6 = (x + 2)(x + 3)$，所以 $2x^2 + 10x + 12 = 2(x + 2)(x + 3)$。回頭檢查：把 $x$ 換成 1，原式 $2 + 10 + 12 = 24$，$2 \times 3 \times 4 = 24$，相同。公因式 2 不能漏寫在最前面。
</Answer>

### 範例五：首項係數不是 1（獨立解題）

因式分解 $2x^2 + 7x + 3$。想想看有哪些做法，先自己試，再看下面兩種解法。

<Answer>
解法一，十字交乘法：2 拆成 $2 \times 1$，3 拆成 $1 \times 3$。試 $(2x + 1)(x + 3)$，斜著乘再相加：$2x \times 3 + 1 \times x = 6x + x = 7x$，剛好是中間那項。所以 $2x^2 + 7x + 3 = (2x + 1)(x + 3)$。

解法二，乘起來是 $ac$、加起來是 $b$：$a \times c = 2 \times 3 = 6$，加起來是 7 的兩個數是 1 和 6。把 $7x$ 拆成 $x + 6x$：$2x^2 + x + 6x + 3 = x(2x + 1) + 3(2x + 1) = (2x + 1)(x + 3)$。

比較：解法一靠心算試拆，熟了很快，但要試幾種拆法；解法二每一步都有明確的規則，比較不會漏。兩種做法的答案相同。

回頭檢查：展開 $(2x + 1)(x + 3) = 2x^2 + 6x + x + 3 = 2x^2 + 7x + 3$，回到原式。
</Answer>

## 常見迷思

**迷思一：只湊乘積，沒有檢查加起來是不是 b**。看到常數項 12，就挑一組乘起來是 12 的數，忘了中間那項。

<Misconception>

$x^2 + 8x + 12 = (x + 3)(x + 4)$，因為 $3 \times 4 = 12$。

---

兩個數要同時滿足乘起來是 12、加起來是 8，所以是 $2$ 和 $6$：$x^2 + 8x + 12 = (x + 2)(x + 6)$。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它只管右下角那一格，沒有管長條。$(x + 3)(x + 4)$ 展開是 $x^2 + 7x + 12$，長條合起來是 $7x$，不是 $8x$。檢查：把 $x$ 換成 1，$(1 + 3)(1 + 4) = 20$，但 $1 + 8 + 12 = 21$，不一樣。
</Answer>

診斷題：因式分解 $x^2 + 7x + 10$。

<Answer>
$(x + 2)(x + 5)$。乘起來是 10 的整數對有 $1 \times 10$（和 11）與 $2 \times 5$（和 7），要選和是 7 的那一對。答 $(x + 1)(x + 10)$ 的，是只看乘積。檢查：$(x + 2)(x + 5) = x^2 + 5x + 2x + 10 = x^2 + 7x + 10$。
</Answer>

**迷思二：整項提光就不留東西**。提公因式時，其中一項剛好和公因式一樣，提完就以為沒有剩下的了。

<Misconception>

$4x + 4 = 4(x)$，因為 4 提出來以後，後面只剩 $x$。

---

$4x + 4 = 4(x + 1)$。第二項 4 提走 4，剩下的是 1，不是什麼都沒有。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
$4 = 4 \times 1$，提走 4 以後剩下 1，括號裡要留著 $+1$。展開錯誤的答案 $4(x) = 4x$，少了一項。檢查：把 $x$ 換成 2，原式 $4 \times 2 + 4 = 12$，$4(2) = 8$，不一樣；$4(2 + 1) = 12$ 才對。
</Answer>

診斷題：因式分解 $7y^2 + 7y$。

<Answer>
$7y(y + 1)$。公因式是 $7y$，$7y^2 \div 7y = y$，$7y \div 7y = 1$，所以括號裡是 $y + 1$。答 $7y(y)$ 的，是把第二項的 1 弄丟了。檢查：$7y \times y + 7y \times 1 = 7y^2 + 7y$。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。卡住時，先問：有沒有公因式？兩個數乘起來是什麼、加起來又是什麼？

1. 因式分解 $6x + 9$。

<Answer>
$3(2x + 3)$。6 與 9 的最大公因數是 3。檢查：$3 \times 2x + 3 \times 3 = 6x + 9$。
</Answer>

2. 24 和 36 的最大公因數是多少？

<Answer>
12。$24 = 2 \times 2 \times 2 \times 3$，$36 = 2 \times 2 \times 3 \times 3$，共有的是 $2 \times 2 \times 3 = 12$。
</Answer>

3. 因式分解 $x^2 + 6x + 8$。

<Answer>
$(x + 2)(x + 4)$。乘起來是 8、加起來是 6 的數是 2 和 4。檢查：$x^2 + 4x + 2x + 8 = x^2 + 6x + 8$。
</Answer>

4. 展開 $(x + 4)^2$。

<Answer>
$x^2 + 8x + 16$。和的平方：$x^2 + 2 \times 4 \times x + 4^2$。
</Answer>

5. 因式分解 $x^2 - 7x + 12$。

<Answer>
$(x - 3)(x - 4)$。乘起來是 12、加起來是 $-7$，兩個數同號，而且都是負數：$-3$ 與 $-4$。檢查：$x^2 - 4x - 3x + 12 = x^2 - 7x + 12$。
</Answer>

6. 因式分解 $10x^2 + 15x$。

<Answer>
$5x(2x + 3)$。係數 10 與 15 的最大公因數是 5，兩項又都有 $x$。檢查：$5x \times 2x = 10x^2$，$5x \times 3 = 15x$。
</Answer>

7. 因式分解 $x^2 - x - 12$。

<Answer>
$(x - 4)(x + 3)$。乘起來是 $-12$，加起來是 $-1$：$-4$ 與 3。檢查：$x^2 + 3x - 4x - 12 = x^2 - x - 12$。
</Answer>

8. 去括號，$-2(x - 3)$。

<Answer>
$-2x + 6$。$-2$ 乘 $x$ 是 $-2x$，$-2$ 乘 $-3$ 是 $+6$。檢查：把 $x$ 換成 4，$-2 \times 1 = -2$，$-8 + 6 = -2$。
</Answer>

9. 因式分解 $3x^2 + 5x + 2$。

<Answer>
$(3x + 2)(x + 1)$。$a \times c = 6$、$b = 5$，加起來是 5 的是 2 和 3，$5x = 2x + 3x$：$3x^2 + 3x + 2x + 2 = 3x(x + 1) + 2(x + 1) = (3x + 2)(x + 1)$。檢查：展開 $(3x + 2)(x + 1) = 3x^2 + 3x + 2x + 2 = 3x^2 + 5x + 2$。
</Answer>

10. 因式分解 $2x^2 - 5x - 3$。

<Answer>
$(2x + 1)(x - 3)$。$a \times c = -6$、$b = -5$，乘起來是 $-6$、加起來是 $-5$ 的是 $-6$ 與 1，$-5x = -6x + x$：$2x^2 - 6x + x - 3 = 2x(x - 3) + (x - 3) = (2x + 1)(x - 3)$。檢查：展開 $(2x + 1)(x - 3) = 2x^2 - 6x + x - 3 = 2x^2 - 5x - 3$。
</Answer>

## 提取題

不看前面的內容，憑記憶回答。

1. 因式分解和乘法展開是什麼關係？用 $x^2 + 5x + 6$ 說明為什麼要找「乘起來是 6、加起來是 5」的兩個數。

<Answer>
因式分解是乘法展開的反方向。$(x + p)(x + q)$ 展開是 $x^2 + (p + q)x + pq$，所以要拼回長方形，右下角 $pq$ 要等於常數項 6，兩種長條 $p + q$ 要等於 5。2 和 3 同時滿足，所以是 $(x + 2)(x + 3)$。
</Answer>

2. 有人說 $x^2 + 7x + 10 = (x + 1)(x + 10)$，因為 $1 \times 10 = 10$。你怎麼讓他看到哪裡不對？

<Answer>
展開 $(x + 1)(x + 10) = x^2 + 11x + 10$，中間是 $11x$，不是 $7x$。兩個數除了乘起來是 10，還要加起來是 7，所以是 2 和 5。
</Answer>

3. $6x^2 + 6x$ 的公因式是什麼？為什麼 $6x(x)$ 不對？

<Answer>
公因式是 $6x$，$6x^2 + 6x = 6x(x + 1)$。$6x(x)$ 展開是 $6x^2$，少了第二項；第二項 $6x = 6x \times 1$，提走 $6x$ 以後剩下 1，要留在括號裡。
</Answer>

4. 十字交乘法和「乘起來、加起來」是兩種不同的規則嗎？

<Answer>
不是，它是同一件事的速記。斜著乘再相加的兩項，就是面積圖上不在對角線的兩塊長條，加起來要等於中間那一項。做不出來時，回到面積圖或「乘起來是 $ac$、加起來是 $b$」的找法。
</Answer>
