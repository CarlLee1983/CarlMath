## 情境開場

你在鋪浴室地板，用的是邊長 30 公分的正方形磚。師傅要你量一塊磚的對角線，好決定斜著切的裝飾條要買多長。你拿捲尺一量，大約 42 公分多一點，可是不管把刻度看得多細，總是差一點點對不齊：42.4 公分好像太短，42.5 公分又太長。

你開始懷疑：是尺不夠細嗎？如果邊長是 1，對角線的長度有沒有可能剛好是某個「整數除以整數」的數？這個疑問還牽連到另一個問題：所有整數除以整數得到的數，已經密密麻麻地塞滿數線，還會留下洞嗎？

這個單元要回答的核心問題是：√2 為什麼不能寫成分數，數線上真的沒有空隙嗎？

## 先修回顧

這個單元的先修是[平方根與根式](/units/square-roots/)與[分數在數線上](/units/fractions-on-number-line/)。下面三題不計時、不計分，卡住的話回去看那個單元再回來。

1. $\sqrt{9}$ 等於多少？

<Answer>
3。$\sqrt{9}$ 是 9 的正平方根，也就是平方後等於 9 的正數，$3^2 = 9$。
</Answer>

2. 算算看，$1.4^2$ 和 $1.5^2$ 各是多少？由此說說看，$\sqrt{2}$ 在哪兩個數之間？

<Answer>
$1.4^2 = 1.96$，$1.5^2 = 2.25$。因為 $1.96 < 2 < 2.25$，所以 $\sqrt{2}$ 在 1.4 與 1.5 之間。
</Answer>

3. $\frac{3}{4}$ 在數線上的 0 與 1 之間，把 0 到 1 平分成 4 段，它在哪裡？寫成小數是多少？

<Answer>
在第 3 個分點，也就是從 0 往右數 3 段的地方；寫成小數是 0.75。
</Answer>

## 直覺

### 有理數、無理數與實數

邊長 1 的正方形，對角線長的平方是 2，所以對角線長是 $\sqrt{2}$（讀作「根號 2」），$\sqrt{2} \approx 1.414$。這個數是哪一種數？

數線上的每一個點都代表一個數。其中能寫成兩個整數相除、分母不為 0 的數，叫做有理數，例如 $\frac{3}{4}$、$-2$（可以寫成 $\frac{-2}{1}$）、0.5（可以寫成 $\frac{1}{2}$）。數線上不是有理數的數，叫做無理數（irrational number）。有理數與無理數合起來，叫做實數。

有理數與無理數也可以從小數分辨。有理數寫成小數時，一定是有限小數或循環小數：做長除法時，餘數一定比除數小，只有有限種可能，算著算著餘數就會重複。反過來，有限小數與循環小數也都能寫成分數，所以都是有理數：$0.333\ldots = \frac{1}{3}$；$0.2727\ldots$ 令它為 $x$，$100x - x = 27$，所以 $x = \frac{27}{99} = \frac{3}{11}$。因此無理數寫成小數，一定無限而且不循環。

### 圖解：把對角線轉到數線上

在數線上，以 0 到 1 為邊畫一個單位正方形，再畫它從 0 出發的對角線。用圓規把針尖放在 0，筆尖放在對角線的另一端，沿著圓弧轉到數線上，筆尖落下的點就在對角線長的位置。

情境、圖和符號三者是對應的：地板磚的對角線是圖上的對角線，量出來的 42 公分多是 $30 \times \sqrt{2}$（邊長放大 30 倍，面積放大 $30^2 = 900$ 倍，所以對角線正方形的面積是 $900 \times 2 = 1800$，而 $(30\sqrt{2})^2 = 900 \times 2 = 1800$），而 $\sqrt{2}$ 是圓弧落在數線上的那個點。所以 $\sqrt{2}$ 是數線上真實存在的一個點，不只是符號。

圖沒辦法回答的是：這個點能不能寫成 $\frac{p}{q}$，也就是 p、q 兩個整數相除？（p、q 是代表整數的字母。）這要靠推理。

## 推理

### 反證法：先假設它是分數

反證法的想法是：想說明某件事不成立，就先假設它成立，一步一步推下去；如果推出矛盾，表示一開始的假設不可能，原來的事就不成立。

假設 $\sqrt{2} = \frac{p}{q}$，p、q 是正整數。任何分數都能約分到最簡，所以可以要求 $\frac{p}{q}$ 是最簡分數：p 與 q 除了 1 以外，沒有共同的因數。

1. 兩邊平方，得 $2 = \left(\frac{p}{q}\right)^2 = \frac{p^2}{q^2}$。理由：$\sqrt{2}$ 的平方是 2；分數的平方，是分子、分母各自平方。
2. 兩邊乘 $q^2$，得 $p^2 = 2q^2$。理由：等式兩邊乘同一個不為 0 的數，仍然相等。
3. $p^2$ 是偶數。理由：$p^2$ 等於 2 乘整數 $q^2$，是 2 的倍數。
4. p 是偶數。理由：奇數的平方一定是奇數。奇數可以寫成 $2k + 1$（k 是整數），把第二個因數 $2k+1$ 當成一個數，用分配律拆開第一個因數，$(2k+1)(2k+1) = 2k(2k+1) + (2k+1) = 2\bigl[k(2k+1) + k\bigr] + 1$，除以 2 餘 1。如果 p 是奇數，$p^2$ 就是奇數，和第 3 步矛盾，所以 p 是偶數。
5. 設 $p = 2m$，m 是正整數。理由：偶數就是 2 的倍數。
6. 代入第 2 步，$(2m)^2 = 2q^2$，即 $4m^2 = 2q^2$，兩邊除以 2，得 $q^2 = 2m^2$。理由：把 p 換成 $2m$，等式兩邊再同除以 2。
7. q 是偶數。理由：$q^2$ 是 2 乘整數 $m^2$，是偶數，再照第 4 步的道理，q 是偶數。
8. p、q 都是偶數，都有因數 2，這和「$\frac{p}{q}$ 是最簡分數」矛盾。理由：最簡分數的分子與分母，除了 1 沒有共同的因數。
9. 所以一開始的假設不成立，$\sqrt{2}$ 不能寫成分數。理由：每一步都有理由，唯一沒有根據的是第一句假設，矛盾只能來自它。

### 證據不是證明

用計算機算 $\sqrt{2}$ 到小數第幾百位，都看不出循環，這是證據，不是證明：看過再多位，也只是有限位，循環可能出現在更後面。上面的 9 步沒有看小數，直接從「能寫成分數」推出矛盾，這才是證明。

### 數線上的空隙

有理數在數線上非常密：任意兩個有理數取平均，還是有理數，所以兩個有理數之間不管多近，都還有別的有理數。可是 $\sqrt{2}$ 偏偏不在其中，所以只有有理數的數線上有洞。把無理數也放進來，就是實數。每個實數對應數線上的一個點，數線上每一點也對應一個實數，「數線上沒有空隙」說的就是這件事。

## 範例

每個範例最後都回頭檢查一次，看結果合不合理。

### 範例一：比較 $\sqrt{2}$ 與 $\frac{3}{2}$（完整範例）

第一步，$\left(\frac{3}{2}\right)^2 = \frac{9}{4} = 2.25$，而 $(\sqrt{2})^2 = 2$。

為什麼這步成立？

<Answer>
兩個正數，大的那個平方也比較大（邊長大的正方形面積大），所以可以比平方來比大小；反過來也成立：平方比較小的那個數，本身也比較小。見先修回顧第 2 題的作法。
</Answer>

第二步，$2 < 2.25$，所以 $\sqrt{2} < \frac{3}{2}$。

回頭檢查：$\sqrt{2}$ 約 1.414，$\frac{3}{2} = 1.5$，$1.414 < 1.5$，結論一致。

### 範例二：比較 $\sqrt{3}$ 與 $\frac{5}{3}$（範例與練習配對）

先看示範：比較 $\sqrt{5}$ 與 $\frac{9}{4}$。$\left(\frac{9}{4}\right)^2 = \frac{81}{16} = 5.0625$，比 5 大，所以 $\sqrt{5} < \frac{9}{4}$。回頭檢查：$\sqrt{5}$ 約 2.236，$\frac{9}{4} = 2.25$。

換你：比較 $\sqrt{3}$ 與 $\frac{5}{3}$。

<Answer>
$\left(\frac{5}{3}\right)^2 = \frac{25}{9}$，約 2.78，比 3 小，所以 $\frac{5}{3} < \sqrt{3}$。回頭檢查：$\frac{5}{3}$ 約 1.667，$\sqrt{3}$ 約 1.732，結論一致。
</Answer>

### 範例三：用分數夾住 $\sqrt{2}$（留空最後一步）

先看 $\frac{7}{5}$：$\left(\frac{7}{5}\right)^2 = \frac{49}{25} = 1.96$，比 2 小，所以 $\frac{7}{5} < \sqrt{2}$。

接著看 $\frac{17}{12}$：$\left(\frac{17}{12}\right)^2 = \frac{289}{144}$。

最後一步留給你：把 $\frac{289}{144}$ 與 2 比大小，寫出夾住 $\sqrt{2}$ 的不等式，並回頭檢查。

<Answer>
$2 = \frac{288}{144}$，$\frac{289}{144}$ 比 2 大，所以 $\sqrt{2} < \frac{17}{12}$，合起來

$$
\frac{7}{5} < \sqrt{2} < \frac{17}{12}
$$

回頭檢查：$\frac{7}{5} = 1.4$，$\frac{17}{12}$ 約 1.417，$\sqrt{2}$ 約 1.414，確實夾在中間。夾得再窄（這兩個分數只差 $\frac{1}{60}$），$\sqrt{2}$ 也不等於夾它的任何一個分數。
</Answer>

### 範例四：證明 $\sqrt{2} + 1$ 是無理數（留空最後兩步）

假設 $\sqrt{2} + 1 = \frac{r}{s}$，r、s 是整數，s 不為 0。

第一步，兩邊減 1：$\sqrt{2} = \frac{r}{s} - 1 = \frac{r - s}{s}$。

為什麼這步成立？

<Answer>
等式兩邊同減 1 仍相等，$\frac{r}{s} - 1$ 通分後是 $\frac{r - s}{s}$。這個做法和 $\sqrt{2}$ 的反證法一樣：先假設是分數，再推出別的東西是分數。
</Answer>

最後兩步留給你：說明矛盾在哪裡，並回頭檢查。

<Answer>
$r - s$ 與 $s$ 都是整數，所以 $\sqrt{2}$ 被寫成兩個整數相除，和「$\sqrt{2}$ 不是有理數」矛盾，所以假設不成立，$\sqrt{2} + 1$ 是無理數。回頭檢查：$\sqrt{2} + 1$ 與 $\sqrt{2}$ 只差整數 1，所以「$\sqrt{2} + 1$ 是分數」和「$\sqrt{2}$ 是分數」同時成立或同時不成立；後者已經證明不成立，結論一致。
</Answer>

### 範例五：兩個無理數的和一定是無理數嗎？（獨立解題）

先自己試，再看解答。

<Answer>
不一定。$\sqrt{2}$ 是無理數，$-\sqrt{2}$ 也是（如果 $-\sqrt{2}$ 是分數，乘上 $-1$ 後 $\sqrt{2}$ 也會是分數）。但 $\sqrt{2} + (-\sqrt{2}) = 0$，0 是有理數。要說明「不一定」，舉一個反例就夠了。回頭檢查：另一個反例是 $(1 + \sqrt{2}) + (1 - \sqrt{2}) = 2$，也是有理數。
</Answer>

## 常見迷思

**迷思一：小數算很多位沒循環，就是證明**。

<Misconception>

我把 $\sqrt{2}$ 算到小數第 50 位都沒有循環，所以它一定是無理數。

---

算過的位數再多都只是有限位，循環可能出現在更後面。要證明是無理數，必須像上面的反證法一樣，從定義推出來。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它把「目前沒看到循環」當成「永遠不會循環」。看過有限位，不能保證後面的樣子。例如 $\frac{1}{97}$ 的循環節長 96 位，第 97 位起才重複，只看前 50 位完全看不出循環，可是它是兩個整數相除，是有理數。
</Answer>

診斷題：小明把一個「兩個整數相除」得到的數，用長除法算到小數第 50 位，都沒看到循環，他說這個數是無理數。對嗎？

<Answer>
不對。兩個整數相除的數是有理數，小數一定有限或循環，只是循環節可能很長。例如 $\frac{1}{97}$ 的循環節長 96 位，第 97 位起才重複，前 50 位完全看不出來。答「對」的人，是把「沒看到循環」當成了證明。
</Answer>

**迷思二：無限小數就是無理數**。

<Misconception>

$0.333\ldots$ 的小數位數沒有盡頭，所以它是無理數。

---

無理數要「無限而且不循環」。$0.333\ldots$ 無限但循環，它等於 $\frac{1}{3}$，是有理數。

</Misconception>

錯誤範例錯在哪裡？為什麼錯？先自己說說看，再打開核對。

<Answer>
它漏看了「不循環」這個條件。無限小數有兩種：循環的是有理數，不循環的才是無理數。
</Answer>

診斷題：$0.272727\ldots$（27 一直重複）是有理數還是無理數？

<Answer>
有理數。它是循環小數，等於 $\frac{3}{11}$（$3 \div 11 = 0.2727\ldots$）。答無理數的人，是看到無限就以為是無理數。
</Answer>

## 練習

這裡的題目混了不同類型，錯得比較多是正常的，混在一起練，長期記得比較牢。

1. 下列各數哪些是有理數：$-4$、$\frac{5}{3}$、$\sqrt{7}$、$\sqrt{49}$、0.8？

<Answer>
$-4$、$\frac{5}{3}$、$\sqrt{49}$、0.8 是有理數。$\sqrt{49} = 7$ 是整數。$\sqrt{7}$ 在 2 與 3 之間（$4 < 7 < 9$），不是整數，也和 $\sqrt{2}$ 一樣不能寫成分數，是無理數：可以用同樣的反證法（把偶數換成 7 的倍數），本站先接受。答「有根號就是無理數」的，漏了 $\sqrt{49} = 7$。
</Answer>

2. 算 $\sqrt{16} + \sqrt{9}$。

<Answer>
7。$\sqrt{16}$ 是 16 的正平方根，等於 4，$\sqrt{9} = 3$，$4 + 3 = 7$。答 $\pm 4 \pm 3$ 的，忘了根號只指正的那一個。
</Answer>

3. $\frac{1}{3}$ 的小數是 $0.333\ldots$，它是有理數嗎？為什麼？

<Answer>
是。它是 1 除以 3，兩個整數相除。小數雖然無限，但 3 一直循環。
</Answer>

4. 去括號並化簡，$3(x - 2) + 2x$。

<Answer>
$5x - 6$。$3(x - 2) = 3x - 6$，再合併 $3x + 2x = 5x$。回頭檢查：$x = 2$ 時，$3 \times 0 + 4 = 4$，$5 \times 2 - 6 = 4$。
</Answer>

5. 比較 $\sqrt{5}$ 與 2.2 的大小。

<Answer>
$2.2^2 = 4.84$，比 5 小，所以 $2.2 < \sqrt{5}$。回頭檢查：$\sqrt{5}$ 約 2.236。
</Answer>

6. 小數 $0.1010010001\ldots$（每次多一個 0）是有理數還是無理數？為什麼？

<Answer>
無理數。0 的個數越來越多，沒有一段會一直重複，是無限而且不循環的小數。有規律不等於循環。
</Answer>

7. 算 $(-3)^2 - 2^3$。

<Answer>
1。$(-3)^2 = 9$，$2^3 = 8$，$9 - 8 = 1$。
</Answer>

8. 證明 $\sqrt{2} - 1$ 是無理數。

<Answer>
假設 $\sqrt{2} - 1 = \frac{r}{s}$，r、s 是整數，s 不為 0。兩邊加 1，$\sqrt{2} = \frac{r}{s} + 1 = \frac{r + s}{s}$。$r + s$ 與 $s$ 都是整數，所以 $\sqrt{2}$ 是分數，和 $\sqrt{2}$ 是無理數矛盾，假設不成立。
</Answer>

9. $\sqrt{2} \times \sqrt{2}$ 是有理數嗎？由此說說看，「兩個無理數相乘，一定是無理數」對嗎？

<Answer>
$\sqrt{2} \times \sqrt{2} = 2$，是有理數。所以那句話不對，一個反例就夠了。
</Answer>

## 提取題

不看前面的內容，憑記憶回答。

1. 說說看有理數、無理數、實數各是什麼，三者是什麼關係。

<Answer>
有理數是能寫成兩個整數相除（分母不為 0）的數；不是有理數的實數是無理數；有理數與無理數合起來是實數。
</Answer>

2. 用自己的話說明，$\sqrt{2}$ 不是分數的反證法：假設什麼，最後矛盾在哪裡？

<Answer>
假設 $\sqrt{2} = \frac{p}{q}$ 是最簡分數。平方後得 $p^2 = 2q^2$，所以 p 是偶數；設 $p = 2m$ 代回去，得 $q^2 = 2m^2$，所以 q 也是偶數。p、q 都是偶數，和最簡分數矛盾。
</Answer>

3. 為什麼 $p^2$ 是偶數，可以推出 p 是偶數？

<Answer>
因為奇數的平方一定是奇數：$(2k+1)(2k+1) = 2\bigl[k(2k+1) + k\bigr] + 1$，除以 2 餘 1。p 如果是奇數，$p^2$ 就是奇數。
</Answer>

4. 為什麼把 $\sqrt{2}$ 算到再多位都沒循環，仍不算證明？

<Answer>
看過的位數再多都是有限位，循環可能出現在更後面（例如 $\frac{1}{97}$ 的循環節長 96 位，第 97 位起才重複）。證明要從定義一步步推出來，不靠看。
</Answer>
