## 情境開場

兩個人各自記錄練習時拼出的方片數。第一個人從三塊開始，每次多放一塊；第二個人從一塊開始，每次把數量變成原來的兩倍。前幾次的數量相近，繼續下去卻會出現很大的差別。

「多一塊」是在比較相差多少，「變成兩倍」是在比較前後的倍數。把兩種話聽成同一件事，就可能在估算未來數量時差得很遠。我們要用明確的式子分開這兩種規則。

「每次加一樣多」和「每次乘一樣多」會長成什麼樣子？

## 先修回顧

先試兩題，需要時回到[數列與規律](/units/sequences/)與[指數律](/units/exponent-rules/)。不用計時或評分。

1. 第一項為四，每次增加三。從第一項到第六項，增加了幾次？第六項多少？

<Answer>
增加五次，第六項 $4+3\times5=19$。項號六不代表增加六次。
</Answer>

2. 計算 $2^0$、$2^3$、$(-2)^3$。負底數的括號能不能省略？

<Answer>
分別為一、八、負八。括號表明負二整體是底數，不能任意省略或把負號當成與乘方無關。
</Answer>

如果你已經能從固定差或固定倍乘寫通項，並檢查首項到指定項有多少個間隔，可以直接跳到練習。

若相鄰兩項的「後項減前項」固定為 $d$，稱為**等差數列**（arithmetic sequence），$d$ 叫公差，讀作「共同的差」。規則是 $a_{n+1}=a_n+d$；加上負公差就表示每次減少相同的量。

若下一項總是前一項乘固定數 $r$，稱為**等比數列**（geometric sequence），$r$ 叫公比。規則是 $a_{n+1}=ra_n$，讀作「下一項等於公比乘前一項」；$ra_n$ 就是 $r\times a_n$。

前圖第一串公差為一；第二串公比為二。要檢查一串給定的數，應使用同方向的差或比，不能第一步用後項除前項，下一步又反過來。若只列幾項而沒保證後續規則，仍只能說這幾步符合，不能據此決定無限多項。

## 推理

### 等差通項來自重複相加

本課的項號從一開始。從首項 $a_1$ 到第 n 項，共有 n 減一個間隔，每個間隔加公差，因此

$$
a_n=a_1+(n-1)d.
$$

讀作「第 n 項等於首項，加上 n 減一次公差」。把 n 取一時，增加次數為零，正好回到首項；若誤寫成 n 次，第一項就先多加一次。

同樣地，從第 p 項走到第 q 項，跨過 q 減 p 個間隔，所以兩個項值之差是間隔數乘公差。這能由兩個已知位置找出公差，不必一定知道首項，也不是拿項值直接除以項號。

公差可以為正、零或負。為零時每項相同；為負時項值逐次下降。等差說的是差固定，沒有要求項值一定是正整數，也沒有要求數列一定增加。

### 等比通項來自重複相乘

先看公比非零的情況。第一項到第二項乘一次公比，到第三項乘兩次，到第 n 項共乘 n 減一次，所以

$$
a_n=a_1r^{n-1},\qquad r\ne0.
$$

讀作「第 n 項等於首項乘公比的 n 減一次方」。首項對應零次方，非零公比的零次方是一，因此公式也涵蓋第一項。

兩個數列即使首項相同，公差或公比不同，後續也可能完全不同。等差通項是加上一段變化量；等比通項是乘上一個倍率，不能把兩條公式只當作不同的符號外形，忘記背後的操作。

### 負公比、分數公比與零

正首項配上大於一的正公比，數值會越來越大；公比在零與一之間時，每次只保留一部分，正項逐次縮小。公比為負則正負交替，例如公比負二會依序出現正、負、正、負。即使數值絕對值增加，也不能說項值一直增加。

用相鄰項相除找公比，必須確認前項不是零。本課以固定倍乘的遞迴描述規則；公比為零時，首項後全部是零，須另寫「第一項給定，第二項起為零」，不把首項硬寫成零的零次方。

若首項本來就是零，固定倍乘會使後面也都是零，不論用哪個公比都如此。因此只看到全零數列，不能靠零除以零反推出唯一的公比。後面的通項計算以非零公比為主，碰到零時回到遞迴檢查。

### 固定差與固定比不是互斥的標籤

例如每一項都是五，差為零，也能每次乘一，兩種條件都符合。反過來，二、四、六、八的差固定為二，但相鄰比是二、二分之三、三分之四，並不固定。

判斷時至少檢查兩個相鄰間隔，能避免只看兩項就急著下結論；但若要談後面全部的項，仍需已知整個規則。有限檢查是辨認與驗算，通項的依據則是每一步都遵守同樣的遞迴。

## 範例

### 完整範例：每排座位增加

一座小劇場第一排十二個座位，後面每排比前面多兩個，共有八排。設第 n 排座位數為 $a_n$，公差二，項號範圍是一到八。第八排為

$$
a_8=12+(8-1)\times2=26.
$$

第八排有二十六個座位。回頭檢查：第一排到第八排有七個間隔，增加十四個；這個答案只是一排的座位數，不是整座劇場的總數。

為什麼這步成立？

<Answer>
首項已包含第一排十二個座位，其後七排各增加一次二。由每步固定增加推得等差通項，不能把排數八直接當成增加次數。
</Answer>

### 範例與練習配對

某設備每次測試後，剩餘可用量固定變成前一次的一半。第一次量到八十單位，設第 n 次量測為 $b_n$，則公比是 $\frac12$，第四次為 $b_4=80\left(\frac12\right)^3=10$ 單位。

回頭檢查：八十、四十、二十、十，共有三次減半。這裡把「固定一半」當作題目給的模型，不由四筆量測保證實際設備永遠照這樣衰減。

換你做：另一模型首項四十八，每次乘 $\frac12$。求第五項，並逐項檢查。

<Answer>
$a_5=48\left(\frac12\right)^4=3$。依序四十八、二十四、十二、六、三，四次減半，與通項一致。
</Answer>

### 留空最後一步

等差數列第三項十一、第七項二十三。兩位置相隔四個間隔，公差 $d=\frac{23-11}{7-3}=3$。因此首項 $a_1=11-2\times3=$＿＿。

為什麼這步成立？

<Answer>
第七項比第三項多四次公差，所以先用項值差除以項號差；第三項距首項兩個間隔，回推首項要減去兩次公差。
</Answer>

<Answer>
首項五。回頭檢查：第三項 $5+2\times3=11$，第七項 $5+6\times3=23$，都吻合。
</Answer>

這題也可先寫第三項等於首項加兩次公差、第七項等於首項加六次公差，再相減消去首項。從間隔直接推算較短，列出兩個關係則較容易核對已知位置；兩種方法用的都是固定公差。

### 留空最後兩步

等比數列首項三、公比負二。請先寫通項，再求第五項，並檢查符號。

<Answer>
$a_n=3(-2)^{n-1}$，$a_5=3\times16=48$。回頭檢查：三、負六、十二、負二十四、四十八，負公比讓符號交替，第五項是正的。
</Answer>

### 獨立完成

某等差數列首項二十、公差負四。求第六項，再判斷零是否出現在這個數列裡，並回頭檢查。

<Answer>
$a_6=20+5\times(-4)=0$，所以零在第六項出現。依序二十、十六、十二、八、四、零，五次減四，吻合。
</Answer>

## 常見迷思

<Misconception>

「等差數列第十項就是首項加十次公差。」請指出多算的那一步。

---

第一項本身已經是起點，第十項只跨九個間隔，所以應加九次公差；代入第一項檢查公式，最容易發現這種錯位。

</Misconception>

診斷題：首項七、公差二，第二項是多少？

<Answer>
九，只加一次二；若加兩次會得到第三項十一。
</Answer>

<Misconception>

「等比數列公比的絕對值大於一，項值一定一直增加。」哪個情況反駁這句話？

---

負公比會讓正負交替；例如首項一、公比負二時，一、負二、四、負八不會一直增加。絕對值變大與項值增加是兩回事。

</Misconception>

診斷題：首項二、公比負三，第二項與第三項各為多少？是否逐項增加？

<Answer>
第二項負六，第三項十八。從二到負六先下降，所以不是逐項增加。
</Answer>

## 練習

這裡交錯不同題型，錯得比較多是正常的；先辨認固定差還是固定倍數，長期記得比較牢。

1. 等差數列首項四、公差三，求第六項。

<Answer>
$a_6=4+5\times3=19$。五個間隔共增加十五，與首項相加得十九。
</Answer>

2. $a_n=n^2+2$，求 $a_4$，並指出四是項號還是項值。

<Answer>
$a_4=18$；四是項號，十八才是項值。
</Answer>

3. 等比數列首項五、公比三，求第四項。

<Answer>
$a_4=5\times3^3=135$。五、十五、四十五、一百三十五，共乘三次三。
</Answer>

4. 二、五、八、十一這四項的相鄰差與相鄰比各是否固定？

<Answer>
差都為三；比依序為 $\frac52$、$\frac85$、$\frac{11}8$，不相同。只能判斷這四項符合等差，後面仍需規則。
</Answer>

5. 計算 $(-2)^4$ 與 $(-2)^3$，說明符號不同的原因。

<Answer>
分別為十六與負八。偶數個負數相乘為正，奇數個負數相乘為負。
</Answer>

6. 等差數列第二項七、第五項十九，求公差與首項。

<Answer>
三個間隔增加十二，公差四；首項 $7-4=3$。驗算第二項七、第五項 $3+4\times4=19$。
</Answer>

7. 只知道前三項一、二、四，就能確定第十項是五百一十二嗎？說明還需要什麼。

<Answer>
不能。需另知後面每次也都乘二，才能用首項一、公比二的規則得到 $2^9=512$；有限三項不足以唯一延伸。
</Answer>

8. 首項六，每次乘負二分之一。求第五項並保留最簡分數。

<Answer>
$a_5=6\left(-\frac12\right)^4=\frac38$。四次乘負數，結果為正；依序六、負三、二分之三、負四分之三、八分之三。
</Answer>

9. 首項九，每次乘零。第二項與第五項為何？能否用相鄰兩個零相除，求出公比？

<Answer>
第二項與第五項都是零，直接用固定倍乘規則得到；不能做零除以零。題目已給公比零，不是從後面的零項比值算出來。
</Answer>

## 提取題

不看前文公式，先憑記憶回答，再核對。

1. 等差數列的通項是什麼，為什麼有 n 減一？

<Answer>
$a_n=a_1+(n-1)d$；從首項到第 n 項只有 n 減一個間隔。
</Answer>

2. 公比非零的等比數列通項是什麼？

<Answer>
$a_n=a_1r^{n-1}$；從第一項起共乘 n 減一次公比。
</Answer>

3. 負公比會怎樣影響非零項的符號？

<Answer>
每乘一次負公比就反號，正負交替；不能只看絕對值大小判斷項值一直增加。
</Answer>

4. 用相鄰項相除找公比前，要檢查什麼？

<Answer>
前項不能為零；零除以零沒有定義。零首項或零公比要回到固定倍乘的遞迴直接處理。
</Answer>
