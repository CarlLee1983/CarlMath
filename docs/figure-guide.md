# 教具繪製規範

本文件是繪製 CarlMath 教具的依據，讀者是之後新增教具的站主與 agent。內容涵蓋 SVG 的結構、版面尺寸、色票語意、替代文字、共用元件 `NumberLine`、`Counters`、`FractionBar`、`Shape`、`UnitGrid`、`AreaModel`、`BalanceScale`、`CoordPlane` 與 `FunctionGraph` 的參數，以及發布前的驗收。教具在教材裡怎麼用（配文字說明、表徵數量、import 寫法）屬於[內容撰寫規範](content-guide.md)，本文件不重述。

單一版面與封閉色盤是 [ADR 0002：教具採單一版面與封閉色盤](adr/0002-figures-single-layout-closed-palette.md) 的決定：教具是數線、點陣、積木這類幾何規則的圖，等比縮放就能讀，所以只畫一份 SVG；顏色只用閱讀頁的色票 token，讓同一個顏色在全路線意思一致，深色模式也不必逐圖處理。代價是每張圖的文字量與寬度受限，複雜的圖必須拆開。

## 先用共用元件

數線一律用 `NumberLine`，小物圓點一律用 `Counters`，等分的長條（分數條）一律用 `FractionBar`，多邊形、角與圓一律用 `Shape`，單位方格一律用 `UnitGrid`，長方形面積模型（把乘法或分配律拆成幾塊）一律用 `AreaModel`，方程式的天平（x 盒子與 1 的砝碼、失衡、兩邊拿掉）一律用 `BalanceScale`，坐標點與象限一律用 `CoordPlane`，函數曲線一律用 `FunctionGraph`，讓這些圖在全路線長得一樣。它們都放在 `src/components/figures/`，教材以 `@figures/NumberLine.astro`、`@figures/Counters.astro`、`@figures/FractionBar.astro`、`@figures/Shape.astro`、`@figures/UnitGrid.astro`、`@figures/AreaModel.astro`、`@figures/BalanceScale.astro` 匯入。數線與分數條的疊排分數共用同一個內部元件 `StackedFraction`，不由教材直接匯入；一次性教具需要圖內分數時要匯入它，讓全路線的分數長得一樣。共用元件畫不出來的圖，才做成一次性的 `<主題>Figure.astro`，和該單元的教材放在一起，並遵守下面每一條規則。

教具元件只輸出 `<svg>`。圖名下方的說明文字由 `<Figure caption="…">` 負責，不寫在 SVG 裡。

## SVG 結構

- 用原生 SVG，不用 Mermaid 或任何圖表 runtime。
- 根元素寫 `role="img"`，`aria-labelledby` 依序指向圖內的 `<title>` 與 `<desc>`。
- 圖內每個 `id`（包括 `<title>`、`<desc>`、`<marker>`、漸層）都加元件前綴，例如 `nl-…`、`ct-…`，同一頁有多張圖也不會撞名。共用元件的前綴由參數雜湊而來，輸出是決定性的。
- 只寫 `viewBox`，不寫 `width`、`height`。
- 樣式用元件的 scoped `<style>`，線寬、字級、顏色寫在 class 上，不寫在每個元素的屬性裡。
- SVG 裡不能用 KaTeX；需要公式時寫在 `<Figure>` 的說明或正文。

## 版面：單一版面、等比縮放

| 項目 | 規定 |
| --- | --- |
| `viewBox` 寬 | 480，高度依內容決定 |
| 顯示寬上限 | 32rem，窄螢幕等比縮小到容器寬 |
| 字級（viewBox 單位） | 數字 22，文字標籤 20，下限 20 |
| 線寬 | 主線 3，刻度與輔助線 2，跳躍弧 2.5，端點一律圓頭 |
| 文字標籤 | 每張圖最多三個（刻度上的數字不算；面積模型的例外見下；幾何圖的算法見 [`Shape`](#shape) 一節） |

**面積模型的例外**：把乘法拆成長方形面積的圖（例如 23 × 14 拆成 20、3 與 10、4），邊上的長度數字視同刻度數字，格內每格一個面積數字也不另計，但最多 4 格（橫段數 × 縱段數，例如 2 × 2、1 × 3）。理由是面積模型的價值就在圖上的邊長、格內面積與式子逐一對應，刪掉任何一組數字都會失去這個對應，而一張 2 × 2 的圖又拆不成兩張。超過 4 格時仍要拆圖。分數乘法的面積格（例如 3/4 × 2/3 把正方形切成 4 × 3 格）也算面積模型：邊上的分數視同刻度數字，格內不寫數字，所以不受 4 格的限制。畫整數、小數與字母式的面積模型一律用 [`AreaModel`](#areamodel)，不再另做一次性教具；它的參數與上限見該節。

320px 寬時，480 寬的圖會縮成約 0.6 倍，字級 20 約等於 12px，這是可讀的下限。字再小、標籤再多、或者刻度數字擠在一起時，不要縮字級，把圖拆成兩張。

### 坐標圖的標記（CoordPlane 撰寫約定）

本節記錄坐標階段已定案的繪圖規則；`CoordPlane` 元件邊界沿用 ADR 0005，實際參數見下方 `CoordPlane` 一節。

- 軸名 x、y、原點 O 與刻度數字是基本標記，不計入每圖三個文字標籤的額度。
- 原點只顯示一個 O，不重複顯示兩軸的 0。O、鄰近刻度與點名須錯開，不能靠縮小字級解決重疊。
- 點名另計，每圖最多四個；說明性文字仍最多三個。擁擠時拆圖。
- 四象限介紹圖可放四個象限名稱，但不再疊其他點名與解題說明。
- 沿用整數淡格線；分數坐標的點可落在格線之間，不新增整片分數格線。

## 色票：封閉色盤

教具只能用閱讀頁的色票 token，每個 token 有全站固定的語意：

| token | 用途 |
| --- | --- |
| `--fg` | 主線、數字、文字標籤、一般的圓點 |
| `--muted`、`--line` | 刻度、括號等輔助元素 |
| `--accent` | 讀者該注意的東西，例如數線上的點、跳躍弧、被標記的圓點 |
| `--ok`、`--warn` | 只用於迷思對照，例如並列的錯誤與正確作法 |
| `--bg` | 只用於空心端點的填色，遮住穿過它的主線（例如數線射線的空心圓），不當成區塊底色 |
| `--family` | 不進圖內 |

顏色屬性（`fill`、`stroke`、`stop-color` 等）與 CSS 的顏色宣告，只允許 `currentColor`、`none`、`transparent`、`inherit`、`var(--token)`，以及參照圖內漸層或圖樣（pattern）的 `url(#id)`。這類 id 每張圖不同，`fill={`url(#…)`}` 可以寫在元素屬性上，是「顏色寫在 class 上」的唯一例外。`var()` 不得帶 fallback 色碼，例如 `var(--accent, #2563eb)` 不合格；hex、色名、`rgb()`、`hsl()` 都不允許，frontmatter 裡的 hex 字串也算。內容驗證掃描內容根目錄 `lessons/` 下的 `*Figure.astro`；共用教具由 `tests/figure-components.test.mjs` 套用同一套規則。

**顏色不能是唯一的訊息來源**：要區分的東西，除了顏色還要有形狀、虛實線或文字標籤的差別。例如數線上的點是實心圓、跳躍弧帶箭頭；`FractionBar` 塗色的份是實心、沒塗的份只有框線；`Counters` 被標記的圓點是實心，其餘是空心。色弱讀者把圖看成灰階時，仍要分得出來。

## 替代文字

- **`<title>`**：10 個字以內的圖名，例如「從 3 跳到 7」；空格也算一個字。
- **`<desc>`**：用完整句子寫出圖中的數值和對應關係，讓不看圖的讀者也能理解，例如「0 到 10 的數線，每一格是 1。3 有一個點，從 3 往右畫一道弧線跳到 7，弧線上標著加 4。」不要只寫「一條數線」。
- **讀圖練習的替代文字**：提供與圖相同的已知資訊，不提前給出待求結果。例如要求讀出 A 點坐標時，可寫「每格代表 1；A 位於原點右方第三條垂直格線與上方第二條水平格線的交點」，不直接寫出 A 的坐標。讓讀者自行判斷坐標順序、正負與象限；答案與推理放在收合解析。幾何題同樣描述已知邊長、角度與對應關係。這是資訊等值的文字作答方式，不宣稱也測得視覺讀圖能力；不能為了避免透露答案而省略作答必需的資訊。
- **`figcaption`**（`<Figure caption>`）：只寫「請注意看什麼」，不和 `desc` 重複。
- **數字的寫法**：`desc`、`caption`、`note` 裡的整數量、個數、長度與度數一律寫阿拉伯數字（「4 塊」「60°」），分數與小數照各元件一節用中文讀法（分數條的份數與塗色數屬於分數讀法，照 `FractionBar` 一節寫「平分成四份」）；國字只用於序數（「第一道弧」）、分數讀法（「四分之一圈」）與不表示數量的「一」（「一個圓」「一條邊」）。同一段文字不混用「八個」與「4 片」。`desc` 裡的負數是例外，一律寫中文讀法（「負五」「負二分之一」），正數與 0 照舊寫阿拉伯數字，所以寫「從負五到 5」，不寫「負 5」或「負五到五」；`caption` 與 `note` 的負數照[內容撰寫規範](content-guide.md)的「純文字欄位的負號」寫「−5」。

共用元件的 `title` 與 `desc` 是必填參數，`title` 超過 10 個字或任一欄空白時 build 失敗。`desc` 是否真的寫出數值與對應關係，只能靠人看。

## `NumberLine`

```mdx
<Figure caption="從 3 往右跳 4 格，停在哪裡">
  <NumberLine
    title="從 3 跳到 7"
    desc="0 到 10 的數線，每一格是 1。3 有一個點，從 3 往右畫一道弧線跳到 7，弧線上標著加 4；3 到 7 下方有括號，標著 4 格。"
    from={0}
    to={10}
    points={[{ at: 3 }]}
    jumps={[{ from: 3, to: 7, label: "+4" }]}
    spans={[{ from: 3, to: 7, label: "4 格" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `from`、`to` | 必填，數線的起點與終點，`from` 小於 `to`；位置值的寫法見下 |
| `step` | 刻度間隔，預設 1；`to − from` 必須是 `step` 的整數倍；**它的寫法決定刻度標籤的寫法**，見下；寫成分數時必須是最簡分數（`"1/2"`，不寫 `"2/4"`），否則 build 失敗；`labelEvery` 同理 |
| `labelEvery` | 只標這個數的倍數，必須是 `step` 的正整數倍，可以寫分數或小數；不給時依下面的規則 |
| `mixed` | 預設關閉；開啟時大於 1 的分數刻度寫成帶分數。只能搭配 `"a/b"` 寫法的 `step`，`step` 是數字時開啟會 build 失敗 |
| `points` | 數線上的點：`{ at, label? }` |
| `jumps` | 跳躍弧：`{ from, to, label? }`，畫在數線上方，終點有箭頭 |
| `spans` | 距離括號：`{ from, to, label? }`，畫在數字下方 |
| `rays` | 單邊射線（不等式的解）：`{ from, direction, open }`，`direction` 是 `"left"` 或 `"right"`，`open` 是 `true` 或 `false`，三個欄位都必填；射線是寬 5 的 `--accent` 粗線，從端點延伸到數線那一端並帶箭頭，`open` 為真畫空心圓（不含端點、填 `--bg`），否則畫實心圓（含端點） |

- **位置值**（`from`、`to`、`step`、`labelEvery`、`points[].at`、`jumps[].from/to`、`spans[].from/to`、`rays[].from`）寫成數字或 `"a/b"` 字串。數字依它的十進位字面轉成精確分數（`0.1` 就是 1/10，不經浮點運算，所以 `step={0.1}` 時 `0.3` 在刻度上）；字串必須是整數分子、正整數分母，`"1/0"` 或 `"1.5/2"` 這類寫法 build 失敗。內部以約分後的有理數比較，`"2/4"` 與 `"1/2"` 是同一個位置。所有位置都必須落在刻度上。
- **標籤寫法由 `step` 的寫法決定**，不另設格式參數：`step="1/4"` 這類字串，非整數刻度標成疊排分數，分母沿用刻度的分母、不約分（每格 1/4 時，1/2 的位置標 2/4）；`step={0.1}` 這類數字，非整數刻度標成十進位小數；整數刻度不論哪一種都只寫整數。
- 疊排分數是上下排的分子、分數線、分母，數字字級 22，分數線與刻度同寬、顏色用 `--fg`；帶分數的整數部分接在疊排真分數左邊。有疊排分數時，數線下方依實際高度加高，`spans` 的括號與標籤往下移，不與分數重疊。疊排分數不算進下面的文字標籤上限。
- **負數**：`from` 可以是負數，位置值直接寫 `-3`、`-1.5`、`"-1/2"`。刻度、點與標籤裡的負號一律是數學減號「−」（U+2212），不是連字號「-」；整數與小數刻度由元件自動輸出，`points`、`jumps`、`spans` 的 `label` 是作者自己寫的字串，要寫負數時必須直接打「−」，標籤裡的連字號「-」（後面可隔空格）後面接數字、分數字元（如 ½）、小寫字母或左括號（例如 `-3`、`5 - 2`、`-x`、`-½`）會 build 失敗，不自動轉換；點的名稱 `A-B` 這種大寫字母之間的連字號不受影響。
- **負分數**：負號畫在整個疊排分數的左邊（`.sf-sign`），垂直置中對齊分數線，分子分母仍是正數，分母沿用刻度的分母、不約分（每格 1/4 時，−1/2 的位置標 −2/4）。開啟 `mixed` 時，絕對值大於 1 的負分數寫成帶分數，負號在整數部分左邊（−3/2 標成 −1½）。負號與整數部分、分數一起置中於刻度，帶負號的分數比正的寬，320px 上每多一個負號標籤就更擠，段數比照帶分數的限制，用 `labelEvery` 少標幾個。疊排分數的負號版面在 `src/lib/stacked-fraction.ts`，數線與分數條共用。
- 刻度間隔一律等距，0 的刻度加粗加長。
- 兩張參數完全相同的數線放在同一頁，`id` 前綴會相同；同一頁不要重複放一模一樣的圖。
- 10 段以內每格都標數字。超過 10 段時，整數數線只標 5 的倍數（含 0）、兩端點與 `points` 的位置；分數與小數數線只標整數、兩端點與 `points`。`labelEvery` 用來改掉「5 的倍數」或「整數」這一項（照它標，仍加上兩端點與 `points`），10 段以內給了 `labelEvery` 也照它標。帶分數或兩位以上的小數標籤比整數寬，10 段以內也可能在 320px 擠在一起（實測 9 段的帶分數、10 段的一位小數都讀不清）；這時用 `labelEvery` 只標整數或少數幾個刻度，要讀者注意的位置改用 `points` 標出。
- `points`、`jumps`、`spans` 的 `label` 合計最多三個。射線不帶標籤，不算進這個上限。
- 有射線時，`<desc>` 要寫出端點、空心或實心與方向，例如「從 120 往右的粗線，120 是實心圓，表示含 120」；不等號照負數的前例寫中文讀法（「大於或等於」）。只做單邊射線，兩端都有界的區間不畫。
- `<desc>` 裡的分數與小數用中文讀法：「四分之三」「一又二分之一」「零點三」，不寫 `3/4`；負數在前面加「負」：「負三」「負二分之一」「負一又二分之一」「負一點五」，不寫 `-3` 或「−3」。
- 刻度數字最多 4 位數。量更大時改變一格代表的單位，例如一格代表 1 萬或 1000，`from`、`to` 照單位寫成小數字，並在 `desc`、說明或 `spans` 標籤寫明一格代表多少。5 位以上的端點數字可能被裁切，這條規則先擋下，不必逐張確認。兩端離邊緣的距離至少 28，端點標籤比較寬時（例如 −1000、−10½，含負號）元件依標籤寬度自動加大，所以負的 4 位數端點不會被裁切；刻度間距會因此略為縮短。

## `FractionBar`

```mdx
<Figure caption="平分成 4 份，塗 3 份">
  <FractionBar
    title="四分之三"
    desc="一條長條平分成四份，從左邊塗滿三份，右側標著四分之三。"
    bars={[{ parts: 4, shaded: 3, label: "3/4" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `bars` | 1 到 4 條，每條 `{ parts, shaded, label? }`，由上往下排 |
| `parts` | 等分成幾份，1 到 24 的整數 |
| `shaded` | 從左邊連續塗滿幾份，0 到 `parts` 的整數 |
| `label` | 畫在條右側：`"a/b"` 字串畫成疊排分數，整數畫成純文字 |

- 每條代表同一個整體，長度相同；塗色的份以 `--accent` 實心填滿，沒塗的份只有框線，外框是主線（寬 3、`--fg`），等分線是輔助線（寬 2、`--muted`，與數線刻度相同）。
- `label` 的分數照寫的樣子畫、不約分（`"2/4"` 就畫 2/4），畫法與數線刻度的疊排分數相同，數字字級 22。
- **對齊條件**：版面寬 480、左右各留 28，與 `NumberLine` 相同。沒有任何一條帶 `label` 時，條的左右端對齊數線上 `from`、`to` 的 x 座標，所以分數條放在 0 到 1 的數線正上方（`step` 與 `parts` 相配，例如 `step="1/4"` 配 `parts={4}`）時，等分線與刻度對齊。只要有一條帶 `label`，所有條都會縮短，為右側標籤騰出空間，此時不保證對齊。
- 不支援：假分數（`shaded` 大於 `parts`）、從中間或任意位置塗色、二維切割（長方形或圓的切法）。這些要另做一次性教具。
- `<desc>` 用中文讀法寫出份數與塗色數，例如「平分成四份，塗滿三份」，不寫 `3/4`。

## `Shape`

三角形、平行四邊形、圓這類平面圖形一律用 `Shape`，作者以抽象座標宣告形狀，元件負責縮放與標記。為什麼不含座標軸與格線，見 [ADR 0003：平面圖形共用教具以抽象座標宣告、自動縮放，不含座標軸](adr/0003-shape-abstract-coordinates-no-axes.md)。版面計算與驗證在 `src/lib/shape-geometry.ts`。

```mdx
<Figure caption="45° 的角在哪個頂點，虛線是哪一條高">
  <Shape
    title="直角等腰三角形"
    desc="頂點 A、B、C 的直角等腰三角形：A 是直角，B 是 45°，C 的角未知；A 到 C 與 A 到 B 這 2 條邊長度相等，各有 1 條短斜線，A 到 B 的邊長是 4；從 A 向斜邊畫一條虛線的高，標著高。"
    polygons={[
      {
        vertices: [[0, 0], [4, 0], [0, 4]],
        names: ["A", "B", "C"],
        sides: [{ side: 0, label: 4, equal: 1 }, { side: 2, equal: 1 }],
        angles: [{ at: 0, right: true }, { at: 1, degrees: 45 }, { at: 2, degrees: "?" }],
      },
    ]}
    guides={[{ from: [0, 0], to: [2, 2], label: "高" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `polygons` | 多邊形清單，每個 `{ vertices, names?, filled?, sides?, angles? }`，見下 |
| `circles` | 圓清單，每個 `{ center, radius, show?, label? }`，見下 |
| `guides` | 虛線輔助線段，每條 `{ from, to, label?, right? }`，例如三角形的高，見下 |

`polygons` 與 `circles` 至少要有一個；一張圖可以有多個圖形。

- **座標**：`[x, y]`，y 軸朝上，單位任意（寫 `[0, 0]`、`[4, 0]`、`[0, 3]` 或放大十倍畫出來一樣）。元件依所有圖形的外接範圍等比縮放到 viewBox 寬 480，水平置中，高度依內容決定，y 軸自動翻轉。標籤太長時會自動縮小圖形，讓標籤不超出畫面；長到縮小也放不下時 build 失敗，訊息指出是哪個標籤，要縮短標籤或把圖拆成兩張。
- **`vertices`**：至少 3 個頂點，依序連成封閉的多邊形，順時針或逆時針都可以，頂點不能全在同一條直線上。頂點編號從 0 起算，第 `i` 條邊是頂點 `i` 到頂點 `i + 1`（最後一條接回 0）。
- **`names`**：頂點字母，如 `["A", "B", "C"]`，數量須與 `vertices` 相同，每個只能是單一大寫拉丁字母（A–Z），否則 build 失敗（想放文字用 `label`，會算進文字標籤上限）；畫在頂點外側。
- **`filled`**：整塊塗 `--accent`（半透明，讓區內的度數與輔助線看得見），外框仍是主線；沒塗的只有外框，灰階下分得出來。
- **`sides`**：每項 `{ side, label?, equal?, parallel? }`。`label` 畫在邊的外側，不驗證比例，所以示意圖可以寫「100 公尺」而不按比例畫；`equal`（1–3）在邊中點畫 1–3 條短斜線，同一組相等的邊寫同樣的數字；`parallel`（1–2）在邊上畫 1–2 個箭頭，同一組平行的邊寫同樣的數字，箭頭方向一致。
- **`angles`**：每項 `{ at, degrees? 或 right? }`。`degrees` 寫數字會畫角弧與「N°」，寫 `"?"` 畫角弧與「?」（練習題用，不洩漏答案）；`right: true` 畫直角記號（小方框）取代角弧，不寫度數。`degrees` 與 `right` 擇一。
- **`circles`**：`show` 是 `"radius"`（圓心向右的半徑）或 `"diameter"`（通過圓心的水平直徑），線段帶圓心點；`label` 畫在線段上方，須搭配 `show`。不寫 `show` 就只畫圓。
- **`guides`**：`--muted` 虛線，與實線外框以線型區分。`label` 畫在線的一側。`right: true` 在 `to`（垂足）畫直角記號，小方框夾在輔助線與它落在的那條邊之間、朝向輔助線那一側；`to` 必須落在某個多邊形的邊上，且輔助線與該邊夾角 90°（±1°），否則 build 失敗，訊息指出是不在邊上還是不垂直、實際夾角多少。多條邊都符合時取第一個多邊形的第一條。

**標籤上限**（每張圖合計，超過任一項 build 失敗，要把圖拆成兩張）：

| 類別 | 算什麼 | 上限 |
| --- | --- | --- |
| 邊長與度數 | `sides`、`circles`、`guides` 的 `label` 中含數字的（`4`、`"100 公尺"`），加上 `angles` 的 `degrees`（數字與 `"?"` 都算） | 合計 6 |
| 頂點字母 | `names` 的字母，所有多邊形合計 | 4 |
| 文字標籤 | `label` 中不含數字的（「底」「高」「半徑」） | 3 |

邊長與度數視同刻度數字（字級 22），文字標籤字級 20，頂點字母字級 22；直角記號、等邊記號與平行記號不算標籤。線寬：外框與圓是主線 3，角弧與直角記號 2.5（`--accent`），等邊與平行記號、虛線輔助線 2。

**度數驗證**：`degrees` 是數字時，build 依頂點座標算出實際內角（凹角大於 180° 也算），和標的度數相差超過 1° 就失敗，訊息指出哪個頂點、標的度數與實際度數，例如「`polygons[0].angles[0]`（頂點 1）標了 40°，但依座標算出來約是 36.9°」；`right: true` 也驗證是 90°。`"?"` 與邊長標籤不驗證。修法是改座標或改標籤，不要改成 `"?"` 來繞過。

- 不支援：座標軸與格線（ADR 0003；坐標平面與函數圖形另用專用元件，見 [ADR 0005](adr/0005-coordinate-figures-family-components.md)）、比例尺、**刻意不按比例的角**。`Shape` 不開度數驗證的例外，刻意不按比例的角（例如誇大的示意角）要做成一次性教具。
- 也不支援：弧或曲邊的多邊形、圓的填色、圓上的弦與切線。需要時另做一次性教具。
- `<desc>` 寫出頂點、邊長、角度與記號對應的邊與角，例如「A 到 C 與 A 到 B 兩條邊長度相等」，不只寫「一個三角形」。

## `CoordPlane`

坐標平面的點、線段、完整圓與象限用 `CoordPlane`；沒有坐標軸的幾何示意仍用 `Shape`。教材明確以 `import CoordPlane from "@figures/CoordPlane.astro";` 匯入，不是內建教材元件。範圍與標記驗證在 `src/lib/coord-plane.ts`，元件只輸出 SVG。

```mdx
<Figure caption="A 在原點右方、上方">
  <CoordPlane
    id="first-location"
    title="兩個數定位"
    desc="每格 1；A 位於原點右方 2 格、上方 1 格。"
    xRange={[-3, 3]}
    yRange={[-3, 3]}
    points={[{ at: [2, 1], name: "A" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `id` | 必填，穩定的作者識別名：小寫英文字母開頭，後接小寫英文字母、數字或連字號。同一頁每個實例必須不同，即使圖形、圖名與替代文字完全相同也要分別命名。識別名納入決定性雜湊，連到每張圖自己的 title、desc，不用隨機值或全域計數器 |
| `title`、`desc` | 必填，沿用共用替代文字檢查；title 最多 10 個字元 |
| `xRange`、`yRange` | 必填，各為 `[最小值, 最大值]`；兩端有限、嚴格遞增且包含 0，跨度各為 2 到 8（含端點）。端點與點都可用有限小數表示分數位置 |
| `points` | 點陣列，每個 `{ at: [橫坐標, 縱坐標], name? }`，最多 12 點；坐標須在範圍內，最多 4 個點名。name 為 O 以外的單一大寫英文字母，同圖不得重複；不寫 name 就只畫點 |
| `quadrants` | 預設 false；true 時固定顯示四個中文象限名，兩軸都須有正負範圍，且不能給任何 points、segments 或 circles，避免疊加點名或解題資訊 |
| `circles` | 選填，每圖最多 1 個 `{center:[x,y],radius:r}` 完整圓；圓心須是視窗內有限坐標，r 為正有限數，換算半徑至少 1 個 viewBox 單位。圓心左右上下各加減 r 均須在視窗內（貼邊合法），否則拒絕建置，不裁切圓周。省略為空陣列，不接受 null |
| `segments` | 線段陣列，每個 `{ from: [x, y], to: [x, y], auxiliary? }`，最多 12 條。端點與 points 共用有限值、合法範圍驗證及等比轉換；可用有限小數表示分數。auxiliary 只接受布林值，預設 false；重合端點允許，表示零長度 |

- 橫軸向右、縱軸向上為正；兩軸等比例。繪圖區兩方向至多 360，單位長至少 45，整數格線每格 1；分數點位在格線之間，不新增分數格線。只有一個 O，兩軸不再標 0。主線寬 3、格線與刻度寬 2，點用 accent 實心圓，數字與點名字級 22、象限文字 20，不靠縮字塞入。
- 點名依固定的 8 個相鄰位置依序嘗試，預留 O、軸名、刻度數字、所有點及先放入的點名的保守字框，並避開軸線與線段。放不下時 build 以點名提示拆圖或調整範圍；四象限名也須避讓基本標記，正負範圍過度不平衡時 build 失敗。此為有限候選的簡單排版，不保證所有密集輸入都有位置。
- 線段穿過刻度數字的保守字框時，刻度先在同一刻度附近的 5 個固定位置避讓，保留字級；候選須避開軸線、線段、點及其他文字。放不下就以刻度值提示拆圖或調整範圍。沒有線段的既有圖保留原刻度位置。
- 目前不接受自由說明文字，請寫在正文或 Figure 說明中；每圖最多 3 個說明標籤的規範仍適用，不為本元件開放任意圖層。實線段是寬 3 的 fg 主線；auxiliary 線段為寬 2 的 muted 虛線（8、6），以線型區分，不只靠顏色。三角形或其他坐標圖形逐邊寫成線段，不另提供多邊形或通用圖層。desc 須交代端點及輔助線的角色，不能把輔助路程誤稱為待求的直線距離。
- 無效識別名、範圍、點或線段坐標、auxiliary、點名、超量、象限混用或無法避讓都會在 build 失敗，不會裁掉資料或縮小字級。作者仍須檢查真正的中文字型字框及手機可讀性。同頁識別名的唯一性是作者責任，fixture 驗證同圖不同 id 的關聯。
- 完整圓使用同一單位長換算圓心與半徑，以原生 SVG circle 畫寬 3 的 fg 圓周、不填色；不把不等長視窗拉成橢圓。圓心、圓周點與半徑另用既有 points、segments 明示；一般點不強制在圓周上。例：`circles={[{center:[1,1],radius:2}]}`，兩軸 `[-2,4]`，可搭配 `[1,1]` 到 `[3,1]` 的半徑線段。
- 有圓時 O、軸名、刻度與點名都須避開圓周。圓周與保守字框以圓心至矩形的最短／最遠距離解析判斷，不靠角度取樣，也不把整個圓內部當成禁止放字的區域。候選仍有限，放不下就請作者調整範圍或拆圖。沒有圓的既有版面保持原配置。

- 讀點練習的 desc 寫相對原點的方向與格數，不寫待求數對或象限答案；必要的格數與每格單位仍要完整提供。

## `FunctionGraph`

函數曲線使用 `FunctionGraph`，依 ADR 0005 與坐標幾何用的 `CoordPlane` 分開。資料驗證、解析裁切與標記配置由 `src/lib/function-graph.ts` 負責，元件只輸出 SVG。本版每圖一個常數、一次、二次、三次、指數或對數函數，不接受 JavaScript 函式、運算式字串或其他函數族；比較多個函數時拆圖。

```mdx
import FunctionGraph from "@figures/FunctionGraph.astro";

<Figure caption="起始水量 3 公升，每分鐘增加 2 公升">
  <FunctionGraph
    id="tank-function"
    title="時間與水量"
    desc="橫軸每刻度 1 分鐘，縱軸每刻度 2 公升。直線從 0、3 到 3、9，兩端是實心圓；A 位於 2、7。"
    xRange={[-1,4]}
    yRange={[-1,10]}
    yStep={2}
    fn={{linear:[2,3]}}
    domain={{from:0,to:3,openFrom:false,openTo:false}}
    points={[{at:[2,7],name:"A"}]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `id`、`title`、`desc` | 必填，沿用 CoordPlane 的穩定識別名與共用替代文字契約。每個實例的 id 在同頁必須不同，參數共同產生決定性雜湊；title 最多 10 字 |
| `xRange`、`yRange` | 各為兩個有限數的嚴格遞增範圍，必須包含 0；兩軸可不同比例，**不是函數的定義域** |
| `xStep`、`yStep` | 預設 1，須為正安全整數；刻度位於它的整數倍，每軸最多 8 個刻度間隔（包含 0 所在位置），數字最多 4 位。密集時增加間距或拆圖，不能縮字；desc 明寫各軸刻度單位 |
| `fn` | 恰好一個族：`{linear:[a,b]}` 表示一次函數，兩個係數必須有限且 a 非零；`{constant:c}` 表示常數函數，c 必須有限。零係數不寫 linear；`{quadratic:[a,b,c]}` 表示 y = ax² + bx + c，3 個係數必須有限且 a 非零，退化的一次或常數函數改用對應族；`{cubic:[a,b,c,d]}` 表示 y = ax³ + bx² + cx + d，4 個係數有限且 a 非零。不接受可變階數的 polynomial 陣列；`{exponential:[base]}` 表示 y = baseˣ，僅 1 個正有限且不等於 1 的底數；base=1 請用 constant，不接受 exp 別名；`{logarithmic:[base]}` 表示 y = log_base(x)，同樣限正有限且非 1 的底數，天然定義域 x > 0，不提供平移或 log 別名 |
| `domain` | 省略時一般族表示全體實數，logarithmic 表示天然定義域 x > 0。提供時四欄必填：`{from,to,openFrom,openTo}`，有限端點是數字，無界端用 `null`；openFrom/openTo 必須是布林值，true 為開放。null 端必須 true。from 小於 to；相等時僅雙閉合法，表示單點域。logarithmic 額外要求有限 from 為正數或開放的 0、有限 to 為正數；from=null 仍受 x > 0 限制，不接受負下界或封閉的 0 |
| `points` | 選填，最多 12 個 `{at:[x,y],name?}`。必須在視窗、定義域與函數曲線上，不能在開放端點畫實心標記。曲線數值核對的容差為相對誤差 1e−10（以 1 為尺度下限）與縱軸跨度的 1e−8 倍兩者較小值，避免放大視窗後標記明顯離線。最多 4 個不重複點名，為 O 以外的單一大寫字母 |

- 固定寬 480，繪圖區 360 × 360；兩軸獨立換算單位長，**不畫格線**。主角曲線用 fg 主線，刻度用 muted，點與端點用 accent；空心端點填 bg，以空／實心區分開閉，不只靠顏色。文字 22、主線寬 3、刻度寬 2。原點只標 O，不重複兩個 0。
- 一次與常數函數以解析式求視窗交點，不用稀疏取樣。二次函數以解析頂點與水平邊界交點切出可見區段，每段用精確的 SVG 二次 Bézier 曲線表示，不用取樣點連線；頂點在視窗外時兩支曲線不會被錯誤相連。頂點由係數計算，作者要突出頂點時仍用 `points` 標記，並接受與其他點相同的曲線核對，不新增頂點或對稱軸參數。曲線可裁切；只有原定義域的有限端點位於畫面時才畫端點圈，視窗邊界本身不產生端點圈。真端點恰好落在邊界仍完整顯示；單點域畫一個實心點，與重合的 points 去重。軸箭頭表示坐標軸方向，曲線本身不加箭頭；有無延伸由 domain 與 desc 說明。
- 三次函數由導函數實根分成單調區間，以有括界且檢查誤差的求根求視窗交點，每段用精確 SVG 三次 Bézier（C 指令）呈現。求根不是取樣折線；分離可見分支不互連，接觸視窗的切點仍受定義域開閉約束。誤差、導函數、控制點或投影精度不可靠時拒絕建置。三次字框避讓檢查參數區間內的全部導函數根與端點，不只檢查端點弦。

- 指數函數採**有誤差上限的自適應折線近似**，不是精確 Bézier。令 k = ln(base)，每段寬 h 的線性插值垂直誤差上界為 `h² × k² × max(兩端函數值) × yUnit / 8`。這來自二階導數的解析界，不是靠稀疏取樣估計。每段含數值安全餘量後須不超過 0.1 個 viewBox 單位；不符就二分，最多 4096 段、深度 64，不能達標就拒絕。exp/log 與投影的浮點運算另有保守精度檢查；不宣稱形式化區間運算證明。
- 指數曲線透過對數反解與視窗上邊界的交點，遞增／遞減分別裁掉對應一側。標記仍核對真函數，不核對近似折線；可分辨的標記 x 值納入折線節點。字框檢查以單調函數的完整值域判斷，另擴張 0.1 單位以涵蓋近似誤差。有限端點與單點域沿用原規則，反解浮點誤差不應吞掉像 3²=9 的真邊界端點。
- 指數函數始終大於 0，曲線不夾成 0、不補水平線、不在 x 軸畫端點。為避免線寬看起來貼住漸近線，可見曲線最小高度換算後須距 x 軸至少 4 個 viewBox 單位；不足、下溢成 0 或計算不可靠時拒絕，請縮短橫軸視窗或放大縱軸比例。這是可讀性限制，不是改變函數的定義域，也不會偷偷剪掉尾巴。desc 與正文說明趨近 x 軸但不相交。

- 對數函數的自然域固定為 x > 0；0 沒有有限函數值，不能在 y 軸補空心或實心端點。視窗上下界以 baseʸ 反解 x，再與視窗及作者的正數定義域求交。明確的 0 開界與省略域都不畫 y 軸端點；裁切不製造端點。可以可靠核對的整數反解（例如 log₃9 = 2）保留，不任意四捨五入其他對數值。
- 對數同樣是**有界折線近似**。令 k = ln(base)，每段 [u,v] 的 u > 0，誤差界為 `((v−u)/u)² × yUnit / (8 × |k|)`，來自區間上 `|f''|` 的最大值。含安全餘量須不超過 0.1 個 viewBox 單位；沿用最多 4096 段、深度 64。增減兩族都檢查絕對誤差，字框亦擴張誤差量以同時避開真曲線與折線。標記必須在天然域與真函數上。
- 對數可見曲線須距 y 軸至少 4 個 viewBox 單位；不足請縮短縱軸視窗或放大橫軸比例。不把非正值傳給對數、不把下溢交點夾成 0、不偷偷裁尾。極端底數、底數太接近 1、反解／函數值／投影精度不足都會拒絕。

- 原點、軸名、刻度與點名都預留保守字框，避開曲線、軸線、所有點及端點。二次曲線的字框碰撞依解析範圍判斷，包含內部極值，不只檢查端點弦或稀疏取樣。不同端點或點標記互相遮擋時也拒絕建置；固定候選位置放不下就拒絕建置；作者仍須檢查實際字框及窄螢幕。點名的額度沿用坐標圖，沒有任意圖層或自由說明文字。
- 非法族、係數、範圍、端點、標記及過密刻度均拒絕建置。有限資料若在計算時溢位、比例無法可靠表示、二次運算的消去誤差超過縱軸跨度的 1e−8 倍，或視窗內沒有可見圖形，也明確拒絕。錯誤包含 `<FunctionGraph>`、作者 id 與欄位，例如 `points[0].at 不在函數曲線上`、`domain.from`、`xStep 刻度過密`；缺替代文字沿用 `必須有 title`／`必須有 desc`。
- 教材必須明確 import，不是內建元件；沿用合法教具 import、允許清單與檔案存在性驗證，不另建一份註冊表。題圖只標已知資料，待求式子、函數值與解法留在收合答案。

二次函數的最小例子（y = (x − 1)² + 2）：

```mdx
<FunctionGraph
  id="translated-parabola"
  title="拋物線的頂點"
  desc="橫軸每刻度 1，縱軸每刻度 2。拋物線開口朝上，A 在 1、2，B 在 0、3，C 在 2、3；曲線向左右延伸，沒有有限端點。"
  xRange={[-2,4]}
  yRange={[0,10]}
  yStep={2}
  fn={{quadratic:[1,-2,3]}}
  points={[{at:[1,2],name:"A"},{at:[0,3],name:"B"},{at:[2,3],name:"C"}]}
/>
```

平移、伸縮與反射都先展開成二次係數，例如 y = 2(x − 1)² + 3 寫 `{quadratic:[2,-4,5]}`；比較不同函數時維持相同視窗與刻度並分張畫，沒有疊加多條曲線的 API。


三次例子 y = x²(x − 2)：`fn={{cubic:[1,-2,0,0]}}`，可用 `xRange={[-1,3]}`、`yRange={[-4,10]}`、`yStep={2}`，並以 `points={[{at:[0,0],name:"A"},{at:[2,0],name:"B"}]}` 標出與橫軸相切及穿越的兩種零點。A 與原點 O 都保留且錯開；代數結論由教材說明，不新增自動解題標籤。

指數增減對照可分別用 `fn={{exponential:[2]}}` 與 `fn={{exponential:[0.5]}}`，兩圖都設 `xRange={[-3,3]}`、`yRange={[-1,5]}`。前者標 `(0,1)`、`(1,2)`、`(2,4)`；後者標 `(0,1)`、`(-1,2)`、`(-2,4)`，只給 `(0,1)` 一個點名即可。兩圖的可見最小高度為 1/8，距 x 軸 7.5 個 viewBox 單位，滿足上述辨識門檻。

對數正反查詢對照：`{logarithmic:[2]}` 可設兩軸 `[-2,4]`，標 `(1,0)`、`(2,1)`、`(4,2)`；與同視窗的 `{exponential:[2]}` 對照時兩軸單位長相同。遞減例 `{logarithmic:[0.5]}` 使用 `xRange={[-2,4]}`、`yRange={[-2,3]}`，標 `(1,0)`、`(2,-1)`、`(4,-2)`，最小可見 x=1/8，距 y 軸 7.5 單位。後者兩軸比例不同，只用來看遞減，不據螢幕角度宣稱反射對稱。

## `UnitGrid`

```mdx
<Figure caption="塗色的格子是蓋住的面積，粗線圍出的是周長">
  <UnitGrid
    title="L 形的周長"
    desc="4 列 4 行的方格，塗了 L 形的 5 格，粗線沿著塗色區的邊界描出一圈，周長 12 格。"
    rows={4}
    cols={4}
    cells={[[0, 0], [1, 0], [2, 0], [2, 1], [2, 2]]}
    perimeter
    labels={[{ side: "right", text: "周長" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `rows`、`cols` | 列數 1 到 12、行數 1 到 10 的整數，超過 build 失敗 |
| `rects` | 塗色的長方形，每個 `{ row, col, rows, cols }`：左上角的列、行（0 起算，列由上往下）與往下、往右各幾格 |
| `cells` | 逐格塗色，每格 `[row, col]`（0 起算） |
| `perimeter` | `true` 時沿塗色區的實際邊界描外框，表示周長；沒有塗色時 build 失敗 |
| `labels` | 邊上的標籤，每個 `{ side, text }`；`side` 是 `"top"`、`"bottom"`、`"left"`、`"right"`，每邊最多一個 |

- `rects` 與 `cells` 可以並用，重疊的格只算一次；任何一格超出 `rows` × `cols` 的範圍 build 失敗。長方形寫法與逐格寫法塗出的結果完全相同。
- 塗色的格是 `--accent` 實心，沒塗的格只有格線，灰階下仍分得出來。格線是輔助線（寬 2、`--muted`），周長外框是主線（寬 3、`--fg`）。外框沿塗色區的實際邊界走，不規則形狀、凹口與中間挖空的洞都一樣；分開的幾塊各自描邊。
- `text` 是整數時為邊上的格數，視同刻度數字（字級 22），範圍 1 到 99，不算文字標籤；是字串時為文字標籤（字級 20），1 到 3 個字，圖內最多 3 個。標籤置中在塗色區外接範圍的那一邊，沒有塗色時置中在整個方格的那一邊。
- 一格固定 32（viewBox 寬 480），方格置中；12 × 10 是手機上還數得清楚的上限。
- 不支援：半格、斜線、三角形。用方格數三角形面積的圖要做成一次性教具。既有的百格圖不併入 `UnitGrid`。
- **一張圖只放一個主角**：「面積相同、周長不同」的對照，在同一個 `<Figure>` 裡畫兩張 `UnitGrid` 並排，各自有 `title` 與 `desc`，不要在一張圖裡塗兩個形狀。
- `<desc>` 寫出列數、行數、塗了哪些格、塗了幾格，有外框時寫出周長格數，不只寫「一張方格」。

## `AreaModel`

把乘法或分配律拆成長方形面積的圖一律用 `AreaModel`：長方形的橫邊與縱邊各拆成 1 到 3 段，每段寫一個長度，每一格寫面積。版面計算與驗證在 `src/lib/area-model.ts`，元件只畫 SVG。

```mdx
<Figure caption="x 加 2 乘 3，拆成兩塊">
  <AreaModel
    title="3(x + 2)"
    desc="一個長方形，縱邊是 3，橫邊拆成 x 和 2 兩段，字母 x 的長度只是示意，不按比例。左格面積是 3x，右格面積是 6。"
    cols={["x", 2]}
    rows={[3]}
    areas={[["3x", null]]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」；有字母段時 `desc` 必須原文含「不按比例」四個字，否則 build 失敗 |
| `cols` | 橫邊的各段，由左往右，1 到 3 段 |
| `rows` | 縱邊的各段，由上往下，1 到 3 段 |
| `areas` | 含字母的格的面積字串，`areas[列][行]`，列數與行數要和 `rows`、`cols` 相同；兩邊都是數字的格一律寫 `null`，給字串會 build 失敗 |
| `cellText` | 兩邊都是數字的格寫什麼：`"product"`（預設）是乘積，`"expression"` 是「橫邊 × 縱邊」的算式（例如 `10 × 4`），兩者都由元件產生；含字母的格不受影響 |
| `highlightRow` | 強調的那一列（0 起算）：這一列的格加粗框（寬 3、`--accent`）並淡淡塗 `--accent`；不給就都不強調 |
| `missing` | 缺角格 `[列, 行]`（0 起算），必須在格子範圍內，否則 build 失敗：該格畫成虛線框、不塗色，格內照常寫面積（兩邊是數字的格自動算，含字母的格照 `areas`），用來表示配方法裡「還沒有、要補上」的一塊；與 `highlightRow` 並用時，被強調列中的缺角格仍以虛線、不塗色為準（不加粗、不塗 `--accent`）；不給就沒有缺角 |

- **上限**：橫段數 × 縱段數最多 4 格，所以 1 × 1、1 × 2、1 × 3、2 × 2 都可以，2 × 3 不行，超過時 build 失敗，要把圖拆成兩張。
- **每段長度**有兩種寫法：正數（整數或小數）依比例畫；字母式字串（小寫英文字母，前面可以有係數，例如 `"x"`、`"2a"`、`"ab"`）不按比例，一律用固定的示意長度畫出。零、負數與空字串都 build 失敗。數字段只在同一條邊的數字段之間依比例，太窄的段固定在下限寬度，字母段與數字段之間沒有比例關係。
- **不畫負長度**：面積模型畫的是實際的長寬，長度一律是正的。負數的分配（例如 `3(x − 2)`）不用這張圖，改用文字推導。
- **格內面積**：兩邊都是數字的格由元件自動算，作者不能覆寫，數字才不會寫錯：預設寫乘積（小數走精確有理數，0.1 × 0.2 是 0.02，不出現科學記號），`cellText="expression"` 寫成「橫邊 × 縱邊」的算式，用來呈現還沒算出來的乘法。含字母的格必須在 `areas` 給面積字串（例如 `"3x"`），沒給就 build 失敗。格內文字比格寬時 build 失敗（估計寬度，左右各留 4），要縮短文字或把圖拆開。
- **字母用斜體 SVG 文字**，不用 KaTeX（SVG 裡不能用 KaTeX）：邊長與面積字串裡的英文字母畫成斜體，數字與符號維持正體；指數等上標用 Unicode 字元（`"x²"`）。
- **字級與標籤**：邊長與格內面積字級 22，視同刻度數字，不算文字標籤（見上面「面積模型的例外」）；格框是寬 2 的 `--fg`，強調列加粗到 3 並塗淡 `--accent`，除了顏色還有線寬的差別。
- **虛線框的語意**：全站統一為「拿掉的或還沒有的」，`AreaModel` 的缺角格用它表示還沒有、要補上的一塊（`BalanceScale` 用同一種虛線框表示拿掉的物件）。缺角格的虛線框是寬 2 的 `--fg`、不塗色，與實線格只差線型，所以 `desc` 必須說明哪一格是缺的與它的面積（例如「右下角是缺的一格，用虛線框表示，面積是 9」）。
- **版面**：viewBox 寬 480，橫邊總寬 400，高度依縱邊段數決定。字母段橫向固定 120、縱向固定 70。橫邊全是字母段時總寬不到 400，整排置中；縱邊全是字母段時圖高只算到格子底，不留空白。
- `<desc>` 寫出每一段的長度與每一格的面積，強調列要說明是哪一列，字母段要寫明不按比例（desc 必須原文含「不按比例」，其他說法如「不依比例」不算）。

## `BalanceScale`

方程式的天平一律用 `BalanceScale`：左右兩個秤盤，各放 x 盒子（方形、內寫斜體 x）與 1 的砝碼（圓形、內寫 1），可以畫成平衡、某一邊較重，以及兩邊同時拿掉物件。版面計算與驗證在 `src/lib/balance-scale.ts`，元件只畫 SVG。

```mdx
<Figure caption="兩邊同時拿掉 3 個砝碼，天平仍然平衡">
  <BalanceScale
    title="拿掉砝碼"
    desc="天平原本左盤有 1 個 x 盒子和 3 個 1 的砝碼，右盤有 5 個 1 的砝碼；兩邊各拿掉 3 個砝碼，拿掉的畫成虛線框，剩下左盤 1 個 x 盒子、右盤 2 個砝碼，兩邊仍然平衡。"
    left={{ x: 1, units: 3 }}
    right={{ x: 0, units: 5 }}
    removed={{ left: { units: 3 }, right: { units: 3 } }}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `left`、`right` | 必填，每盤 `{ x, units }`：x 盒子與 1 的砝碼的個數，都是 0 以上的整數 |
| `tilt` | `"left"` 或 `"right"`，表示那一邊較重、往下傾斜；不給時畫成平衡，其他值 build 失敗 |
| `removed` | 每盤拿掉的物件 `{ left?: { x?, units? }, right?: { x?, units? } }`，沒寫的視為 0 |

- **上限**：每盤至少 1 個物件，合計（x 盒子加砝碼，含被拿掉的）最多 10 個，超過、不是 0 以上的整數或一盤沒有物件時 build 失敗。一盤每排 5 個，超過 5 個換排。
- **`tilt` 只表示哪邊較重**：傾斜角固定（10°），不依物件數量計算，所以 `tilt` 要由作者依等式兩邊的實際輕重自己指定，元件不會檢查它與個數是否相符。
- **`removed`**：拿掉的物件仍留在原位，畫成虛線框（`stroke-dasharray`）、不塗色，框內的 x 或 1 照舊；數量超過該盤原有的數量 build 失敗。每種物件拿掉的排在同類最後面。虛線框在本站的語意統一為「拿掉的或還沒有的」，`AreaModel` 的缺角格同此。
- **畫法**：x 盒子是方形、砝碼是圓形，盤上的物件淡塗 `--accent`、框線是寬 2 的 `--fg`；符號字級 22，視同刻度數字，不算文字標籤，x 用斜體 SVG 文字。橫樑、支柱、底座與秤盤底線是主線（寬 3、`--fg`），吊繩與吊桿是輔助線（寬 2、`--muted`）。viewBox 寬 480，高度依物件排數決定。
- **灰階下的區別**：靠形狀（盒子與砝碼）、虛實線（在盤上與拿掉的）與傾斜方向，不只靠顏色。
- 只畫係數與常數都是正整數的方程式；負數與分數不進天平。
- `<desc>` 必須寫出兩邊各有幾個盒子與砝碼、拿掉了什麼、天平是否平衡（失衡時寫哪一邊較重），不只寫「一個天平」。

## 雙數線

兩個一起變化的量（例如罐數與價錢、時間與水量）用雙數線：同一個 `<Figure>` 裡上下放兩條 `NumberLine`，兩條的 `from` 相同、段數相同，刻度就會上下對齊。每條各自的 `title` 與 `desc` 寫明它代表哪個量，`caption` 說明上下對應。

## `Counters`

```mdx
<Figure caption="彈珠排成一排">
  <Counters title="一排 7 顆" desc="7 顆彈珠排成一排，前 3 顆塗滿，後 4 顆是空心圓。" count={7} layout="row" marked={3} />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `count` | 必填，1–30 的整數 |
| `layout` | `row` 一排、`grid` 依 `columns` 換排、`scatter` 散開 |
| `columns` | `grid` 每排幾顆，1–10，預設 5，配合「5 與 10」的結構 |
| `marked` | 前幾顆標記成 `--accent` 的實心圓，其餘變成空心圓；不給時全部是 `--fg` 實心圓 |
| `seed` | `scatter` 的亂數種子，有預設值；同樣的參數每次 build 都畫在同樣的位置 |

`row` 最多放 11 顆，再多就 build 失敗，請改用 `grid`。散開的圓點彼此不重疊，放不下時 build 失敗，換 `seed` 或減少顆數。

## 用在可列印材料

可列印材料頁（`/print/<材料 id>/`）也用 `Counters` 與 `NumberLine` 畫圓點和數線。列印時頁面強制淺色，背景是白、`--fg` 是黑，其餘 token 用淺色值；家用黑白印表機會把 `--accent` 印成灰色，所以「顏色不能是唯一的訊息來源」在這裡特別重要。印出的尺寸由材料頁的卡片以 mm 決定，教具本身仍只寫 `viewBox`。

## 驗收

發布前，每張教具都要在下列四種組合各看一次，加上列印預覽：

| | 淺色 | 深色 |
| --- | --- | --- |
| 桌面寬 | 顏色、粗細、對齊 | 顏色隨主題切換，沒有看不見的線 |
| 320px 寬 | 數字與標籤讀得清楚，沒有水平捲軸 | 同左 |

自動檢查只涵蓋機器能判斷的部分：fixture 教具的結構、線寬與字級、主題切換時的顏色，以及 320px 沒有水平捲軸（`tests/figures.spec.ts`）。圖是否真的讀得清楚，只能靠人看。
