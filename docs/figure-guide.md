# 教具繪製規範

本文件是繪製 CarlMath 教具的依據，讀者是之後新增教具的站主與 agent。內容涵蓋 SVG 的結構、版面尺寸、色票語意、替代文字、共用元件 `NumberLine` 與 `Counters` 的參數，以及發布前的驗收。教具在教材裡怎麼用（配文字說明、表徵數量、import 寫法）屬於[內容撰寫規範](content-guide.md)，本文件不重述。

單一版面與封閉色盤是 [ADR 0002：教具採單一版面與封閉色盤](adr/0002-figures-single-layout-closed-palette.md) 的決定：教具是數線、點陣、積木這類幾何規則的圖，等比縮放就能讀，所以只畫一份 SVG；顏色只用閱讀頁的色票 token，讓同一個顏色在全路線意思一致，深色模式也不必逐圖處理。代價是每張圖的文字量與寬度受限，複雜的圖必須拆開。

## 先用共用元件

數線一律用 `NumberLine`，小物圓點一律用 `Counters`，讓這兩種圖在全路線長得一樣。兩者都放在 `src/components/figures/`，教材以 `@figures/NumberLine.astro`、`@figures/Counters.astro` 匯入。共用元件畫不出來的圖，才做成一次性的 `<主題>Figure.astro`，和該單元的教材放在一起，並遵守下面每一條規則。

教具元件只輸出 `<svg>`。圖名下方的說明文字由 `<Figure caption="…">` 負責，不寫在 SVG 裡。

## SVG 結構

- 用原生 SVG，不用 Mermaid 或任何圖表 runtime。
- 根元素寫 `role="img"`，`aria-labelledby` 依序指向圖內的 `<title>` 與 `<desc>`。
- 圖內每個 `id`（包括 `<title>`、`<desc>`、`<marker>`、漸層）都加元件前綴，例如 `nl-…`、`ct-…`，同一頁有多張圖也不會撞名。共用元件的前綴由參數雜湊而來，輸出是決定性的。
- 只寫 `viewBox`，不寫 `width`、`height`。
- 樣式用元件的 scoped `<style>`，線寬、字級、顏色寫在 class 上，不寫在每個元素的屬性裡。
- SVG 裡不能用 KaTeX；需要公式時寫在 `<Figure>` 的說明或正文。

## 版面：單一版面、等比縮放

| 項目 | 規定 |
| --- | --- |
| `viewBox` 寬 | 480，高度依內容決定 |
| 顯示寬上限 | 32rem，窄螢幕等比縮小到容器寬 |
| 字級（viewBox 單位） | 數字 22，文字標籤 20，下限 20 |
| 線寬 | 主線 3，刻度與輔助線 2，跳躍弧 2.5，端點一律圓頭 |
| 文字標籤 | 每張圖最多三個（刻度上的數字不算；面積模型的例外見下） |

**面積模型的例外**：把乘法拆成長方形面積的圖（例如 23 × 14 拆成 20、3 與 10、4），邊上的長度數字視同刻度數字，格內每格一個面積數字也不另計，但最多 2 × 2 共 4 格。理由是面積模型的價值就在圖上的邊長、格內面積與式子逐一對應，刪掉任何一組數字都會失去這個對應，而一張 2 × 2 的圖又拆不成兩張。超過 4 格時仍要拆圖。

320px 寬時，480 寬的圖會縮成約 0.6 倍，字級 20 約等於 12px，這是可讀的下限。字再小、標籤再多、或者刻度數字擠在一起時，不要縮字級，把圖拆成兩張。

## 色票：封閉色盤

教具只能用閱讀頁的色票 token，每個 token 有全站固定的語意：

| token | 用途 |
| --- | --- |
| `--fg` | 主線、數字、文字標籤、一般的圓點 |
| `--muted`、`--line` | 刻度、括號等輔助元素 |
| `--accent` | 讀者該注意的東西，例如數線上的點、跳躍弧、被標記的圓點 |
| `--ok`、`--warn` | 只用於迷思對照，例如並列的錯誤與正確作法 |
| `--family` | 不進圖內 |

顏色屬性（`fill`、`stroke`、`stop-color` 等）與 CSS 的顏色宣告，只允許 `currentColor`、`none`、`transparent`、`inherit`、`var(--token)`，以及參照圖內漸層的 `url(#id)`。`var()` 不得帶 fallback 色碼，例如 `var(--accent, #2563eb)` 不合格；hex、色名、`rgb()`、`hsl()` 都不允許，frontmatter 裡的 hex 字串也算。內容驗證掃描內容根目錄 `lessons/` 下的 `*Figure.astro`；共用教具由 `tests/figure-components.test.mjs` 套用同一套規則。

**顏色不能是唯一的訊息來源**：要區分的東西，除了顏色還要有形狀、虛實線或文字標籤的差別。例如數線上的點是實心圓、跳躍弧帶箭頭；`Counters` 被標記的圓點是實心，其餘是空心。色弱讀者把圖看成灰階時，仍要分得出來。

## 替代文字

- **`<title>`**：10 個字以內的圖名，例如「從 3 跳到 7」。
- **`<desc>`**：用完整句子寫出圖中的數值和對應關係，讓不看圖的讀者也能理解，例如「0 到 10 的數線，每一格是 1。3 有一個點，從 3 往右畫一道弧線跳到 7，弧線上標著加 4。」不要只寫「一條數線」。
- **`figcaption`**（`<Figure caption>`）：只寫「請注意看什麼」，不和 `desc` 重複。

共用元件的 `title` 與 `desc` 是必填參數，`title` 超過 10 個字或任一欄空白時 build 失敗。`desc` 是否真的寫出數值與對應關係，只能靠人看。

## `NumberLine`

```mdx
<Figure caption="從 3 往右跳 4 格，停在哪裡">
  <NumberLine
    title="從 3 跳到 7"
    desc="0 到 10 的數線，每一格是 1。3 有一個點，從 3 往右畫一道弧線跳到 7，弧線上標著加 4；3 到 7 下方有括號，標著 4 格。"
    from={0}
    to={10}
    points={[{ at: 3 }]}
    jumps={[{ from: 3, to: 7, label: "+4" }]}
    spans={[{ from: 3, to: 7, label: "4 格" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `from`、`to` | 必填，數線的起點與終點，`from` 小於 `to` |
| `step` | 刻度間隔，預設 1；`to − from` 必須是 `step` 的整數倍 |
| `labelEvery` | 只標這個數的倍數，必須是 `step` 的倍數；不給時依下面的規則 |
| `points` | 數線上的點：`{ at, label? }` |
| `jumps` | 跳躍弧：`{ from, to, label? }`，畫在數線上方，終點有箭頭 |
| `spans` | 距離括號：`{ from, to, label? }`，畫在數字下方 |

- 只支援整數，所有位置都必須落在刻度上；分數與小數之後另行擴充。
- 刻度間隔一律等距，0 的刻度加粗加長。
- 兩張參數完全相同的數線放在同一頁，`id` 前綴會相同；同一頁不要重複放一模一樣的圖。
- 10 段以內每格都標數字。超過 10 段時只標 5 的倍數（含 0）、兩端點與 `points` 的位置；`labelEvery` 用來改掉「5 的倍數」這一項，10 段以內給了 `labelEvery` 也照它標。
- `points`、`jumps`、`spans` 的 `label` 合計最多三個。
- 刻度數字最多 4 位數。量更大時改變一格代表的單位，例如一格代表 1 萬或 1000，`from`、`to` 照單位寫成小數字，並在 `desc`、說明或 `spans` 標籤寫明一格代表多少。5 位以上的端點數字可能被裁切，這條規則先擋下，不必逐張確認。

## `Counters`

```mdx
<Figure caption="彈珠排成一排">
  <Counters title="一排 7 顆" desc="7 顆彈珠排成一排，前 3 顆塗滿，後 4 顆是空心圓。" count={7} layout="row" marked={3} />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `count` | 必填，1–30 的整數 |
| `layout` | `row` 一排、`grid` 依 `columns` 換排、`scatter` 散開 |
| `columns` | `grid` 每排幾顆，1–10，預設 5，配合「5 與 10」的結構 |
| `marked` | 前幾顆標記成 `--accent` 的實心圓，其餘變成空心圓；不給時全部是 `--fg` 實心圓 |
| `seed` | `scatter` 的亂數種子，有預設值；同樣的參數每次 build 都畫在同樣的位置 |

`row` 最多放 11 顆，再多就 build 失敗，請改用 `grid`。散開的圓點彼此不重疊，放不下時 build 失敗，換 `seed` 或減少顆數。

## 用在可列印材料

可列印材料頁（`/print/<材料 id>/`）也用 `Counters` 與 `NumberLine` 畫圓點和數線。列印時頁面強制淺色，背景是白、`--fg` 是黑，其餘 token 用淺色值；家用黑白印表機會把 `--accent` 印成灰色，所以「顏色不能是唯一的訊息來源」在這裡特別重要。印出的尺寸由材料頁的卡片以 mm 決定，教具本身仍只寫 `viewBox`。

## 驗收

發布前，每張教具都要在下列四種組合各看一次，加上列印預覽：

| | 淺色 | 深色 |
| --- | --- | --- |
| 桌面寬 | 顏色、粗細、對齊 | 顏色隨主題切換，沒有看不見的線 |
| 320px 寬 | 數字與標籤讀得清楚，沒有水平捲軸 | 同左 |

自動檢查只涵蓋機器能判斷的部分：fixture 教具的結構、線寬與字級、主題切換時的顏色，以及 320px 沒有水平捲軸（`tests/figures.spec.ts`）。圖是否真的讀得清楚，只能靠人看。
