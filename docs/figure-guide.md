# 教具繪製規範

本文件是繪製 CarlMath 教具的依據，讀者是之後新增教具的站主與 agent。內容涵蓋 SVG 的結構、版面尺寸、色票語意、替代文字、共用元件 `NumberLine`、`Counters`、`FractionBar`、`Shape`、`UnitGrid` 與 `AreaModel` 的參數，以及發布前的驗收。教具在教材裡怎麼用（配文字說明、表徵數量、import 寫法）屬於[內容撰寫規範](content-guide.md)，本文件不重述。

單一版面與封閉色盤是 [ADR 0002：教具採單一版面與封閉色盤](adr/0002-figures-single-layout-closed-palette.md) 的決定：教具是數線、點陣、積木這類幾何規則的圖，等比縮放就能讀，所以只畫一份 SVG；顏色只用閱讀頁的色票 token，讓同一個顏色在全路線意思一致，深色模式也不必逐圖處理。代價是每張圖的文字量與寬度受限，複雜的圖必須拆開。

## 先用共用元件

數線一律用 `NumberLine`，小物圓點一律用 `Counters`，等分的長條（分數條）一律用 `FractionBar`，多邊形、角與圓一律用 `Shape`，單位方格一律用 `UnitGrid`，長方形面積模型（把乘法或分配律拆成幾塊）一律用 `AreaModel`，讓這六種圖在全路線長得一樣。它們都放在 `src/components/figures/`，教材以 `@figures/NumberLine.astro`、`@figures/Counters.astro`、`@figures/FractionBar.astro`、`@figures/Shape.astro`、`@figures/UnitGrid.astro`、`@figures/AreaModel.astro` 匯入。數線與分數條的疊排分數共用同一個內部元件 `StackedFraction`，不由教材直接匯入；一次性教具需要圖內分數時要匯入它，讓全路線的分數長得一樣。共用元件畫不出來的圖，才做成一次性的 `<主題>Figure.astro`，和該單元的教材放在一起，並遵守下面每一條規則。

教具元件只輸出 `<svg>`。圖名下方的說明文字由 `<Figure caption="…">` 負責，不寫在 SVG 裡。

## SVG 結構

- 用原生 SVG，不用 Mermaid 或任何圖表 runtime。
- 根元素寫 `role="img"`，`aria-labelledby` 依序指向圖內的 `<title>` 與 `<desc>`。
- 圖內每個 `id`（包括 `<title>`、`<desc>`、`<marker>`、漸層）都加元件前綴，例如 `nl-…`、`ct-…`，同一頁有多張圖也不會撞名。共用元件的前綴由參數雜湊而來，輸出是決定性的。
- 只寫 `viewBox`，不寫 `width`、`height`。
- 樣式用元件的 scoped `<style>`，線寬、字級、顏色寫在 class 上，不寫在每個元素的屬性裡。
- SVG 裡不能用 KaTeX；需要公式時寫在 `<Figure>` 的說明或正文。

## 版面：單一版面、等比縮放

| 項目 | 規定 |
| --- | --- |
| `viewBox` 寬 | 480，高度依內容決定 |
| 顯示寬上限 | 32rem，窄螢幕等比縮小到容器寬 |
| 字級（viewBox 單位） | 數字 22，文字標籤 20，下限 20 |
| 線寬 | 主線 3，刻度與輔助線 2，跳躍弧 2.5，端點一律圓頭 |
| 文字標籤 | 每張圖最多三個（刻度上的數字不算；面積模型的例外見下；幾何圖的算法見 [`Shape`](#shape) 一節） |

**面積模型的例外**：把乘法拆成長方形面積的圖（例如 23 × 14 拆成 20、3 與 10、4），邊上的長度數字視同刻度數字，格內每格一個面積數字也不另計，但最多 4 格（橫段數 × 縱段數，例如 2 × 2、1 × 3）。理由是面積模型的價值就在圖上的邊長、格內面積與式子逐一對應，刪掉任何一組數字都會失去這個對應，而一張 2 × 2 的圖又拆不成兩張。超過 4 格時仍要拆圖。分數乘法的面積格（例如 3/4 × 2/3 把正方形切成 4 × 3 格）也算面積模型：邊上的分數視同刻度數字，格內不寫數字，所以不受 4 格的限制。畫整數、小數與字母式的面積模型一律用 [`AreaModel`](#areamodel)，不再另做一次性教具；它的參數與上限見該節。

320px 寬時，480 寬的圖會縮成約 0.6 倍，字級 20 約等於 12px，這是可讀的下限。字再小、標籤再多、或者刻度數字擠在一起時，不要縮字級，把圖拆成兩張。

## 色票：封閉色盤

教具只能用閱讀頁的色票 token，每個 token 有全站固定的語意：

| token | 用途 |
| --- | --- |
| `--fg` | 主線、數字、文字標籤、一般的圓點 |
| `--muted`、`--line` | 刻度、括號等輔助元素 |
| `--accent` | 讀者該注意的東西，例如數線上的點、跳躍弧、被標記的圓點 |
| `--ok`、`--warn` | 只用於迷思對照，例如並列的錯誤與正確作法 |
| `--family` | 不進圖內 |

顏色屬性（`fill`、`stroke`、`stop-color` 等）與 CSS 的顏色宣告，只允許 `currentColor`、`none`、`transparent`、`inherit`、`var(--token)`，以及參照圖內漸層或圖樣（pattern）的 `url(#id)`。這類 id 每張圖不同，`fill={`url(#…)`}` 可以寫在元素屬性上，是「顏色寫在 class 上」的唯一例外。`var()` 不得帶 fallback 色碼，例如 `var(--accent, #2563eb)` 不合格；hex、色名、`rgb()`、`hsl()` 都不允許，frontmatter 裡的 hex 字串也算。內容驗證掃描內容根目錄 `lessons/` 下的 `*Figure.astro`；共用教具由 `tests/figure-components.test.mjs` 套用同一套規則。

**顏色不能是唯一的訊息來源**：要區分的東西，除了顏色還要有形狀、虛實線或文字標籤的差別。例如數線上的點是實心圓、跳躍弧帶箭頭；`FractionBar` 塗色的份是實心、沒塗的份只有框線；`Counters` 被標記的圓點是實心，其餘是空心。色弱讀者把圖看成灰階時，仍要分得出來。

## 替代文字

- **`<title>`**：10 個字以內的圖名，例如「從 3 跳到 7」；空格也算一個字。
- **`<desc>`**：用完整句子寫出圖中的數值和對應關係，讓不看圖的讀者也能理解，例如「0 到 10 的數線，每一格是 1。3 有一個點，從 3 往右畫一道弧線跳到 7，弧線上標著加 4。」不要只寫「一條數線」。
- **`figcaption`**（`<Figure caption>`）：只寫「請注意看什麼」，不和 `desc` 重複。
- **數字的寫法**：`desc`、`caption`、`note` 裡的整數量、個數、長度與度數一律寫阿拉伯數字（「4 塊」「60°」），分數與小數照各元件一節用中文讀法（分數條的份數與塗色數屬於分數讀法，照 `FractionBar` 一節寫「平分成四份」）；國字只用於序數（「第一道弧」）、分數讀法（「四分之一圈」）與不表示數量的「一」（「一個圓」「一條邊」）。同一段文字不混用「八個」與「4 片」。`desc` 裡的負數是例外，一律寫中文讀法（「負五」「負二分之一」），正數與 0 照舊寫阿拉伯數字，所以寫「從負五到 5」，不寫「負 5」或「負五到五」；`caption` 與 `note` 的負數照[內容撰寫規範](content-guide.md)的「純文字欄位的負號」寫「−5」。

共用元件的 `title` 與 `desc` 是必填參數，`title` 超過 10 個字或任一欄空白時 build 失敗。`desc` 是否真的寫出數值與對應關係，只能靠人看。

## `NumberLine`

```mdx
<Figure caption="從 3 往右跳 4 格，停在哪裡">
  <NumberLine
    title="從 3 跳到 7"
    desc="0 到 10 的數線，每一格是 1。3 有一個點，從 3 往右畫一道弧線跳到 7，弧線上標著加 4；3 到 7 下方有括號，標著 4 格。"
    from={0}
    to={10}
    points={[{ at: 3 }]}
    jumps={[{ from: 3, to: 7, label: "+4" }]}
    spans={[{ from: 3, to: 7, label: "4 格" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `from`、`to` | 必填，數線的起點與終點，`from` 小於 `to`；位置值的寫法見下 |
| `step` | 刻度間隔，預設 1；`to − from` 必須是 `step` 的整數倍；**它的寫法決定刻度標籤的寫法**，見下；寫成分數時必須是最簡分數（`"1/2"`，不寫 `"2/4"`），否則 build 失敗；`labelEvery` 同理 |
| `labelEvery` | 只標這個數的倍數，必須是 `step` 的正整數倍，可以寫分數或小數；不給時依下面的規則 |
| `mixed` | 預設關閉；開啟時大於 1 的分數刻度寫成帶分數。只能搭配 `"a/b"` 寫法的 `step`，`step` 是數字時開啟會 build 失敗 |
| `points` | 數線上的點：`{ at, label? }` |
| `jumps` | 跳躍弧：`{ from, to, label? }`，畫在數線上方，終點有箭頭 |
| `spans` | 距離括號：`{ from, to, label? }`，畫在數字下方 |

- **位置值**（`from`、`to`、`step`、`labelEvery`、`points[].at`、`jumps[].from/to`、`spans[].from/to`）寫成數字或 `"a/b"` 字串。數字依它的十進位字面轉成精確分數（`0.1` 就是 1/10，不經浮點運算，所以 `step={0.1}` 時 `0.3` 在刻度上）；字串必須是整數分子、正整數分母，`"1/0"` 或 `"1.5/2"` 這類寫法 build 失敗。內部以約分後的有理數比較，`"2/4"` 與 `"1/2"` 是同一個位置。所有位置都必須落在刻度上。
- **標籤寫法由 `step` 的寫法決定**，不另設格式參數：`step="1/4"` 這類字串，非整數刻度標成疊排分數，分母沿用刻度的分母、不約分（每格 1/4 時，1/2 的位置標 2/4）；`step={0.1}` 這類數字，非整數刻度標成十進位小數；整數刻度不論哪一種都只寫整數。
- 疊排分數是上下排的分子、分數線、分母，數字字級 22，分數線與刻度同寬、顏色用 `--fg`；帶分數的整數部分接在疊排真分數左邊。有疊排分數時，數線下方依實際高度加高，`spans` 的括號與標籤往下移，不與分數重疊。疊排分數不算進下面的文字標籤上限。
- **負數**：`from` 可以是負數，位置值直接寫 `-3`、`-1.5`、`"-1/2"`。刻度、點與標籤裡的負號一律是數學減號「−」（U+2212），不是連字號「-」；整數與小數刻度由元件自動輸出，`points`、`jumps`、`spans` 的 `label` 是作者自己寫的字串，要寫負數時必須直接打「−」，標籤裡的連字號「-」（後面可隔空格）後面接數字、分數字元（如 ½）、小寫字母或左括號（例如 `-3`、`5 - 2`、`-x`、`-½`）會 build 失敗，不自動轉換；點的名稱 `A-B` 這種大寫字母之間的連字號不受影響。
- **負分數**：負號畫在整個疊排分數的左邊（`.sf-sign`），垂直置中對齊分數線，分子分母仍是正數，分母沿用刻度的分母、不約分（每格 1/4 時，−1/2 的位置標 −2/4）。開啟 `mixed` 時，絕對值大於 1 的負分數寫成帶分數，負號在整數部分左邊（−3/2 標成 −1½）。負號與整數部分、分數一起置中於刻度，帶負號的分數比正的寬，320px 上每多一個負號標籤就更擠，段數比照帶分數的限制，用 `labelEvery` 少標幾個。疊排分數的負號版面在 `src/lib/stacked-fraction.ts`，數線與分數條共用。
- 刻度間隔一律等距，0 的刻度加粗加長。
- 兩張參數完全相同的數線放在同一頁，`id` 前綴會相同；同一頁不要重複放一模一樣的圖。
- 10 段以內每格都標數字。超過 10 段時，整數數線只標 5 的倍數（含 0）、兩端點與 `points` 的位置；分數與小數數線只標整數、兩端點與 `points`。`labelEvery` 用來改掉「5 的倍數」或「整數」這一項（照它標，仍加上兩端點與 `points`），10 段以內給了 `labelEvery` 也照它標。帶分數或兩位以上的小數標籤比整數寬，10 段以內也可能在 320px 擠在一起（實測 9 段的帶分數、10 段的一位小數都讀不清）；這時用 `labelEvery` 只標整數或少數幾個刻度，要讀者注意的位置改用 `points` 標出。
- `points`、`jumps`、`spans` 的 `label` 合計最多三個。
- `<desc>` 裡的分數與小數用中文讀法：「四分之三」「一又二分之一」「零點三」，不寫 `3/4`；負數在前面加「負」：「負三」「負二分之一」「負一又二分之一」「負一點五」，不寫 `-3` 或「−3」。
- 刻度數字最多 4 位數。量更大時改變一格代表的單位，例如一格代表 1 萬或 1000，`from`、`to` 照單位寫成小數字，並在 `desc`、說明或 `spans` 標籤寫明一格代表多少。5 位以上的端點數字可能被裁切，這條規則先擋下，不必逐張確認。

## `FractionBar`

```mdx
<Figure caption="平分成 4 份，塗 3 份">
  <FractionBar
    title="四分之三"
    desc="一條長條平分成四份，從左邊塗滿三份，右側標著四分之三。"
    bars={[{ parts: 4, shaded: 3, label: "3/4" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `bars` | 1 到 4 條，每條 `{ parts, shaded, label? }`，由上往下排 |
| `parts` | 等分成幾份，1 到 24 的整數 |
| `shaded` | 從左邊連續塗滿幾份，0 到 `parts` 的整數 |
| `label` | 畫在條右側：`"a/b"` 字串畫成疊排分數，整數畫成純文字 |

- 每條代表同一個整體，長度相同；塗色的份以 `--accent` 實心填滿，沒塗的份只有框線，外框是主線（寬 3、`--fg`），等分線是輔助線（寬 2、`--muted`，與數線刻度相同）。
- `label` 的分數照寫的樣子畫、不約分（`"2/4"` 就畫 2/4），畫法與數線刻度的疊排分數相同，數字字級 22。
- **對齊條件**：版面寬 480、左右各留 28，與 `NumberLine` 相同。沒有任何一條帶 `label` 時，條的左右端對齊數線上 `from`、`to` 的 x 座標，所以分數條放在 0 到 1 的數線正上方（`step` 與 `parts` 相配，例如 `step="1/4"` 配 `parts={4}`）時，等分線與刻度對齊。只要有一條帶 `label`，所有條都會縮短，為右側標籤騰出空間，此時不保證對齊。
- 不支援：假分數（`shaded` 大於 `parts`）、從中間或任意位置塗色、二維切割（長方形或圓的切法）。這些要另做一次性教具。
- `<desc>` 用中文讀法寫出份數與塗色數，例如「平分成四份，塗滿三份」，不寫 `3/4`。

## `Shape`

三角形、平行四邊形、圓這類平面圖形一律用 `Shape`，作者以抽象座標宣告形狀，元件負責縮放與標記。為什麼不含座標軸與格線，見 [ADR 0003：平面圖形共用教具以抽象座標宣告、自動縮放，不含座標軸](adr/0003-shape-abstract-coordinates-no-axes.md)。版面計算與驗證在 `src/lib/shape-geometry.ts`。

```mdx
<Figure caption="45° 的角在哪個頂點，虛線是哪一條高">
  <Shape
    title="直角等腰三角形"
    desc="頂點 A、B、C 的直角等腰三角形：A 是直角，B 是 45°，C 的角未知；A 到 C 與 A 到 B 這 2 條邊長度相等，各有 1 條短斜線，A 到 B 的邊長是 4；從 A 向斜邊畫一條虛線的高，標著高。"
    polygons={[
      {
        vertices: [[0, 0], [4, 0], [0, 4]],
        names: ["A", "B", "C"],
        sides: [{ side: 0, label: 4, equal: 1 }, { side: 2, equal: 1 }],
        angles: [{ at: 0, right: true }, { at: 1, degrees: 45 }, { at: 2, degrees: "?" }],
      },
    ]}
    guides={[{ from: [0, 0], to: [2, 2], label: "高" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `polygons` | 多邊形清單，每個 `{ vertices, names?, filled?, sides?, angles? }`，見下 |
| `circles` | 圓清單，每個 `{ center, radius, show?, label? }`，見下 |
| `guides` | 虛線輔助線段，每條 `{ from, to, label?, right? }`，例如三角形的高，見下 |

`polygons` 與 `circles` 至少要有一個；一張圖可以有多個圖形。

- **座標**：`[x, y]`，y 軸朝上，單位任意（寫 `[0, 0]`、`[4, 0]`、`[0, 3]` 或放大十倍畫出來一樣）。元件依所有圖形的外接範圍等比縮放到 viewBox 寬 480，水平置中，高度依內容決定，y 軸自動翻轉。標籤太長時會自動縮小圖形，讓標籤不超出畫面；長到縮小也放不下時 build 失敗，訊息指出是哪個標籤，要縮短標籤或把圖拆成兩張。
- **`vertices`**：至少 3 個頂點，依序連成封閉的多邊形，順時針或逆時針都可以，頂點不能全在同一條直線上。頂點編號從 0 起算，第 `i` 條邊是頂點 `i` 到頂點 `i + 1`（最後一條接回 0）。
- **`names`**：頂點字母，如 `["A", "B", "C"]`，數量須與 `vertices` 相同，每個只能是單一大寫拉丁字母（A–Z），否則 build 失敗（想放文字用 `label`，會算進文字標籤上限）；畫在頂點外側。
- **`filled`**：整塊塗 `--accent`（半透明，讓區內的度數與輔助線看得見），外框仍是主線；沒塗的只有外框，灰階下分得出來。
- **`sides`**：每項 `{ side, label?, equal?, parallel? }`。`label` 畫在邊的外側，不驗證比例，所以示意圖可以寫「100 公尺」而不按比例畫；`equal`（1–3）在邊中點畫 1–3 條短斜線，同一組相等的邊寫同樣的數字；`parallel`（1–2）在邊上畫 1–2 個箭頭，同一組平行的邊寫同樣的數字，箭頭方向一致。
- **`angles`**：每項 `{ at, degrees? 或 right? }`。`degrees` 寫數字會畫角弧與「N°」，寫 `"?"` 畫角弧與「?」（練習題用，不洩漏答案）；`right: true` 畫直角記號（小方框）取代角弧，不寫度數。`degrees` 與 `right` 擇一。
- **`circles`**：`show` 是 `"radius"`（圓心向右的半徑）或 `"diameter"`（通過圓心的水平直徑），線段帶圓心點；`label` 畫在線段上方，須搭配 `show`。不寫 `show` 就只畫圓。
- **`guides`**：`--muted` 虛線，與實線外框以線型區分。`label` 畫在線的一側。`right: true` 在 `to`（垂足）畫直角記號，小方框夾在輔助線與它落在的那條邊之間、朝向輔助線那一側；`to` 必須落在某個多邊形的邊上，且輔助線與該邊夾角 90°（±1°），否則 build 失敗，訊息指出是不在邊上還是不垂直、實際夾角多少。多條邊都符合時取第一個多邊形的第一條。

**標籤上限**（每張圖合計，超過任一項 build 失敗，要把圖拆成兩張）：

| 類別 | 算什麼 | 上限 |
| --- | --- | --- |
| 邊長與度數 | `sides`、`circles`、`guides` 的 `label` 中含數字的（`4`、`"100 公尺"`），加上 `angles` 的 `degrees`（數字與 `"?"` 都算） | 合計 6 |
| 頂點字母 | `names` 的字母，所有多邊形合計 | 4 |
| 文字標籤 | `label` 中不含數字的（「底」「高」「半徑」） | 3 |

邊長與度數視同刻度數字（字級 22），文字標籤字級 20，頂點字母字級 22；直角記號、等邊記號與平行記號不算標籤。線寬：外框與圓是主線 3，角弧與直角記號 2.5（`--accent`），等邊與平行記號、虛線輔助線 2。

**度數驗證**：`degrees` 是數字時，build 依頂點座標算出實際內角（凹角大於 180° 也算），和標的度數相差超過 1° 就失敗，訊息指出哪個頂點、標的度數與實際度數，例如「`polygons[0].angles[0]`（頂點 1）標了 40°，但依座標算出來約是 36.9°」；`right: true` 也驗證是 90°。`"?"` 與邊長標籤不驗證。修法是改座標或改標籤，不要改成 `"?"` 來繞過。

- 不支援：座標軸與格線（ADR 0003；要畫座標平面的圖，等座標平面階段重新決定）、比例尺、**刻意不按比例的角**。`Shape` 不開度數驗證的例外，刻意不按比例的角（例如誇大的示意角）要做成一次性教具。
- 也不支援：弧或曲邊的多邊形、圓的填色、圓上的弦與切線。需要時另做一次性教具。
- `<desc>` 寫出頂點、邊長、角度與記號對應的邊與角，例如「A 到 C 與 A 到 B 兩條邊長度相等」，不只寫「一個三角形」。

## `UnitGrid`

```mdx
<Figure caption="塗色的格子是蓋住的面積，粗線圍出的是周長">
  <UnitGrid
    title="L 形的周長"
    desc="4 列 4 行的方格，塗了 L 形的 5 格，粗線沿著塗色區的邊界描出一圈，周長 12 格。"
    rows={4}
    cols={4}
    cells={[[0, 0], [1, 0], [2, 0], [2, 1], [2, 2]]}
    perimeter
    labels={[{ side: "right", text: "周長" }]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `rows`、`cols` | 列數 1 到 12、行數 1 到 10 的整數，超過 build 失敗 |
| `rects` | 塗色的長方形，每個 `{ row, col, rows, cols }`：左上角的列、行（0 起算，列由上往下）與往下、往右各幾格 |
| `cells` | 逐格塗色，每格 `[row, col]`（0 起算） |
| `perimeter` | `true` 時沿塗色區的實際邊界描外框，表示周長；沒有塗色時 build 失敗 |
| `labels` | 邊上的標籤，每個 `{ side, text }`；`side` 是 `"top"`、`"bottom"`、`"left"`、`"right"`，每邊最多一個 |

- `rects` 與 `cells` 可以並用，重疊的格只算一次；任何一格超出 `rows` × `cols` 的範圍 build 失敗。長方形寫法與逐格寫法塗出的結果完全相同。
- 塗色的格是 `--accent` 實心，沒塗的格只有格線，灰階下仍分得出來。格線是輔助線（寬 2、`--muted`），周長外框是主線（寬 3、`--fg`）。外框沿塗色區的實際邊界走，不規則形狀、凹口與中間挖空的洞都一樣；分開的幾塊各自描邊。
- `text` 是整數時為邊上的格數，視同刻度數字（字級 22），範圍 1 到 99，不算文字標籤；是字串時為文字標籤（字級 20），1 到 3 個字，圖內最多 3 個。標籤置中在塗色區外接範圍的那一邊，沒有塗色時置中在整個方格的那一邊。
- 一格固定 32（viewBox 寬 480），方格置中；12 × 10 是手機上還數得清楚的上限。
- 不支援：半格、斜線、三角形。用方格數三角形面積的圖要做成一次性教具。既有的百格圖不併入 `UnitGrid`。
- **一張圖只放一個主角**：「面積相同、周長不同」的對照，在同一個 `<Figure>` 裡畫兩張 `UnitGrid` 並排，各自有 `title` 與 `desc`，不要在一張圖裡塗兩個形狀。
- `<desc>` 寫出列數、行數、塗了哪些格、塗了幾格，有外框時寫出周長格數，不只寫「一張方格」。

## `AreaModel`

把乘法或分配律拆成長方形面積的圖一律用 `AreaModel`：長方形的橫邊與縱邊各拆成 1 到 3 段，每段寫一個長度，每一格寫面積。版面計算與驗證在 `src/lib/area-model.ts`，元件只畫 SVG。

```mdx
<Figure caption="x 加 2 乘 3，拆成兩塊">
  <AreaModel
    title="3(x + 2)"
    desc="一個長方形，縱邊是 3，橫邊拆成 x 和 2 兩段，字母 x 的長度只是示意，不按比例。左格面積是 3x，右格面積是 6。"
    cols={["x", 2]}
    rows={[3]}
    areas={[["3x", null]]}
  />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」；有字母段時 `desc` 必須原文含「不按比例」四個字，否則 build 失敗 |
| `cols` | 橫邊的各段，由左往右，1 到 3 段 |
| `rows` | 縱邊的各段，由上往下，1 到 3 段 |
| `areas` | 含字母的格的面積字串，`areas[列][行]`，列數與行數要和 `rows`、`cols` 相同；兩邊都是數字的格一律寫 `null`，給字串會 build 失敗 |
| `cellText` | 兩邊都是數字的格寫什麼：`"product"`（預設）是乘積，`"expression"` 是「橫邊 × 縱邊」的算式（例如 `10 × 4`），兩者都由元件產生；含字母的格不受影響 |
| `highlightRow` | 強調的那一列（0 起算）：這一列的格加粗框（寬 3、`--accent`）並淡淡塗 `--accent`；不給就都不強調 |

- **上限**：橫段數 × 縱段數最多 4 格，所以 1 × 1、1 × 2、1 × 3、2 × 2 都可以，2 × 3 不行，超過時 build 失敗，要把圖拆成兩張。
- **每段長度**有兩種寫法：正數（整數或小數）依比例畫；字母式字串（小寫英文字母，前面可以有係數，例如 `"x"`、`"2a"`、`"ab"`）不按比例，一律用固定的示意長度畫出。零、負數與空字串都 build 失敗。數字段只在同一條邊的數字段之間依比例，太窄的段固定在下限寬度，字母段與數字段之間沒有比例關係。
- **不畫負長度**：面積模型畫的是實際的長寬，長度一律是正的。負數的分配（例如 `3(x − 2)`）不用這張圖，改用文字推導。
- **格內面積**：兩邊都是數字的格由元件自動算，作者不能覆寫，數字才不會寫錯：預設寫乘積（小數走精確有理數，0.1 × 0.2 是 0.02，不出現科學記號），`cellText="expression"` 寫成「橫邊 × 縱邊」的算式，用來呈現還沒算出來的乘法。含字母的格必須在 `areas` 給面積字串（例如 `"3x"`），沒給就 build 失敗。格內文字比格寬時 build 失敗（估計寬度，左右各留 4），要縮短文字或把圖拆開。
- **字母用斜體 SVG 文字**，不用 KaTeX（SVG 裡不能用 KaTeX）：邊長與面積字串裡的英文字母畫成斜體，數字與符號維持正體；指數等上標用 Unicode 字元（`"x²"`）。
- **字級與標籤**：邊長與格內面積字級 22，視同刻度數字，不算文字標籤（見上面「面積模型的例外」）；格框是寬 2 的 `--fg`，強調列加粗到 3 並塗淡 `--accent`，除了顏色還有線寬的差別。
- **版面**：viewBox 寬 480，橫邊總寬 400，高度依縱邊段數決定。字母段橫向固定 120、縱向固定 70。橫邊全是字母段時總寬不到 400，整排置中；縱邊全是字母段時圖高只算到格子底，不留空白。
- `<desc>` 寫出每一段的長度與每一格的面積，強調列要說明是哪一列，字母段要寫明不按比例（desc 必須原文含「不按比例」，其他說法如「不依比例」不算）。

## 雙數線

兩個一起變化的量（例如罐數與價錢、時間與水量）用雙數線：同一個 `<Figure>` 裡上下放兩條 `NumberLine`，兩條的 `from` 相同、段數相同，刻度就會上下對齊。每條各自的 `title` 與 `desc` 寫明它代表哪個量，`caption` 說明上下對應。

## `Counters`

```mdx
<Figure caption="彈珠排成一排">
  <Counters title="一排 7 顆" desc="7 顆彈珠排成一排，前 3 顆塗滿，後 4 顆是空心圓。" count={7} layout="row" marked={3} />
</Figure>
```

| 參數 | 說明 |
| --- | --- |
| `title`、`desc` | 必填，見「替代文字」 |
| `count` | 必填，1–30 的整數 |
| `layout` | `row` 一排、`grid` 依 `columns` 換排、`scatter` 散開 |
| `columns` | `grid` 每排幾顆，1–10，預設 5，配合「5 與 10」的結構 |
| `marked` | 前幾顆標記成 `--accent` 的實心圓，其餘變成空心圓；不給時全部是 `--fg` 實心圓 |
| `seed` | `scatter` 的亂數種子，有預設值；同樣的參數每次 build 都畫在同樣的位置 |

`row` 最多放 11 顆，再多就 build 失敗，請改用 `grid`。散開的圓點彼此不重疊，放不下時 build 失敗，換 `seed` 或減少顆數。

## 用在可列印材料

可列印材料頁（`/print/<材料 id>/`）也用 `Counters` 與 `NumberLine` 畫圓點和數線。列印時頁面強制淺色，背景是白、`--fg` 是黑，其餘 token 用淺色值；家用黑白印表機會把 `--accent` 印成灰色，所以「顏色不能是唯一的訊息來源」在這裡特別重要。印出的尺寸由材料頁的卡片以 mm 決定，教具本身仍只寫 `viewBox`。

## 驗收

發布前，每張教具都要在下列四種組合各看一次，加上列印預覽：

| | 淺色 | 深色 |
| --- | --- | --- |
| 桌面寬 | 顏色、粗細、對齊 | 顏色隨主題切換，沒有看不見的線 |
| 320px 寬 | 數字與標籤讀得清楚，沒有水平捲軸 | 同左 |

自動檢查只涵蓋機器能判斷的部分：fixture 教具的結構、線寬與字級、主題切換時的顏色，以及 320px 沒有水平捲軸（`tests/figures.spec.ts`）。圖是否真的讀得清楚，只能靠人看。
