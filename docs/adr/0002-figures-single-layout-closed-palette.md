# 教具採單一版面與封閉色盤，不沿用 CarlStack 的雙版面與自訂強調色

CarlStack 的圖解規範要求桌面與窄螢幕各畫一份 SVG，並允許每張圖自選強調色 hex（附深色版）。CarlMath 的教具是數線、點陣、積木這類幾何規則的圖，等比縮放就能讀，所以改為單一版面：標準 `viewBox` 寬 480、圖內字級下限 20，保證 320px 寬時可讀，做不到就拆成兩張圖。色彩只用閱讀頁的色票 token，每個 token 有固定語意（`--accent` 是讀者該注意的東西，`--ok`／`--warn` 只用於迷思對照，`--family` 不進圖內），讓同一個顏色在全路線意思一致、深色模式不需逐圖處理。代價是每張圖的文字量與寬度受限，複雜的圖必須拆開。細則見 `docs/figure-guide.md`。

**Falsified if:** 出現某個主表徵（例如函數圖形）在 320px 下無法以單一版面保持可讀而必須另畫窄螢幕版，或 `docs/figure-guide.md` 的語意色不敷使用、需要第四種強調色。
