# 不等號全站用 ≤、≥，取代 ADR 0004 的 ≧、≦

本決定取代 [ADR 0004](0004-inequality-signs-taiwan-geqq.md)。ADR 0004 的前提是「國中考卷用 ≧、≦，高中以後才改」，經查證不成立：113–115 學測、114–115 分科測驗、109–115 國中會考與 108 課綱條文一律印單線 ≤、≥，找不到任何 ≧、≦（來源見 `.scratch/route-to-calculus/research/taiwan-hs-notation.md`）。國中課本是否用 ≧、≦ 沒有查證。即使有，讀者實際對照的考卷與課綱，以及之後從坐標到積分的七個階段，用的都是 ≤、≥。若維持雙線，就得為國中、高中訂兩套規則，那正是 ADR 0004 自己寫的 Falsified if。所以全站統一用 ≤、≥：KaTeX 寫 `\le`、`\ge`，純文字欄位寫「≤」「≥」字元，教具的 `<desc>` 照舊寫中文讀法。〈一元一次不等式〉一篇用一句話說明「有些國中課本寫成 ≧、≦，意思相同」，其他篇不提。這是第二次換寫法，所以內容驗證會擋下 `\geqq`、`\leqq`、≧、≦。日後要改回雙線，就是重新決定，不是修正。

**Falsified if:** 查證到國中課本一律用 ≧、≦，而且讀者回報這造成閱讀困擾，需要在 `docs/content-guide.md` 為國中階段另訂寫法；或 `scripts/validate-content.ts` 必須接受雙線寫法。
