# 平面圖形共用教具以抽象座標宣告、自動縮放，不含座標軸

「量與形」階段開始需要三角形、角與圓，之後的「座標與相似」「三角函數」兩個階段還會大量用到。若各篇各做一次性教具，三角形與角會像數線一樣在全路線長出不同的樣子，事後才收斂。因此新增共用教具 `Shape`：作者以抽象座標寫頂點（y 軸朝上），元件依圖形的外接範圍等比縮放到 viewBox 寬 480，畫出多邊形、圓、邊長、角弧、直角記號、頂點字母、等邊與平行記號和虛線輔助線。度數標籤由 build 依頂點座標驗證，相差超過 1° 就失敗，讓圖不會和文字說的角度矛盾；邊長標籤不驗證，因為示意圖常不按比例畫。

`Shape` 刻意不畫座標軸與格線：座標在這裡只是作者描述形狀的方式，不是讀者要看的數學物件。考慮過的替代是一開始就做成座標平面元件、讓形狀畫在軸上，但量與形階段的讀者還沒學座標，軸與格線只會是雜訊，而且會讓縮放規則被座標範圍綁住。方格的語意（一格就是一平方單位）和多邊形不同，所以另做 `UnitGrid`，不用 `Shape` 加格線代替。代價是座標平面階段來臨時，要重新決定是擴充 `Shape` 還是另做元件。

**Falsified if:** 座標平面階段必須在 `Shape` 上加座標軸或格線才能畫出所需的圖，而不是另做元件；或為了畫刻意不按比例的角，`src/lib/shape-geometry.ts` 的度數驗證必須開例外；或 `docs/figure-guide.md` 的 `Shape` 一節需要第二套縮放規則。
