# 極限與微積分保留精確的白話定義，不以形式證明或考試範圍界定深度

數列與極限、微分、積分面向重新學數學的成人自學者，採精確的白話定義、直覺圖解與可理解的推理，不教 ε–δ／ε–N 的形式定義與證明。有限次的數值驗算不能證明極限存在；省略完整證明時，要交代適用條件並明示省略，讓讀者分得清直覺、推理與完整證明。具體撰寫要求以[內容撰寫規範](../content-guide.md#極限與微積分的嚴謹程度)為準。

完整形式化的分析會增加先修負擔，只靠圖形與數值逼近又容易掩蓋定理條件，因此選擇保留定義的精確含義、要求解釋與反例辨識，而不要求讀者自行寫完整形式證明。「高三數甲程度」也不作為內容上限：課程地圖已刻意包含均值定理、變數變換與分部積分。這個取捨讓現有單元可以保留，但部分定理只提供直覺解釋或省略形式化論證的推理，不能宣稱是一套完整的分析學證明體系。

**Falsified if:** 後續單元必須要求自學者操作 ε–δ／ε–N 才能達成學習目標，或現有白話定義與推理界線不足以清楚交代所用定理的條件。
