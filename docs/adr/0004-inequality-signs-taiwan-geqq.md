# 不等號用台灣國中課本的 ≧、≦，不用國際通用的 ≥、≤

「方程式與不等式」階段開始出現「大於或等於」「小於或等於」。台灣國中教科書寫成 ≧、≦（下面兩條線，KaTeX `\geqq`、`\leqq`），高中以後的教材與國際通用寫法是 ≥、≤（`\ge`、`\le`）。本站讀者是會對照台灣課本、考卷的自學者，所以全站一律用 ≧、≦，純文字欄位寫「≧」「≦」字元，並在一元一次不等式那一篇用一句話說明「其他書上的 ≥ 意思相同」。考慮過的替代是一律用 ≥、≤，與高中以後的教材和多數數學軟體一致；代價是國中讀者翻課本時符號對不上。這是刻意的偏離：日後看到 `\geqq` 時不要「修正」成 `\ge`，要改就是重新決定。

**Falsified if:** 高中以後的階段改用 ≥、≤ 而必須在 `docs/content-guide.md` 為不同階段訂兩套不等號規則；或驗證腳本需要接受兩種寫法並存。
